# Protocol package vision

This dependency-free package gives TypeScript consumers Rust-generated engine/native operation and authoring views, inert printer specifications and independently validated packed display buffers. Protobuf remains the only native API; the shell receives adapters rather than an alternate wire protocol.

The acceptance boundary is schema-v1 SPLT/SPLM/SPLS and schema-v3 SPLR independent byte admission before GPU upload. Actual replay carries distinguishable object/bridge/support/interface/travel/lifecycle roles and honest stationary feeder events through bounded borrowed accessors. Native verifier owns support-contact-gap semantics and emitted-program correctness; decoded bytes confer no firmware, calibration, physical GPU or manufacturing qualification.
