# Protocol package vision

This dependency-free package gives TypeScript consumers Rust-generated engine/native operation and authoring views, inert printer specifications and independently validated packed display buffers. Protobuf remains the only native API; the shell receives adapters rather than an alternate wire protocol.

The acceptance boundary is schema-v1 SPLT/SPLM/SPLS/SPLR byte compatibility, explicit identity/revision/resource correspondence, immutable borrowing and rejection of malformed hashes, sizes, alignment, finite coordinates, source-face ordinals, section loop ranges and replay motion sequences before GPU upload. SPLR exposes independently decoded actual-program positions through bounded f64 strided accessors; it does not implement the native verifier or manufacture a normalized-plan preview. Engine-owned recovery and software-only manufacturing are not implemented by this package; geometry accuracy, independent program replay, real storage and packaged desktop support require separate evidence.
