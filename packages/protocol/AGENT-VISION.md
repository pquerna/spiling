# Protocol package vision

This dependency-free package gives TypeScript consumers Rust-generated engine/native operation and authoring views, inert printer specifications and independently validated packed display buffers. Protobuf remains the only native API; the shell receives adapters rather than an alternate wire protocol.

The acceptance boundary is schema-v1 SPLT/SPLM/SPLS and schema-v5 SPLR independent byte admission before GPU upload. Actual replay carries distinguishable deposited roles, travel/lifecycle and stationary feeder events through bounded borrowed accessors. Nominal width/physical-Z/owner associations distinguish coarse sparse strokes from the unchanged fine schedule without claiming physical measurement. Native verifier owns support-contact-gap semantics and emitted-program correctness; decoded bytes confer no firmware, calibration, physical GPU or manufacturing qualification.

Canonical stored height-image preview is independently admitted as exact bounded P5 Gray8 with generated image metadata, immutable descriptor and SHA-256 binding. Borrowed source row order is preserved; the protocol decoder does not normalize PNG, map displacement, plan geometry or claim feature survival. Native/TypeScript golden bytes plus hostile-size/header/hash tests cover this boundary, not end-to-end durability or physical manufacturing.
