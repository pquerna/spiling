# Replay display vision

This module makes the independently decoded emitted program inspectable as a bounded disposable WebGPU motion surface, standalone or over an optional native scene. Perimeter, solid-fill, travel and the first unknown-start endpoint remain distinguishable; coordinates are actual emitted-program f64 values, not normalized-plan echoes. Draw-state controls retain the original projected batches.

The viewport is an approximate display consumer, not a verifier, planner, printer controller or proof of machine readiness. Its numerical acceptance boundary is origin-rebased f32 projection within 0.001 mm, coupled to atomic publication and shared resource admission. Visibility, alignment, interaction and lifecycle still require declared physical WebGPU reference-hardware evidence; unexercised hardware remains an explicit acceptance limit.
