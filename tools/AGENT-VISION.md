# Tooling vision

A fresh contributor machine should obtain the pinned prerequisites, run the actual native architecture and reproduce packaged artifacts with one documented command surface. Tooling owns dependency provenance and release preparation, not geometry or planner behavior. B0 supports a diagnostic operation/artifact API and CEF viewport; later corpus and manufacturing workloads extend that surface only when implemented.
