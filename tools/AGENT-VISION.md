# Tooling vision

A fresh contributor machine should obtain pinned prerequisites, run the actual native architecture and reproduce artifacts through one documented command surface. Tooling owns dependency provenance, bounded real-surface smoke and release preparation, not geometry, project transactions or planner behavior. Protocol v4 native authoring, software-only manufacturing, geometry inspection and explicit synthetic diagnostics share engine/client tooling. Trusted TypeScript printer/recipe authoring produces bounded inert JSON against generated Rust contracts; it is neither a sandbox nor an engine plugin runtime. Project-bridge smoke exercises actual CEF/native storage without claiming WebGPU presentation; CEF development smoke is not packaged or physical hardware certification. Native/manufacturing support expands only through recorded evidence.
