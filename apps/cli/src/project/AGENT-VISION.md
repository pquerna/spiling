# Project command workflow vision

Provide a reproducible operator surface for source-backed native authoring through the same services as the desktop: ordered imports/shared placements/removal, session undo/redo, explicit checkpoints, fresh-process inspection and explicit recovery. Reports expose persistent state and independently verified native geometry, not CLI-owned project authority. Manufacturing workflows carry explicit inert printer/recipe intent to the Rust compiler, replay emitted programs independently and export validated immutable content; fresh read-only reopen permits replay/export and exposes persisted intent and summary. Intent/pose edits invalidate active artifacts and ordered undo restores coherent engine-owned state. All manufacturing output is software-only, not machine-ready; physical printability, startup/homing/temperature/firmware/collision certification is not claimed. No saved viewer recipe substitution, arbitrary STEP assembly promise or filesystem/platform certification from command availability alone.

Ordered actual-program motion export uses explicit fresh inspection and the same checked ByteStream client and shared exclusive filesystem transaction as the native shell. Its immutable descriptor and inspection provenance accompany operator reports without changing persistent Core state.

Full inert intent preserves printer identity and capabilities. Revision-bound native bed preparation handles placed parts through the same geometry service as the workbench; an explicit normal pose transaction applies the result. Read-only actionable preflight never confers native slicing success or physical qualification. Operator JSON retains revision-bound checks and historical export identity.

Explicit source-face flags add, remove and enable definition/occurrence-scoped Smooth, VerticalRibs, CylindricalRibs and ImageRelief through the same project authority. Schema3 overlays retain canonical immutable image identities; ordered native image import and fresh read-only PGM export accompany self-contained provenance and motion without source-path dependence. Assignment does not remesh or claim compile eligibility.

Whole-owned-volume sparse process edits are explicit ordered Projects commands, separate from full global manufacturing intent. Definition/occurrence values, inherited values and responsible layer/operation identities come only from Rust's authoritative ProjectInfo resolver. Read-only process inspection, scope reset and fresh-process durable compile/replay/export use that same authority; no frontend-owned ordinals or alternate precedence model belong here.
