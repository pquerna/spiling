# Project command workflow vision

Provide a reproducible operator surface for source-backed native authoring through the same services as the desktop: ordered imports/shared placements/removal, session undo/redo, explicit checkpoints, fresh-process inspection and explicit recovery. Reports expose persistent state and independently verified native geometry, not CLI-owned project authority. Manufacturing workflows carry explicit inert printer/recipe intent to the Rust compiler, replay emitted programs independently and export validated immutable content; fresh read-only reopen permits replay/export and exposes persisted intent and summary. Intent/pose edits invalidate active artifacts and ordered undo restores coherent engine-owned state. All manufacturing output is software-only, not machine-ready; physical printability, startup/homing/temperature/firmware/collision certification is not claimed. No saved viewer recipe substitution, arbitrary STEP assembly promise or filesystem/platform certification from command availability alone.
