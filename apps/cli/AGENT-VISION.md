# Native authoring and inspection consumer vision

Serve operators and numerical/transfer acceptance through the same supervised native engine client as the desktop. Author durable source-backed projects, shared rigid occurrences and placements with session undo/redo, explicit checkpoints, read-only inspection and explicit previous-checkpoint recovery. Reopen from engine-owned immutable assets without original source paths. Inspect source faces, bounded unique meshes and native planar sections; optional exclusive output records independently verified chunks and a completion manifest. Ordered manufacturing flags consume bounded inert printer/recipe intent, compile via Rust engine services, independently replay emitted G-code and export validated durable bundle contents into an owned new directory. Fresh-process read-only reports expose persisted intent/summary and allow replay/export, never artifact publication. These artifacts are software-only and not machine-ready; physical printability, firmware/startup/thermal/collision behavior and printer certification remain outside this surface. Geometry recipes remain separate ephemeral evaluation inputs; diagnose and synthetic triangle remain explicit diagnostics. The CLI owns no project store/domain authority, STEP assembly importer, geometry kernel or planner.
