Serve headless operators and numerical/transfer acceptance through the same supervised native gRPC client as the desktop. Preserve readiness, synthetic triangle diagnostics and durable diagnostic operation/artifact retrieval alongside native geometry and source-backed projects; Google Operations and ByteStream remain the sole observation and transfer surface.

Author shared rigid occurrences and placements with bounded session undo/redo, explicit checkpoints, read-only inspection and explicit previous-checkpoint recovery. Reopen from immutable engine-owned source assets without original paths. Inspect source faces, unique bounded meshes and native planar sections; exclusive output records validated chunks only after observed child reap.

Ordered manufacturing flags consume explicit bounded inert printer/recipe intent, compile through Rust engine services, independently replay emitted G-code and export validated immutable bundles. Fresh-process read-only reopen/replay/export is an acceptance boundary, including exact fresh verification and retained source provenance. Supported programs are software-only and not machine-ready; there is no physical printer support, alternate CLI planner, machine connector or manufacturing UI implied by this surface. Platform durability and physical manufacturing require separate evidence.
