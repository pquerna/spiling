# Desktop rules

- Own transient React workbench forms/display state; `src-tauri/` owns native supervision and token-scoped source/project path admission. Protocol-4 ProjectCommand/Response/Info, common EngineJob/JobResult/tagged JobError and selected-path DTOs come from `@spiling/protocol`; core is the sole authoring authority. Never introduce a frontend project store or kernel logic.
- Ship the canonical root `LICENSE.md` offline. Explicit checkbox assent precedes mounting the workbench. Persist only the versioned local acknowledgement; reviewing assent unmounts and stops the engine.
- Browser-only use shows desktop-required, never mocked invokes. Admit and initialize a strictly WebGPU viewport before starting/restarting the engine; unsupported devices are visible failures, with no WebGL fallback.
- `useWorkbench` serializes one short invoke exchange at a time, not an entire native job or transfer. Track active jobs independently; pending cancellation takes priority after the current complete exchange, poll jobs every 100 ms, and never abort a pipe read to cancel. Stop/restart remain available during native work and transfer. Generations reject stale completion.
- Start with a new unattached project. Import token-selected parts sequentially; a later domain error preserves earlier admissions and names the failed source. Engine scene epochs and core persistent identity/revisions/dirty/history are authoritative. Euler XYZ degrees are only a placement-editor presentation, converted to canonical unit quaternions.
- Fetch paged metadata and unique-definition chunks incrementally, validate hashes/layout/identity through protocol decoders, then upload one chunk and yield a frame. Shared instances reuse viewport definitions; pose/add/remove never request mesh bytes. Retain borrowed bytes while the viewport owns their decoded views.
- Revision changes immediately clear face selection and section overlays. If engine commit precedes a cancelled/failed scene upload, retain the previous display explicitly stale and noninteractive; disable picks and mutations, and resume by re-reading the current scene without reimport/retessellation. A section-only transfer cancellation discards staged lines, retaining the interactive scene and prior overlay labelled with its own plane.
- Await idempotent viewport teardown before replacement and on loss/close. Process/transport/GPU failure tears down the session; typed geometry/project/manufacturing errors and decoder admission failures retain a healthy engine and last valid display. Restart explicitly reopens shell-private attached saved storage; never replay unsaved mutations or prior-session undo.
- New/open/recover and explicit stop/restart require dirty-discard confirmation. First save admits a new directory name through native selection; normal save uses attached storage. ProjectSaved and ProjectResponse::Status update project status only: intent/artifact-only undo/redo must not invalidate the scene, retessellate or retransfer meshes, and save must not clear history. Read-only disables mutations/save/undo/redo but preserves inspection/sections.
- After a typed project job failure, query ProjectInfo. A postcommit durability failure may attach storage while reporting save_uncertain/dirty; display the explicit warning and preserve prior confirmed saved revision. Never label it cancelled/saved or blindly retry.
- Preserve the generated protocol-4 Hello, including manufacturing_capabilities, without a second handshake model. Common job polling/cancellation can carry manufacturing errors/results: handle each tagged domain/result explicitly and preserve a healthy session, but reject manufacturing results as unavailable desktop operations. Do not add manufacturing UI, native invokes, planning or replay.
- Privileged fixture controls appear only when native `RuntimeInfo.geometry_debug_enabled` reflects a startup canonical fixture root plus explicit CEF debug opt-in. Source arrays and project directories are relative/confined and use the production token/job/decoder workflow. No unrestricted renderer filesystem authority.
- `dev` serves port 1420; `check` typechecks and `build` typechecks/bundles. Acceptance requires real native invokes, multi-object display/picking, pause/resume, cancellation and lifecycle evidence on declared WebGPU hardware. Packaging certification is separate; compilation is not visual evidence.
- Preserve OSL source notices and adjacent JSON licensing sidecars. Unminified Vite output retains source legal comments; distributions obey `../../docs/license.md`.
