# Native desktop shell rules

- Own CEF composition, native dialogs, local invoke ACLs, shared-client supervision and binary bridging only. Core owns durable authoring/storage; shell retains only private path admission/attached-checkpoint routing, never a project implementation, kernel, planner or renderer.
- Pin Tauri `3.0.0-alpha.4`, tauri-build `3.0.0-alpha.3`, runtime-cef `3.0.0-alpha.5` and rfd `0.17.2` exactly. The direct runtime-cef dependency is the upstream CEF build/package detection hook; retain `cef_entry_point`, never add Wry or custom unsafe helper-process code. CEF is `152.3.0`.
- Explicitly register invokes in `build.rs`, `main.rs` and the local-only main capability. The only core permission is close through deferred cleanup. No remote capability or broad shell/process/filesystem ACL. Synthetic triangle remains an explicit bridge diagnostic, never an import fallback or CAD UI.
- Schedule rfd's picker on the application main thread without holding the engine mutex. Enable only `xdg-portal`, with no zenity/GTK fallback; Linux needs xdg-desktop-portal and a running supported desktop backend. Selection is at most 32 files, all-or-nothing; cancel returns empty and preserves unconsumed selection.
- Keep filesystem bytes/code units private. Generated SelectedSource and SelectedProjectPath expose UUID/session/bounded label (project intent open/save), never NativePath. Source tokens consume on ImportPart JobAccepted; at most one project token per intent consumes on Open/Save JobAccepted. Clear token tables on stop/restart/interruption/close; picker cancellation preserves tokens. Generic geometry denies ImportPart/binary reads; generic project denies all Open/Save. Token-only project_open/project_save and raw geometry_chunk are distinct bridges.
- Startup-only `SPILING_GEOMETRY_FIXTURE_ROOT` plus valid `SPILING_CEF_DEBUG_PORT` enables privileged relative fixture admission. Canonicalize the fixed root and existing sources/open directories; for new save targets canonicalize the existing parent and refuse an existing destination. Reject absolute/traversing/outside/symlink-escaping paths; mint ordinary intent/session tokens. No arbitrary-path invoke.
- CEF debugging is disabled unless `SPILING_CEF_DEBUG_PORT=1024..65535`; only exact `SPILING_CEF_UNSANDBOXED=1` and `SPILING_CEF_SOFTWARE_GPU=1` select their explicit diagnostics. Preserve upstream Auto sandbox warnings/limitations. Software GPU is not production hardware evidence.
- Resolve installed sidecars adjacent to the desktop executable (or installation-prefix bin for CEF Debian layout); no PATH/cwd/arbitrary ancestor search. Debug builds alone allow absolute SPILING_ENGINE_PATH. SPILING_PROTOCOL_VERSION is an explicit u16 mismatch diagnostic.
- Close/exit prevents new commands, queries dirty state and requests main-thread native discard confirmation before awaited shutdown/reap. Cancel restores admission. Hold the client mutex only for exchanges/cleanup, never the dialog; see [engine rules](src/engine/AGENT-RULES.md). Frontend admits GPU before spawning; shell startup alone launches no engine.
- Project open/save use EngineClient::project and common EngineJob polling/tagged recoverable errors over protocol 4. Forward Hello, including manufacturing_capabilities, unchanged. ClientError::Manufacturing is typed and nonfatal; manufacturing JobError/JobResult remain common job metadata, never a project attachment receipt. No manufacturing native invokes, planner, replay or UI bridge. Remember attached saved NativePath privately after success, or reconcile save_uncertain after postcommit Io failure. Restart requires dirty-discard intent; explicit project_reopen restores the checkpoint, never unsaved mutations. Save does not touch scene/display/history.
- Root tools generate contracts/notices and copy the target-suffixed sidecar before the pinned CEF-aware CLI. CEF_PATH defaults to ignored .cache/cef; avoid unrequested CEF/package builds. Ship root license/source/NOTICE and generated release provenance, preserving icon sidecars.
- Acceptance uses actual token/job/chunk invokes, responsive cancel, source fidelity, restart/fresh identity and close without orphan processes. Unit security tests do not certify native dialogs, WebGPU or distributables; physical reference-machine evidence governs platform claims.
