# Native manufacturing bridge vision

Own a narrow production bridge from the manufacturing review panel to supervised shared native services: explicit intent mutation, single durable compilation/inspection jobs, bounded validated actual-program replay bytes and dialog-token-scoped exclusive four-file export.

Capture transient fresh inspection authority rather than trusting stored verified flags or arbitrary renderer reports. Historical operations cannot install authority in a different session; reopen needs fresh verification. Active content checks occur after transfers and before filesystem commit. Shared exclusive directory ownership and cleanup remain one implementation for CLI and desktop.

No renderer filesystem authority, native geometry objects, project persistence, planner, independent parser, machine executor or silent GPU fallback belongs here. Explicit startup diagnostics permit actual native-panel software evidence when WebGPU is unavailable; dialogs, rendering/picking, hardware and packaging certification remain independent reference-platform gates.
