# Desktop engine supervision vision

Translate real native child ownership into one recoverable gRPC authoring/diagnostic workbench. Dead engines never report running; typed domain errors preserve healthy sessions; explicit stop differs from interruption. Shared EngineClient owns supervision, EngineRpc owns RPC access, core owns project/storage, and the engine's single durable scheduler owns native and diagnostic work.

One lazy child begins with an unattached project and a persistent diagnostic ledger. Private bounded source/project/image/export tokens admit paths; only the attached saved checkpoint route is retained. Image import uses its own token bridge and the common operation dispatcher; canonical stored-image retrieval is read-only and independent of any import token or original source. Operations names observe/cancel work without blocking cleanup; raw ByteStream bytes use checked domain metadata and bounds. Fresh manufacturing inspection authority is transient, request/session/content-bound and cleared on reopen/lifecycle changes; retained historical outputs never establish live ownership.
The operator bridge admits full inert intent through bounded native dialog tokens, preserves profile declarations and exposes separate software input Preflight. Read-only bed preparation returns native original-source contact evidence and a pose preserving arbitrary rigid orientation; explicit review/Apply leaves both captured revisions, history and read-only authority to Core. True schedule thickness and empty support-contact gaps are native checked metadata, not renderer estimates or fabricated motion.

The shell does not retain native objects, implement project transactions/storage, replay edits, accumulate unbounded transfer bytes, plan manufacturing or add a second handshake model. Restart explicitly reopens only saved storage. Startup-gated fixtures use production path tokens without unrestricted renderer filesystem access.

Acceptance requires actual process interoperability, durable diagnostic behavior, fatal/recoverable errors, native dialog/token operations, independent cancellation and no surviving child after stop/close during native work or transfer. Visible picking/rendering and distributable certification remain separate reference-hardware gates.
