# Desktop engine supervision rules

- Use spiling-engine-client exclusively for bounded framing, protocol-4 negotiation, request deadlines and process shutdown/wait/termination/kill-on-drop. Forward generated Hello, including manufacturing_capabilities, unchanged. Generated ProjectCommand/Response/Info and common EngineJob/JobResult/tagged JobError own contracts; core owns authoring/storage.
- One asynchronous mutex serializes child ownership and one complete short exchange, including restart/close cleanup. Never hold it over dialog work, native job polling waits or frontend upload loops. The closing atomic gate is checked before and after locking.
- Keep stopped, running and interrupted distinct. Refresh verifies the actual child; absent client means absent Hello. Preserve interruption diagnostics until explicit recovery; do not auto-retry or replay.
- Typed geometry/project/manufacturing errors and ClientError::is_fatal=false preserve a healthy client. Handle ClientError::Manufacturing explicitly as nonfatal, not a transport interruption. Common job metadata includes ManufacturingCompiled/ManufacturingVerified and JobError::Manufacturing; neither manufacturing result can attach a project checkpoint route. No manufacturing invokes or replay. Fatal transport/correlation/worker failures disconnect, terminate and reap. Raw chunk/triangle responses move the client's Vec into IPC without JSON/base64 or whole-artifact copies.
- Source selections are bounded private NativePaths paired with generated UUID/session/label DTOs. Successful selection replaces the set atomically; picker cancellation preserves it. Import consumes a matching active-session token only on JobAccepted. Clear on stop, crash, diagnostic interrupt and restart; consumed failed jobs require reselect.
- geometry_control refuses ImportPart/ReadArtifactChunk; project_control refuses every Open/Save. project_select_path schedules main-thread rfd folder admission for open or a new directory-name save destination. project_open/project_save resolve private intent/session tokens (bounded to one each), consumed on JobAccepted and cleared on lifecycle changes. Actual NativePaths never reach JavaScript.
- Startup canonical fixture root requires CEF debug opt-in. Existing source/open paths must be canonical descendants; a save name must not exist and its canonical existing parent must be confined. Reject absolute/parent/symlink escapes. RuntimeInfo reveals the gate, never root/paths.
- Startup while live reuses Hello. Restart checks dirty-discard intent, cleans the old child, then spawns; explicit project_reopen opens the privately attached checkpoint. New/open may switch away from a read-only snapshot; edits/undo/redo/save remain forbidden. Successful or reconciled postcommit saves attach routes; failed/cancelled open preserves the prior route. Never replay unsaved authoring. Failed stop forcibly reaps or reports interrupted cleanup failure.
- A postcommit durability error attaches published storage while reporting typed Io failure. Only that failed job's ProjectSaved receipt with save_uncertain proves publication of its pending route; sticky ProjectInfo uncertainty from an earlier save cannot settle a later precommit failure. Never auto-retry an uncertain write.
- Engine discovery is installed-executable-relative; development override is absolute and explicit. Surface protocol override errors. Exercise actual lifecycle/token/job/chunk invokes and process trees. Pure source-gate tests cover byte fidelity, limits, unique session-bound tokens and canonical containment, not mocked imports.
