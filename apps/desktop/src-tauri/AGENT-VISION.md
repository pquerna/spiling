# Native desktop shell vision

Provide a packaged Chromium Embedded Framework host and narrow protocol-4 geometry/project bridge to a separately supervised engine. Forward the generated handshake and common job/error contracts, including software-only manufacturing capability metadata, without exposing manufacturing invokes. Native paths remain byte/code-unit preserving shell-private values behind intent/session-bound tokens; bounded chunk vectors move directly into raw IPC responses.

The durable authoring surface uses the same EngineClient as CLI: source-backed import/shared rigid occurrences, native inspection/sections, bounded undo/redo, checkpoint save/open/explicit previous recovery and read-only snapshots. Core alone owns authoring/storage. Recoverable geometry/project/manufacturing errors preserve the child; corrupt transport requires a new session. Explicit restart/reopen restores attached saved storage, never consumed-source replay or unsaved mutation.

Privileged automation admits only fixed-root-relative sources/project directories under startup CEF debugging opt-in. New save targets are nonexisting names under a canonical confined parent. This exercises production tokens/jobs/binary transport without unrestricted renderer filesystem access. Bridge evidence is not visible authoring/dialog certification.

Windows, macOS and Linux use the upstream CEF-aware packager; implementation alone certifies none of them. Upstream sandbox limitations remain visible. Physical WebGPU display/picking, real file-dialog cancel/multi-select, responsive cancellation, pause/resume and process/resource cleanup are acceptance gates; packaging polish/certification is deferred separately. No alternate webview, linked kernel, planner or manufacturing replay belongs here.
