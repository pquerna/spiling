# Surface finish workbench vision

Provide a modest source-backed finish editor over the sole native project authority: explicit source face, definition-versus-occurrence scope, numeric source-local vertical ribs and Smooth override, ordered durable layers and reveal-by-remove/disable semantics. Useful rib drafts start at depth 0.1 mm, pitch 2 mm, protected edge margin 0.8 mm and phase zero.

The supported construction is bounded additive manufacturing of native certified full-height rectangular exterior vertical walls under upright bed-anchored placement. Preserve original material; manufacturing owns process/topology/envelope admission and independent emitted replay. Persistent authorship can precede compile eligibility, with explicit native rejection and no silently untextured success. This is software-only construction, not edited source BREP, grip qualification, arbitrary image relief, a general brush or a shader preview.

Acceptance uses actual native face selection, authoritative layer receipts, history and durable reopening, plus changed verified emitted paths in existing replay. Diagnostic no-GPU controls establish bridge behavior only, never physical picking or hardware qualification.
