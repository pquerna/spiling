# Surface finish workbench vision

Provide a source-backed finish editor over the sole native project authority: explicit source face, definition-versus-occurrence scope, planar and cylindrical source-local vertical ribs, Smooth override, ordered durable layers and reveal-by-remove/disable semantics. Numeric carrier-specific controls map to the single generated finish contract; source identity and editing/history are independent of carrier or exporter.

The supported construction is bounded additive manufacturing of native certified full-height rectangular supporting walls or complete exterior circular cylinder faces under upright bed-anchored placement. Preserve original material; manufacturing owns periodic profiles, native mapping, process/topology/envelope admission and independent emitted replay. Persistent authorship can precede compile eligibility, with explicit native rejection and no silently untextured success. This is software-only construction, not edited source BREP, grip qualification, arbitrary image relief, crossed/helical knurling, a general brush or a shader preview.

Acceptance uses actual native face selection, authoritative layer receipts, history and durable reopening, plus changed verified emitted paths in existing replay. Diagnostic no-GPU controls establish bridge behavior only, never physical picking or hardware qualification.
