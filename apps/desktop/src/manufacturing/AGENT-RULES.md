# Manufacturing workbench rules

- Own transient scalar drafts, native operation workflows and operator review only. Generated schema-4 domain types are authoritative; native.ts alone invokes Tauri. Full inert ManufacturingIntent JSON enters through a native dialog, Rust validation and a session-bound single-use token with a strict 32 KiB byte cap. No executed profiles or renderer paths. Preserve the entire printer/job declaration and all unedited process/support data through scalar edits; configuration/calibration hashes are declarations, never physical qualification.
- Explicitly select either loaded full intent or bundled diagnostic software reference. Show complete-Marlin versus diagnostic identity. Recipe/process/retraction/enabled-support scalar edits submit one full intent on Apply, never per keystroke; unchanged drafts submit nothing. Failed admission retains the draft. Authority replacement resets drafts; concurrent authoritative intent changes require explicit reload. Core owns Undo/Redo/Save/Reopen.
- Read-only permits Preflight, fresh Verify and Export, but not Apply/Compile/bed preparation. Bed place/center uses the shared Rust client helper with certified native definition bounds, declared bed envelope and an axis-aligned pose; renderer performs no pose algebra. Preserve orientation, reject oblique uncertified contact and nonfitting bounds, commit through revision-bound SetInstancePose and Core history.
- Freshness binds session, project/open epoch, current server-selected artifact hash/input hash and fresh request generation. Capture revision is provenance, not content freshness. Recheck after transport/decode/GPU staging. Superseded replay is cleared; historical reports are labelled inactive and release packed display bytes. Unchanged checkpoint bookkeeping does not invalidate matching content.
- Surface metadata revisions use the same authority refresh and artifact invalidation as intent edits, with no scene remesh. Captured provenance exposes complete ordered surface overlays. Realized section area includes bounded additions and equals source plus added area; geometric added volume is construction accounting, not measured extrusion or grip efficacy. Deposited volume remains based on actual path length and true height.
- Layer/event/travel controls change display state only. SPLR3 separates object/support deposition, lifecycle/prime and stationary retract/recover; recovery is not deposited material. Native verified-bundle layer metadata displays true thickness and section Z, including zero-deposition support-contact-gap layers. Selecting an empty schedule layer shows no events and never substitutes a neighbour. Homing has no displayed trajectory; first unknown-start travel is an endpoint only.
- Native dialog-only single-use tokens authorize immutable four-file export. Confined fixture admission and explicit no-GPU attachment require native startup capabilities. Diagnostic transport is labelled no GPU/picking/hardware acceptance; normal product WebGPU admission remains mandatory.
- Typed Manufacturing.Preflight uses the same long-running operation dispatcher/cancellation as Compile and Verify. Report every bounded severity/code/message and occurrence/face reference, captured revision and stale status. Eligibility is inexpensive input/profile/orientation/placement only; native layer/support/bridge/offset analysis remains pending during Compile, and physical qualification is absent. Display independent coverage/provenance, object/support/prime/retraction accounting and explicit first-layer/cooling/retraction/bridge/support policies; no Print action. Exercise state invariants with `node --test apps/desktop/test/manufacturing-state.test.mjs` and the real CEF panel with `tools/smoke-desktop.mjs --scenario manufacturing`.
