# Manufacturing workbench rules

- Own transient recipe drafts, native workflows and review only. Generated domain contracts are authoritative; native.ts alone invokes Tauri. Full inert ManufacturingIntent JSON uses native dialog/Rust validation/session-bound single-use token, capped32KiB. Preserve the entire explicit printer/job declaration, deposition limits and unedited policies through recipe edits. No executed profile, renderer path, inferred default or physical qualification follows from configuration/calibration hashes.
- Explicitly select either loaded full intent or bundled diagnostic software reference. Show complete-Marlin versus diagnostic identity. Recipe/process/retraction/enabled-support scalar and seam/rectilinear policy edits submit one full intent on Apply, never per keystroke; unchanged drafts submit nothing. Required top_skin_axis edits are independent of regional rectilinear_axis and preserve sparse policy and source-bound zones. Preferred seam directions require explicit finite nonzero XY input, robustly normalized with canonical zero before submission in placed build/machine coordinates, never camera/source coordinates. Preserve already admitted unit vectors through reload and unrelated edits. Preferred starts use existing perimeter vertices; admitted bridge/support orientation exceptions remain separate. Failed admission retains the draft. Authority replacement resets drafts; concurrent authoritative intent changes require explicit reload. Core owns Undo/Redo/Save/Reopen.
- Preferred wall width and nominal contour depth describe needs, not a selectable wall algorithm. Explicit software minimum/maximum width draft edits retain the rest of the printer declaration and submit through the same full-intent Apply/history path; native admission and Compile remain authoritative.
- Read-only permits Preflight, fresh Verify and Export, but not Apply/Compile/bed preparation. Observe accepted bed work through the common cancellable operation dispatcher. Its terminal native contact proposal preserves current rigid orientation; check captured session/project/scene, occurrence/pose and applied printer envelope before publication. Review old/proposed poses and contact evidence before explicit Apply. Changed project/scene/intent/session invalidates proposals permanently. Apply submits one SetInstancePose with captured revisions; Core owns history. No renderer placement algebra or display bounds.
- Freshness binds session, project/open epoch, current server-selected artifact hash/input hash and fresh request generation. Capture revision is provenance, not content freshness. Recheck after transport/decode/GPU staging. Superseded replay is cleared; historical reports are labelled inactive and release packed display bytes. Unchanged checkpoint bookkeeping does not invalidate matching content.
- Surface metadata revisions share authority refresh/artifact invalidation with intent edits, without remesh. Captured provenance exposes ordered overlays and image metadata only. Realized area equals source plus added; geometric additions are not measured extrusion/grip. Display summary.surface_resolution as bounded sampled nominal-bead advisory totals with complete/incomplete coverage and resolved/ambiguous/below-resolution/unavailable counts, separately from fresh independent emitted replay. Neither sampled coverage nor native replay proves universal image fidelity or physical printability.
- Display summary.native_geometry evidence as actual occurrence-query/slab coverage, requested/achieved native shape error, bounded query counts and separate accepted disjoint-source/invariant-union/native-interface-complex layer counts plus `owned_critical_slab_count` (unique original occurrence/accepted slab with endpoint or collar ownership). Never render the summary object directly or label the whole plan invariant because one interval is. A directed sample-to-closed-source proof is not a reverse prism certificate; native critical collar metric and incidence ownership remain distinct. Adjacent closed endpoint ownership is not Hausdorff(empty,contact)=0; an active core plus its own outgoing floor face is not a local full-closed prism certificate. Per-occurrence certification is not global composed union-boundary/feature proof. Native coverage is distinct from sampled image-resolution advisories. Skin scope is scheduled realized-material distance; support-clearance scope is continuous target outer occupancy, not anchors, inner material coverage or physical collision freedom. Actual deposited strokes alone anchor deposition.
- Layer/event/travel/source-visibility values commit only after successful bounded GPU update. SPLR5 separates actual XYZ/E/F from nominal verified-plan width/physical-Z/owner association, never measured beads. Fine/combine edits retain fine walls, skins, separators and source-bound density intent; a genuinely unsupported post-band sparse landing may need fine regional Bridge process. Show coarse associated height separately from owning-layer thickness, per-event dimensions and bounded terminal-band owners/retained-fine reasons. Do not promote regional indices into cross-layer source identity. Empty layers show no events; first unknown-start travel is an endpoint, not invented motion. Homing has no displayed trajectory; prime/recovery remain separately accounted.
- Show automatic Wall-associated nominal width range and locally constant-section command counts, including genuine Bridge roles with immutable Wall ownership. These are plan associations, not measured physical beads or a claim that every requested contour is a complete closed loop.
- Native dialog-only single-use tokens authorize immutable four-file export. Confined fixture admission and explicit no-GPU attachment require native startup capabilities. Diagnostic transport is labelled no GPU/picking/hardware acceptance; normal product WebGPU admission remains mandatory.
- Preflight shares the cancellable native operation dispatcher with Compile/Verify. Show current/stale captured revision, engine disposition, every code/message/evidence and occurrence/face scope. Group required admission separately from optional Compile analysis/advisories: required unresolved evidence is not passed, and optional failed evidence does not itself refuse admitted input. Admission never proves Compile or physical qualification. Keep independent coverage/provenance and object/support/prime/retraction accounting distinct; no Print action.
- `workflow.ts` derives presentation from the controller's named `ManufacturingReviewState`, matching project/revision and existing content-bound freshness; never store a second workflow stage or parse error strings into geometry identity. Draft/conflict, stale status, read-only state and current operation failure must not recommend a mutating or stale export action. Retain full diagnostics; only explicit controls invoke existing native operations. Exercise state invariants with `node --test apps/desktop/test/manufacturing-state.test.mjs` and the actual CEF flow with `tools/smoke-desktop.mjs --scenario manufacturing`.
