# Manufacturing workbench vision

Provide a complete thin operator review workflow over the same native manufacturing services as CLI: explicitly selected software intent, supported solid-fill recipe scalar editing, Core checkpoints/history, immutable compilation, fresh independent verification, actual emitted-program endpoint inspection and exclusive four-file export.

Reports remain inspectable as historical evidence but never regain active authority after content invalidation, reopen or session replacement. Fresh validated motion can stand alone or overlay matching native geometry; layer/event/travel controls alter display state only. Independent coverage and captured provenance remain distinct from rendering precision and physical-printability evidence.

This panel is software-only, limited to the declared vertical planar/cylindrical fixed-height solid-fill envelope. It is not a printer executor, calibration tool, browser slicer, arbitrary profile authoring environment or physical support claim. Explicit startup diagnostics exercise the actual panel and native transport without substituting a renderer, inventing picking evidence or bypassing the product WebGPU policy.
