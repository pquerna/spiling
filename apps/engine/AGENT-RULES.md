# Native engine sidecar rules

- Serve authenticated typed gRPC on ephemeral IPv4 loopback. Stdout contains one bounded startup JSON record; stdin supplies the per-launch capability and owner-liveness EOF. Structured bounded diagnostics use stderr. No framed dispatcher, JSON command tunnel, exposed native task IDs or raw binary response path.
- Engine diagnostics, Geometry, Projects and Manufacturing share one durable Jobs ledger and execution permit. Standard Google Operations owns observation/cancellation and Artifacts/ByteStream owns immutable retrieval. Short native actions execute on one bounded dedicated session dispatcher, never Tokio; a single Worker owns all BREP/kernel/storage/manufacturing work and a single Watchdog owns deadlines.
- Compose core as sole source/occurrence/intent/artifact transaction, history and storage authority. Use public geometry/manufacturing facades, never an alternate planner or direct kernel dependency. Preserve declared-profile STEP/native algorithms and frozen numerical tolerances, including independent replay and per-island erosion.
- Import/open/section/manufacturing publish only after promotion ACK and core commit. The dispatcher captures immutable output bytes before accepting a subsequent short edit; SQLite commits descriptors/blobs and the terminal operation atomically. Retain the old complete project/storage/history/native pins until successful open ACK. Cancellation/stale/failure preserves previous state.
- Persistent ProjectRevision and session SceneRevision remain distinct. Geometry changes advance scene epochs; save and intent/artifact-only history do not. Enforce session/base revisions and explicit dirty discard. Read-only forbids edits/save/undo/redo/compile publication, not inspection/replay or switching projects.
- Preserve native path bytes/code units, regular-handle capture, limit+1 reads and size/mtime checks. Imported captured bytes become immutable core source assets; reopen never rereads original paths. Native placements/queries use mm/f64; face references bind session/revision/occurrence/definition/canonical identity.
- Watchdog cancellation and promotion/save CommitToken share the decision lock. Cancellation cannot roll back a committed manifest replacement; publish truthful SaveReceipt/uncertainty through ACK. Deadlines remain 60 seconds plus ten seconds cancellation grace, ending in process exit 70 on missing safe-boundary ACK. Validate SPILING_PROJECT_FAULT=after_assets|before_manifest_replace|after_manifest_replace at startup; fault exits 86 establish actual-process recovery, not power-loss certification.
- Native resident/source/history/staged/display/bundle budgets remain explicit and separate from SQLite durable output copies. Engine memory remains session-bound; retained durable Operations/artifacts may be historical after restart. Do not reconstruct handles, activate historical scenes or automatically resume unfinished manufacturing/native work. RPC drop does not cancel admitted work.
- Owner EOF/Shutdown drains native work through cancellation and ACK before interrupting unfinished ledger entries. Bound server stream drain; never block Tokio on native work or non-cancellable stdin reads.
- Actual-child geometry/project/manufacturing suites and existing diagnostic auth/dedupe/restart/watch/range/concurrency tests govern acceptance. Run native builds and actual-child checks sequentially under externally enforced memory/task limits on constrained hosts. See [control](../../docs/protocol/control.md), [project format](../../docs/protocol/project.md) and [geometry evidence](../../docs/quality/geometry-evidence.md).
- Software manufacturing uses explicit validated inert profiles/intent and native sections; programs are not machine ready. No physical printer/printability, packaging or hardware graphics certification follows from service availability. Triangle remains an explicitly requested synthetic diagnostic, never native import fallback.
