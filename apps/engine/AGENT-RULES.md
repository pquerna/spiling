# Native engine sidecar rules

- Reserve stdout for contracts frames and stderr for bounded structured diagnostics. Exactly one successful v4 handshake precedes commands; request IDs increase strictly. Malformed/unknown control, framing/correlation errors and worker panic/disconnect interrupt the session. Typed geometry/project/manufacturing errors leave it healthy.
- Compose `spiling-core` as the sole source/occurrence/intent/artifact transaction, history and storage authority, the public `spiling-geometry` facade for native evaluation and `spiling-manufacturing` for compilation/independent replay. One bounded worker owns every BREP and performs captured project open/save and manufacturing work; the dispatcher owns derived metadata, ephemeral scene epochs, jobs and immutable encoded buffers.
- Publish import/open/section/manufacturing only after the worker's promotion ACK. Keep the old entire project, writer lock and native pins until successful open ACK. Failed/cancelled/stale stages preserve prior state. Core history pins sources/native definitions/meshes and manufacturing assets under separate budgets; scene pages expose only the current core snapshot.
- Filesystem capture preserves native path bytes/code units, checks a regular handle, bounds limit+1 reads and detects size/mtime changes. Placements and native coordinates are mm/f64. Face references validate session, revision, occurrence, definition and canonical source-face identity.
- Keep command/result/input slots bounded and pull exactly one borrowed chunk per exchange. Account scene/native/staged/artifact resources; leases retain encoded bytes, never BREP. Terminal jobs and released-handle tombstones retain at most 64 records; empty-section handles cannot grow an unbounded lease table.
- The independent deadline owner requests cancel after 60 seconds, then exits 70 after ten seconds without a safe-boundary ACK. Explicit cancel begins that grace earlier. Heavy work never blocks Ping/status/cancel exchanges; stdin idle cannot suspend deadlines. Save/open serialize authoring, but geometry work retains stale-result semantics.
- Retain Triangle only as an explicitly requested synthetic diagnostic. Never display or return it as an import fallback. Structured kernel identity/capabilities describe linked implemented paths, not packaged/hardware certification.
- Persistent ProjectRevision and session SceneRevision are distinct: geometry mutation/replacement advances the scene epoch; save and manufacturing intent/artifact-only edits/history do not regenerate geometry or change scene epochs. New/open require explicit discard when dirty. Read-only rejects edits/save/undo/redo/compile publication, not inspection/replay or switching away.
- Save's native worker uses the watchdog's shared cancellation lock at the durable commit boundary. Cancellation can win only before that boundary; a committed receipt must reach core on ACK. Validate optional `SPILING_PROJECT_FAULT=after_assets|before_manifest_replace|after_manifest_replace` at startup; those stages exit 86 for actual-process crash evidence, not power-loss certification.
- Exercise `cargo test --locked -p spiling-engine -- --test-threads=1` with one build job on constrained hosts. Real-child tests cover native inspection, durable project identities, transactions/history pins, lock/recovery/fault behavior and lifetime rules. See [control protocol](../../docs/protocol/control.md), [project format](../../docs/protocol/project.md) and [geometry evidence](../../docs/quality/geometry-evidence.md); compilation alone proves no native or desktop acceptance.
- Manufacturing is software validation only. Compile captures current native definitions, stored source provenance, occurrences and explicit validated inert printer/recipe data. Semantic stale/cancel checks precede publication; reopen/Inspect independently replay persisted programs. Bound per-bundle/old/history/staged bytes, and transfer correlated typed metadata plus exact FrameKind 4 bytes. No physical printer or printability certification.
