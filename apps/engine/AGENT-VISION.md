# Native engine sidecar vision

Compose one supervised authenticated gRPC service shared by desktop and CLI: durable diagnostics, declared planar/cylindrical STEP native geometry, source-backed recoverable project authoring and software-only manufacturing compilation/independent replay. Core owns persistent transactions/storage/history; one session dispatcher and one native worker preserve precise native ownership, source provenance and cancellation-safe promotion ACK.

All long work is admitted into one SQLite Jobs ledger before acknowledgement, scheduled through its shared execution permit and observed through standard Google Operations. Immutable packed mesh/section/bundle descriptors and bytes are durably published after native ACK, retrieved through ByteStream and retained independently of ephemeral native leases. Restart interrupts unfinished operations without recreating handles or resuming work; explicit saved-project open rebuilds native geometry from stored captured assets.

Real-child ordered intent/compile/verify/save, child shutdown, source-independent fresh inspect/replay/export, history/pin invalidation, writer/read-only lock/fault recovery and current diagnostic reconnect/auth/range behavior govern acceptance. General STEP assemblies/freeform geometry, alternate kernels, physical printer execution/printability, manufacturing UI and packaged hardware/graphics certification remain outside this service.
