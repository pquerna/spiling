# Native engine sidecar vision

Compose one supervised native recoverable project-authoring and software-manufacturing service shared by CLI and desktop. The v4 session admits declared planar/cylindrical STEP parts, shares immutable definitions across rigid occurrences, exposes native face provenance and produces bounded face-mapped meshes, occurrence-separated native sections and independently verified software-only manufacturing bundles. Core transactions own editing and bounded session undo/redo; directory checkpoints preserve exact source bytes, manufacturing intent/artifacts and persistent identities.

Core project authority and native ownership are separate: one worker owns BREP and bounded open/save work; the pipe dispatcher atomically publishes derived metadata after promotion acknowledgement and leases immutable packed bytes. Restart starts a fresh session unless a consumer explicitly opens a saved project. Open rebuilds native admission from captured immutable project assets, never external source paths or persisted display meshes.

Lightweight controls remain responsive around non-preemptible upstream calls. Cancellation respects native promotion and durable disk commit boundaries; explicit deadlines interrupt a wedged worker instead of fabricating cancellation. Real-child geometry, authoring, manufacturing replay, lock and process-crash recovery evidence govern acceptance. General STEP assemblies/freeform geometry, physical printer support/printability, manufacturing UI and packaging/physical graphics certification remain outside this service.
