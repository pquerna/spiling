# Native engine sidecar vision

Compose one supervised authenticated gRPC service shared by desktop and CLI: durable diagnostics, declared planar/cylindrical STEP native geometry, source-backed recoverable project authoring and software-only manufacturing compilation/independent replay. Core owns persistent transactions/storage/history; one session dispatcher and one native worker preserve precise native ownership, source provenance and cancellation-safe promotion ACK.

All long work is admitted into one SQLite Jobs ledger before acknowledgement, scheduled through its shared execution permit and observed through standard Google Operations. Immutable packed mesh/section/bundle and opt-in actual-program replay descriptors/bytes are durably published with their exact report/provenance after native ACK, retrieved through ByteStream and retained independently of ephemeral native leases. Replay bytes are bounded transient publication resources, not Core manifest assets. Restart interrupts unfinished operations without recreating handles or resuming work; explicit saved-project open rebuilds native geometry from stored captured assets.

Manufacturing Preflight is a bounded, revision-captured software eligibility report on the same native worker and durable operation lifecycle. It is usable read-only, publishes no artifacts and mutates no Core state; explicit intent, native compilation analysis and independent actual-program inspection remain separate gates, with no physical qualification implied.

Real-child ordered intent/preflight/compile/verify/save, workbench and CLI consumption, child shutdown, source-independent fresh inspect/replay/export, history/pin invalidation, writer/read-only lock/fault recovery and current diagnostic reconnect/auth/range behavior govern acceptance. General STEP assemblies/freeform geometry, alternate kernels, physical printer execution/printability and packaged hardware/graphics certification remain outside this service.
