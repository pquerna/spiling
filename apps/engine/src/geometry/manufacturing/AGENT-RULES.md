# Manufacturing runtime rules

Compose core intent/artifact authority and the public native manufacturer; own no planner, verifier, persistence implementation or printer execution. Checked domain commands use captured ProjectRevision/session checks and typed authenticated gRPC adapters. Reuse the single dedicated native dispatcher/worker, cancellation watchdog, private execution correlations and promotion ACK; the durable Jobs ledger alone exposes public Google Operations. Reject cancelled or stale results before committing PublishManufacturing. After successful intent/publication commits, reconcile native pins with core retained_sources because committing may clear redo or evict source-owning history. Intent/publication and their undo/redo do not advance scene epochs or regenerate geometry.

Compile captures only current stored definitions and occurrences; native definitions remain immutable worker-owned Arc pins. Account old/current/history plus staged encoded bundles against the separate 64 MiB retained budget and the 16 MiB per-bundle cap before serialization growth. Open narrows incoming storage allocation to remaining capacity. Failed stages drop all captured/staged resources and preserve current state.

Compile and Preflight capture the current immutable SurfaceOverlays and ProcessDocument Arcs and one hash-keyed HeightImage map sharing Core canonical byte Arcs in the same snapshot as definitions, occurrences and intent. Manufacturing schema8 fingerprints/provenance include required recipe policies, the full ordered surface-schema3 overlay and process-schema1 document (including disabled layers), and a self-contained unique canonical content table; project format7 stores validated images and source-bound process scopes. Surface/process/intent edits invalidate active artifacts without remeshing; actual-program replay remains SPLR layout3.

Preflight captures the same explicit intent, current source records and immutable native definition pins as Compile, but reserves no bundle/replay bytes and never prepares a Core edit or artifact. Its bounded software-only report crosses the same cancellation, project-revision stale gate and promotion ACK before durable terminal publication. It remains available for read-only projects; missing intent is a typed NoIntent failure. Eligibility does not replace Compile's native layer/support/bridge analysis or physical qualification.

Required workflow, physical skin thicknesses and density are checked shared contracts, never runtime defaults. Complete Marlin jobs and diagnostic body-only output remain distinct explicit workflows; classified coverage and lifecycle reports travel through the same immutable bundle/provenance and typed Compile/Verify interfaces. Replay staging and durable reservations include all four lifecycle records under the shared replay cap, without counting prime material as object deposition.

Open and Inspect independently replay exact persisted bundle content through the public `inspect_bundle` facade; open explicitly selects ReportOnly and never trusts stored verified flags. Inspect captures a retained ManufacturingAsset Arc and explicit output selection without cloning its bundle Vec. ReportAndMotion stages one separately bounded <=16 MiB replay buffer; ReportOnly stages none. The same producer decoder returns report, captured provenance and optional packed actual-program motion. Read-only permits inspection/retrieval but forbids intent changes and compilation publication. After promotion ACK, the dispatcher borrows replay bytes and retained bundle bytes into one terminal ledger transaction, then immediately releases replay staging; terminal jobs retain only metadata. No Core manifest asset, native parser duplicate or raw transfer service is introduced.

Actual-child regressions in apps/engine/tests/manufacturing.rs cover compilation, replay, transfer, history/invalidation, cancellation/staleness, read-only, corruption and fresh-process source-independent reopen. Exercise native engine/client suites and the actual CLI workflow; software validation is not physical printer certification.
