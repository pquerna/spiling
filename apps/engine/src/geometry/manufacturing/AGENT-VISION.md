# Manufacturing runtime vision

Provide one actual-process software-only workflow from explicit inert printer/recipe intent and current native BREP occurrences through compiled, independently replayed immutable bundles, checkpoint storage and fresh read-only reopen/reverification. CLI and shared clients use the same supervised engine jobs and bounded artifact transfer.

Core alone owns persistent intent, revisions, history and bundle storage; manufacturing owns native planning and independent emitted-program decoding. Dispatcher publication remains a cancellation-safe ACK boundary, and recipe/artifact-only changes leave geometry/display caches intact.

No physical printer connection, printability, heating/homing/startup/collision/firmware certification, Blender support, manufacturing UI or alternate geometry path is provided. Acceptance requires real child-process durable artifacts and explicit failure/cleanup behavior, not persisted success flags or preview-only output.
