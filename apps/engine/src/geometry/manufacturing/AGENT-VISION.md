# Manufacturing runtime vision

Provide one actual-process software-only workflow from explicit inert printer/recipe intent and current native BREP occurrences through compiled, independently replayed immutable bundles, checkpoint storage and fresh read-only reopen/reverification. CLI and shared clients use authenticated typed gRPC, standard Google Operations and bounded immutable artifact/ByteStream retrieval from the same supervised engine.

Core alone owns persistent intent, revisions, history and bundle storage; manufacturing owns native planning and independent emitted-program decoding. Explicit report-only or report-and-motion inspection returns captured provenance and optional immutable packed actual-program display through the existing ACK-safe durable job. Replay buffers are transient until one ledger publication, never persisted in the Core manifest. Recipe/artifact-only changes and inspection leave geometry/display caches intact.

Explicit Preflight offers bounded occurrence/face-aware software input eligibility before compilation. It is a nonmutating durable native operation, not an artifact or a machine-readiness certificate; native analysis remains pending until Compile and physical qualification remains absent.

Software support includes explicit diagnostic body-only output or complete declared Marlin 2 lifecycle/backend/independent replay, physical-thickness skins, sparse planar infill and per-layer material ownership. No physical printer connection, printability, heating/homing/startup/collision/firmware qualification, Blender support or alternate geometry path is provided. Actual firmware configuration/calibration measurements and supervised prints remain external gates. Acceptance requires real child-process durable artifacts and explicit failure/cleanup behavior, not persisted success flags or preview-only output.
