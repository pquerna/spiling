# Engine geometry ownership vision

Provide CLI and desktop with responsive native evaluation of one core-owned durable project: declared-profile STEP assets become immutable shared native definitions, placed occurrences and bounded encoded display/section artifacts. Preserve persistent source/occurrence/face identities and precise mm/f64 placement while native handles, display buffers and scene epochs remain disposable session state.

The worker/dispatcher boundary permits atomic import/open publication, cooperative cancellation, stale rejection and bounded transport even when upstream calls cannot be interrupted. History pins native resources so undo needs no source reread or fabricated native reopening. Save checkpoints preserve core history and report the committed outcome at the durable cancellation boundary.

Numerical/native identity, actual child lifecycle, source-independent reopen, software manufacturing compilation/replay and consumer-visible failures govern acceptance. General assembly import, physical printer execution/printability, native plugins and alternate kernels are not responsibilities of this area.
