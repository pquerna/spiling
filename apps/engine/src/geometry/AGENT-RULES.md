# Engine geometry ownership rules

Own transport-independent native execution, derived metadata/artifacts, source capture and the single kernel worker. The authenticated gRPC host runs Runtime on one dedicated dispatcher thread, never Tokio; the durable Jobs ledger alone owns public admission and observation through Google Operations. Private JobId/EngineJob correlations are bounded execution snapshots, not a second public job service. Compose core Project transactions/storage and the public manufacturing compiler/verifier; never maintain a competing authoritative occurrence/intent/artifact map or allocator. Depend on contracts, core and public geometry/manufacturing facades, never Monstertruck directly. Worker command/result slots have capacity one; only one native job is active. Native objects never cross the boundary.

Import/open definitions are staged until Decide/promote and worker ACK. Reserve private native live pins before promotion, but commit prepared core edits or replace the complete project only after ACK. Keep old project/storage/native/history pins while open stages. Cancellation wins before the decision, not afterward; failed/stale/cancelled stages preserve prior state. Reclaim native objects at safe boundaries against the latest replaceable snapshot, counting old/history and staged resources.

Core retained_sources drives bounded definition and mesh pins, including undo/redo. Current snapshot alone drives scene pages/bounds and face references. Definition pins and consumer leases are independent; final current removal retains history resources until history pruning or project replacement. Released-handle tombstones and terminal jobs are bounded; jobs never retain encoded results. Save/open block authoring, while other pre-promotion native jobs can become stale through transactions.
Manufacturing jobs capture persistent ProjectRevision independently of scene epochs; recipe/artifact publication and their undo/redo preserve geometry caches. Native resident definitions use immutable worker-owned Arc pins for the public compiler. Every open replays the loaded bundle before publication. Separate manufacturing byte budgets count old/current/history and staged assets before allocation/growth. Immutable published bundle Arc pins expose retained bytes without cloning their Vec; the host separately persists bounded durable artifact outputs. See manufacturing/AGENT-RULES.md.
Source-face finish edits use ProjectRevision, preserve SceneRevision and native display artifacts, and synchronize retained-source pins after metadata/history transactions. Authoring must validate session, scene, occurrence, definition and face table membership before discarding transient FaceRef identity. Rebuilt and reused native sources validate every persisted target on open; syntactically valid step:N is insufficient.
Image import uses bounded regular-handle source capture and the optional native PNG decoder in surface-fields; Core retains only immutable canonical assets and metadata. Import/GetSurfaceImage carry project revision through the same watchdog/Decide/ACK lifecycle. Import prepares one asset+layer edit, preserving native pins/scene epoch; Get captures an asset Arc and exposes it only after ACK for one ledger PGM transaction, then releases staging. Read-only retrieval never edits history or republishes scene/bundle outputs. Open charges retained plus staged canonical allocations before loading and validates all canonical assets.
Capture the remaining4 MiB canonical allocation budget, including live prepared candidates, into image work before normalization. The normalizer admits actual canonical capacity before PGM copy/PNG canonical Vec growth; source capture and decoder working bytes have separate explicit caps. Even duplicate content needs incoming allocation headroom until Core deduplicates it. Core preparation rechecks retained plus staged ownership at promotion.

All placements and native queries are mm/f64. Prepare each distinct section definition once within the shared 60 MiB source allowance, including pinned proofs; source/query/output coexistence shares 64 MiB independently of the 16 MiB packed-output cap. Subtract every prepared source and the builder's actual retained capacity before a query; bound packing growth while all unconsumed native loops and encoded copies coexist. Geometry owns the actual stored-pose plane pullback, metric errors and canonical world loops; the worker consumes those loops into the single packed builder and releases a source after its last occurrence. Display artifacts are approximations, never native section input.

Use checked shared domain DTOs and typed protobuf adapters; explicitly validate poses, planes and manufacturing specifications before native work. Return semantic failures as domain errors for canonical gRPC Status mapping. Runtime has no framed decoding or binary writers. After ACK/core commit, the host borrows all current scene mesh chunks or section chunks and publishes immutable artifact descriptors into the sole operation/artifact store. Short artifact pages and manufacturing status gain descriptors in that host, never fabricated resources in native execution. See the parent rules and [wire authority](../../../../docs/protocol/control.md). Real child regressions, not source-wiring assertions, govern behavior.

Open/save use captured immutable Core sources/checkpoints; imported Vec bytes transfer into SourceAsset, and reopen never rereads external paths. The 64 MiB admission scope combines retained old/history source allocations, incoming source allocations (including identical IDs), and pinned native query-proof/index capacity. Reserve remaining proof capacity before import growth; this is not a whole-kernel RSS bound. Old plus staged native/artifact budgets remain separate. Replacement may fail even if it would fit after dropping old state. Save uses a job-bound watchdog commit token before manifest replacement; committed receipts survive cancellation. Same-path writer reopen safely reuses retained Storage; read-only takes no writer lock and cannot author/save. Post-publication durability errors return typed failure with the truthful committed checkpoint, never successful durability or cancellation.
