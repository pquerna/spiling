# Durable engine operations rules

- SQLite WAL/FULL synchronization with one exclusive owner lock owns admission/deduplication and operation/artifact publication. Persist admission before acknowledgement; detached admission and execution survive RPC drop. Supplied nonzero UUID retries deduplicate identical typed method/parameters while retained; conflicts return ALREADY_EXISTS.
- One ledger and shared execution permit schedule diagnostics and native work. Native Runtime/Worker/Watchdog owns private execution correlation only; it is not an exposed jobs API or a second scheduler. Tokio never executes native/kernel/storage work; the session dispatcher hands work to the bounded native worker and publishes after promotion ACK/Core commit.
- Once native work starts, transient control-queue backpressure retains its execution permit/correlation and retries bounded queue admission. Unexpected active observation/publication failures interrupt the session rather than terminalizing the ledger while Runtime may still commit. Persisted Cancelling is sticky across progress; only ACK-authoritative terminal publication may supersede it.
- Preserve distinct DiagnosticMetadata/Result and NativeOperationMetadata/Result codecs. Native metadata binds session, captured scene/project revisions, state/version/timestamps, progress and immutable outputs. Carry captured ProjectRevision into execution: queued Save rejects any intent/artifact/history-only revision change before capturing a checkpoint. Typed domain Status details preserve original native errors. Terminal states never change; unfinished restart/shutdown operations become INTERRUPTED/ABORTED without automatic replay.
- Admission bounds: 128 retained operations and eight pending across both classes. Diagnostic reservations retain the existing 32 MiB store budget and 256 KiB chunk cap. Native durable reservations and unique immutable blobs are separately capped at 256 MiB; import reserves 64 MiB, section/compile/verify 16 MiB, open 80 MiB, save zero. Completion replaces the native reservation with newly stored unique output bytes; failure releases it, and already retained content is not charged again. Native mesh/section chunks cap at 1 MiB, bundle at 16 MiB; independent session/native/history/staged budgets remain in Runtime.
- Native success publishes only after ACK, including truthful committed save receipts even if cancellation arrives after CommitToken wins. Capture outputs before another short scene edit can run; descriptors/hash/size are checked against encoded native metadata. Borrow core bundle Arc bytes into one SQLite transaction with terminal operation state: this is a distinct durable output copy, not zero-copy. No extra whole-bundle Vec clone.
- A committed Save with durability uncertainty remains a terminal Error carrying original Project Io detail plus its operation-specific checked NativeOperationResult ProjectSaved receipt in Status.details. Only this save-uncertain receipt may accompany an error; do not infer it from a later Get or lose SaveAs attachment identity.
- SQLite publication failure after native/disk commit interrupts the process (exit 70), never reports cancellation/rollback or fabricates success. Restart retains an Interrupted operation; clients explicitly reopen/reconcile the committed checkpoint without automatic native retry. Commit-winning cancellation and terminal late-cancel immutability have ledger and actual-child save regressions.
- Coalescing watchers expose latest complete committed snapshots, not event history. Artifacts reference complete immutable SQLite blobs. Store media types explicitly for native formats. Standard ByteStream range/clamping semantics and download/observer limits remain unchanged.
- Native session handles/pages expire independently of durable historical Operations/blobs. Same-request retained retry precedes live-session validation; new work must target the current canonical session. Historical success never becomes active scene state. Cancellation records durable intent and reaches the shared native commit decision lock; it does not promise rollback after commit.
- Exercise actual-child diagnostics and geometry/project/manufacturing suites, including cancellation/race/restart/auth/deduplication/capacity/range/recovery. Run native workloads sequentially under externally enforced memory/task limits on constrained hosts.
