# Native workbench

- `host` exclusively owns EngineClient: two Tokio workers with 8 MiB stacks, eight bounded controls and coalesced snapshots. Admit effects in `App::logic`; redraws repeat. Request acknowledgements differ from background publication.
- Retain accepted Google operation names through observed terminal outcomes. Resume/Cancel explicitly; never retry uncertain mutations. Only matching Open/ProjectSaved receipts attach confirmed routes; failed ProjectSaveUncertain receipts and disconnected unresolved saves retain the authorized attempted target as uncertain without automatic restart/reopen. Dirty discard rechecks identity/revision. Close/Drop await cleanup and child reap.
- NativePath preserves encoding; parented pickers/launch arguments supply paths. Preferences contain theme/license assent and bounded project-keyed inspection views, never project authority. Diagnostics have separate checked artifacts; triangles never substitute for BREP.
- Forms preserve full intent/scopes/layers, capture revisions, retain rejected drafts and commit once on Apply. Core owns scope/inheritance/history. Load bounded inert profiles/catalogs without mutation; engine review binds project/session/revision and exact catalog/query/page. Search/inspection works read-only; only Apply mutates. Engine resolution preserves capture and explicit override provenance. Material-bound recipe fields have one editor. Canonical image previews use checked stored assets, never require original files.
- `scene` atomically publishes checked pages/chunks; occurrences share immutable definitions. Source/section retain their checked display envelope; replay CPU retention uses fresh machine/container headroom and checked disk backing. Rebase f64 before f32; refuse excess error. Stale/paused displays cannot pick/edit. Geometry-only definitions retain face-list inspection. Shared section planes/cameras are transient inspection; GPU caps never mint FaceRefs. Native contours bind the current plane/session/revision; sampled measures retain allowances and cannot stand in for constructed-solid authority.
- `manufacture` separates fresh inspection from stored verification and input-revision provenance. Bind revision/session/record/resource after retrieval and before exclusive export; edits/history invalidate motion. SPLR batches preserve event ordinals and immutable filter ranges; epochs never connect and pressure events are stationary. Nominal beads retain endpoints/physical intervals and explicit breaks; failed numerical/chord bead qualification preserves centerlines. Shared compact tables feed every replay pass; backed pages decode off UI with backpressure, uploads are staged and incomplete loading is visible. GPU allocation failure preserves verified export; uploaded GPU pages currently remain resident. Envelopes/tints never establish mass or physical shape.
- Try and Compare retains one explicit trial separately from Current drafts. Checked reference/candidate captures share the display budget; A/B maps physical height, not layer index. Only a matching observed adoption receipt ends the trial. Keep is not Apply, and candidate inspection never redirects Current export. See [ADR010](../../docs/adr/010-manufacturing-alternatives.md).
- Prepare/Review/Analyze retain per-plate tasks; properties and section inspection stay available across phases. Analyze authors Basic/Enhanced FDM cases; its bounded assumed-law macro consumer displays checked engine fields, not qualified Basic/Enhanced or strength. Keep current/stale capture, actual scale/units, assumed tied/effective laws and numerical versus authoring costs visible. Last success survives failure/cancellation. Explicit engine-owned attachment then Save publishes portable fields; native open/case selection restores them without solving or an old Jobs store, including read-only mode. Read revision and original numerical capture revision stay distinct. Menus, contextual commands and palette share typed Action enablement/dispatch. Navigation retains drafts; Slice refuses unapplied changes. Color study returns to its invoker. Compact command groups overflow rather than wrap workflow tabs. Text/IME retains editing shortcuts; canvas keys require its focus.
- Reference acquisition shares `ui::CatalogSearch` and the same imported/manual editors. Reading/searching does not write inventory. Hide stale-query rows; Enter reviews only a selected current result. Unconfigured printer inventory remains editable but cannot supply project hardware. Keep editor Add/Save and discard controls visible outside body scrolling. Setup editing changes machine facts and re-derives the printer through the contracts derivation; never edit derived printer fields directly. Custom setups start from a machine-description setup for any printer.
- Stock matching uses the shared engine Operation and checked immutable report. Keep binds current project/revision and exact reviewed ingredient refs; source edits never substitute current same-name definitions. Result groups/review are presentation only; use ordinary recipe capture, fresh study and construction transactions.
- Use `ui::ColorPresentation` for color fields and compact summaries: explicit meaning, known/unspecified sample, declared-name precedence and shared density/disclosure. Supply a stable owning field/row ID. Naming modes belong only to the reference inspector. Numeric samples and material identity remain authoritative; no stock-color inference or optical evaluation in UI.
- Plate navigation protects unapplied drafts; structural sheets close only on matching engine receipts. Camera/section/replay view state is bounded by layout ID. One current decoded output is retained; physical sheets remain My Hardware inventory.
- Follow [native interface conventions](../../docs/quality/native-interface.md): title/scope, grouped body, one primary action, visible reason and explicit exit. Analyze uses a pinned Apply/Run action and one scrolling body; compact assumption/freshness state stays visible while detailed qualifications/costs live in Evidence. Attach fastener uses native scene-bound bore preparation and one explicit placement; shaft/seat/motion ghosts remain bounded display data. Explicit assumed reference models never derive laws from catalog identity. Its checked 3D cell exterior and source-boundary markers are display only; reserve CPU/GPU bytes, retain exact cell samples and rebase before float projection. Closing section analysis ends its cut; closing help restores focus without closing its parent.
- `ui` shares production/gallery Graphite/Paper controls. Numeric field scopes retain typing/focus when draft warnings change form layout; labels are unique within the caller's form scope. Inspection stays off in distributions. [Development](../../docs/quality/development.md#native-egui-workbench) owns commands, actual-surface procedures and limits; [ADR006](../../docs/adr/006-native-egui-workbench.md) owns architecture.
