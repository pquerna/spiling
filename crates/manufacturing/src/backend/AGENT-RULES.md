# Typed Cartesian backend rules

Emit only validated inert specifications and normalized paths. `DiagnosticBodyOnly` uses CartesianAbsoluteGcodeV1; `CompleteMarlin` uses Marlin2SingleExtruderGcodeV1; `FixedDualMarlin` uses Marlin2FixedDualGcodeV1. These are explicit workflows, not compatibility aliases. No macro strings, arbitrary firmware commands, connectors or qualification claims.

Diagnostic and single-extruder complete jobs establish G21/G90/M82/G92 E0. Single-extruder complete jobs additionally establish Celsius with M149 C, reset M200 D0, M220 S100, M221 S100 and M107; home all axes with G28; disable leveling with M420 S0; wait on bed M190 R and nozzle M109 R; position then prime with one bounded linear deposition. The pure realization stream owns ordered object/support entry, first-layer/bridge factors, M106 S0..255 cooling and conditional external retraction/Z-hop/recovery. Single-extruder complete jobs finish with M400, vertical clearance lift from the actual realized endpoint, XY park, M400 and heater/fan/motor shutdown. No implicit process defaults, mesh leveling, firmware G10/G11 or user macros.

The reviewed single-extruder [Marlin 2 contract](https://marlinfw.org/docs/gcode/G028.html) assumes one Cartesian XYZ extruder, native unshifted coordinates, no workspace/home offsets, tool offsets, skew, leveling, firmware retraction, mixing, volumetric limits, linear-advance extrusion modification or fixed G0 feed overrides. Configuration must support M200, M420 and M149 (`TEMPERATURE_UNITS_SUPPORT` enabled); no restoring/enabling leveling after homing. Configuration and calibration records are named by hashes; these assertions are not measured hardware truth. [M149 C](https://marlinfw.org/docs/gcode/M149.html) establishes Celsius rather than assuming inherited units; [M200 D0](https://marlinfw.org/docs/gcode/M200.html) selects filament-length E; [M190 R](https://marlinfw.org/docs/gcode/M190.html)/[M109 R](https://marlinfw.org/docs/gcode/M109.html) wait both directions; [M400](https://marlinfw.org/docs/gcode/M400.html) completes queued motion before shutdown. Homing trajectories are firmware-owned and excluded from command-space inspection/collision certification.

All interpolated moves carry XYZ and F (mm/min); deposition carries increasing absolute E (filament mm). Retract/unretract is E-only G1 with explicit F at known stationary XYZ; decreasing E may be negative and exact recovery contributes no deposited material. XYZ/F precision is six decimals, E eight. Cooling uses ordinary default print fan M106 S0..255 for the next queued motion, without LASER_SYNCHRONOUS_M106_M107; configuration declarations must admit external E-only retraction. Thermal targets/limits are finite integral Celsius degrees, matching firmware integer targets. No physical fan/temperature truth is inferred.

The fixed-dual branch is pinned to the reviewed Marlin source/configuration with two independently fed coplanar fixed hotends. Establish addressed flow resets, explicit M218 offsets (including Z0), and T0 S1 before native homing; G92 E0 follows known home. All real selections use M400, outgoing external retract, vertical clearance lift, addressed standby, Tn S1, G92 E0, addressed M109 R, exact incoming E8 debt recovery, lifted travel and one supported waste stroke per actual layer/tool. S1 shifts logical tip coordinates without carriage motion or E change; resets never pay feeder debt. The realization stream owns all route motion and uses one all-layer safe plane, never a second motion vector. Both loaded tools must deposit model on each actual layer. The backend bounds total model/waste/travel/process growth and independently checks actual XYZ6/E8/feed/flow, carriage bounds and conservative inactive-tip/body exclusions before returning any artifact. Final active retract, clearance park and separately addressed shutdown are mandatory. Fixture components have no admitted fixed-dual swept route and refuse. These finite software exclusions are not physical collision qualification.
XYZ6 endpoint projection and physical-decimal bead enclosures belong solely to `contracts::manufacturing::program_coordinates`; backend owns formatting, verifier owns independent parsing and exact correspondence to the projected endpoint. Support contact is a minimum actual emitted full-bead gap, never nominal height plus epsilon. Unrepresentable coordinates refuse with `program_coordinate_conditioning_failure`.
Every rounded lifecycle/object endpoint remains in the specified command envelope; complete park Z must strictly clear all object/prime Z and remain representably higher after rounding. The complete priming segment must not touch/intersect the full all-layer XY deposition bounds expanded by half bead width, two XYZ6 half-steps and scale-aware arithmetic slack; check both specified and rounded endpoints. Protected holes, interior gaps or higher prime Z are not exemptions. This conservative command-space ownership exclusion is not toolhead collision certification; component shapes remain metadata.
The explicit current Cartesian XYZ6 output contract lives in `contracts::manufacturing::program_coordinates`; its `project_xyz6_coordinate_mm` is the sole endpoint projection used by the emitter and support proofs. Carry `xyz6_coordinate_error_mm` for remaining physical-decimal representation error, not geometry-policy slack. Future dialects must explicitly choose their coordinate contract. Clearance must certify actual projected endpoints, never independently repeat rounding or treat a Boolean work pad as a geometric enclosure. Shared encoding rules do not make emitter output an independent replay certificate.
The final nominal-program footprint gate projects both support/interface and object/Bridge endpoints through that contract, carries remaining decimal error on both sides, and uses each declared bead's full height. Native continuous-target exclusion cannot stand in for actual emitted bead clearance when bounded approximation or coordinate quantization extends M/D beyond true source C. The geometry capsule-pair predicate owns the full-segment distance proof. Every actual support/object pair must either prove the requested minimum vertical gap conservatively, in either direction, or prove unchanged XY capsule clearance; merely non-overlapping Z intervals do not discharge the requested gap. Actual selected support contacts additionally prove the declared Z gap as a conservative minimum after final raster/anchor changes; neither an exact physical attachment nor an exact requested gap is promised. Emitter/decoder agreement does not itself prove these properties or physical collision freedom.

Object/support nominal commanded volume is actual projected XYZ6 chord length times `(width-height)*height + PI*(height/2)^2` using each consumed edge width and physical interval height, with applicable flow factors exactly once. Never substitute recipe width, unrounded source chord or nominal reporting height. Divide by round filament area for absolute E; prime and recovery remain distinct. Independent replay decodes actual chords/E and separately checks source endpoint fidelity. Algebraic width-equivalent intervals retain actual parsing/subtraction uncertainty, not intended-accumulator E8 quantization bins; rounded circular nominal targets are admitted by nominal geometry plus forward E8 fidelity, without clamping inverse bounds or weakening process/gradient checks. Reject precision collapse, actual envelope/feed/flow/resource excess; poll cancellation and stream one bounded program. Public emit is not verification.
