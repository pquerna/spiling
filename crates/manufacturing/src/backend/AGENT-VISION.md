# Typed Cartesian backend vision

Realize explicit inert printer/job data as deterministic bounded Cartesian programs. Diagnostic body-only output remains an intentional software inspection workflow. Complete single-extruder jobs and the pinned two-fixed-hotend route encode their reviewed conventional Marlin lifecycles, including modal/frame resets, native homing, heating/cooling waits, bounded supported priming/waste, object deposition, final barriers and clearance park/shutdown. This finite routing policy is not a general multi-material scheduler.

The complete executable command sequence is software-verified, not physically qualified. Named machine, firmware, configuration and calibration provenance are declarations; real hardware selection, configuration review, measurements and supervised prints remain an external acceptance gate. No macros, arbitrary dialects, connector, universal scheduler, automatic calibration, support generation or collision/printability claims.
