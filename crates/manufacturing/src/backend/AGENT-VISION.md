# Typed Cartesian backend vision

Realize explicit inert printer/job data as deterministic bounded single-extruder Cartesian programs. Diagnostic body-only output remains an intentional software inspection workflow. Complete jobs encode the reviewed conventional Marlin 2 lifecycle, including modal resets, native homing, heating/cooling waits, bounded priming, object deposition, final barriers and clearance park/shutdown.

The complete executable command sequence is software-verified, not physically qualified. Named machine, firmware, configuration and calibration provenance are declarations; real hardware selection, configuration review, measurements and supervised prints remain an external acceptance gate. No macros, arbitrary dialects, connector, universal scheduler, automatic calibration, support generation or collision/printability claims.
