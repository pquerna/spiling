# Pure process realization rules

Canonicalize existing normalized paths in place, then stream typed process events to the bounded emitter. Do not format/parse programs, access native geometry/storage, retain a motion/index vector, or call the independent verifier. Sorting/rotation/reversal must be explicit in the stored normalized plan; streaming borrows it with constant-size event state.

Canonicalization orders supports/interface before object roles with deterministic role/XY/point ties. Perimeter seams consume the recipe's nearest/preferred build-XY policy at existing XYZ6 vertices, including projected previous position/prime endpoint and deterministic exact ties; preserve winding and explicit closure. Other roles retain nearest-entry closed seams/open direction. The emitter and independent verifier consume stored paths directly, never another route algorithm. Preserve every admitted path/edge, including coincident entry travel. Nominal bead area uses each path's required width and physical-Z interval height, never recipe width or layer reporting height; compose first-layer/bridge factors. Cooling is queued ordinary default-fan PWM, not a physical measurement.

Only travel meeting the explicit threshold with known current XYZ retracts. Emit decreasing stationary absolute E, optional vertical/XY/landing hop in envelope, then exact recovery to pre-retraction cumulative E. Recovery adds no deposited material. Enforce separate travel/process budgets before sink growth; emitter checks rounded coordinates, feed, E precision and flow. Complete-job prime and final lift/park stay lifecycle-owned.

Fixed-dual jobs first partition complete paths through the contracts reservation helper, then apply the existing precedence/ties within tool-zero and tool-one groups on each actual layer. Each group's seam/entry reference is its actual projected waste endpoint, not the previous tool's model endpoint. Each contiguous bed-rooted fine interval has model work; either tool group may be waste-only. Always emit both groups and supported waste lanes, including tools with no model work for the whole job. Body recipe retraction is disabled: real selections alone create per-feeder external debt from the outgoing actual E8 tick difference, and incoming recovery repays that debt after the epoch's G92 reset. Stream explicit barrier/selection/reset/addressed thermal events and exactly one stroke-derived supported waste line per tool/layer. Every model entry uses vertical lift, horizontal travel at the final-model-top plus declared lift, and descent; no copied motion/index list or hidden seam scheduler.

Acceptance includes independent numeric process goldens, byte mutations of fan/feed/flow/recovery/hop, support-only and real gap layers, variable-height properties and seam/direction determinism. Parent runs checks once integrated. All output is software-only and physically unqualified.
