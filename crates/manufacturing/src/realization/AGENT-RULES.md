# Pure process realization rules

Canonicalize existing normalized paths in place, then stream typed process events to the bounded emitter. Do not format/parse programs, access native geometry/storage, retain a motion/index stream, or call the independent verifier. Sorting/rotation/reversal must be explicit in the stored normalized plan; streaming borrows it with constant-size event state.

The shared deposition-routing crate owns task order, permitted direction/seam and authored wall seam policy. The adapter borrows path terminals, physical intervals and exact separator wall/skin attachment prerequisites; a barrier retains each actual fine layer. No universal role sort or private row router remains. Apply a checked permutation in place with edge widths and directed wall closure preserved, then release transient decisions before streaming. Nominal bead area uses each path's width and physical interval, with first-layer/bridge flow factors. Feeds follow only the declared speed rule in `contracts::manufacturing::speeds` (role speed or uniform speed with factors, per-edge flow ceiling, per-layer cooling scale, `speed_role` for sparse-region bridges, the path's `exposed` flag for outer walls and exposed top skin); fan PWM follows `path_fan_pwm`. A single-tool flow excess slows, never refuses. Later-layer temperature targets precede the first path above layer 0. Cooling remains queued policy, not a measurement.

Before scheduling, `connect.rs` joins clipped road ends along the inside of walls into continuous paths, recording each connector as a `ConnectorRun`; it never moves a road, skips constructions that name individual rows, roads under support within the support gap and connectors near next-layer bridges, relabels a sparse region's Bridge row SparseFill only when it follows its authored axis and the connected layer below supports it throughout; connectors below an orthogonal sparse Bridge preserve its original gap and Bridge construction, and recomputes the layer's nominal volume. Between connecting and scheduling, `lower.rs` simplifies structure-class roads (RFC 11): non-exposed Wall perimeters, covered skin and solid fill, non-skin Bridges and support interface drop points by Douglas–Peucker within `road_tolerances.structure_mm - PROFILE_TOLERANCE_MM`; exposed walls and exposed top skin (the surface class) never change. A wall path is `exposed` only when every edge is on the outermost lane, so a non-exposed wall point moves only beside an exposed wall (within 1.25 mean bead widths); without that, it may be on the surface. Fixed points: path ends, arc and connector runs, width and Z changes; new chords are at least 2.5× the minimum command; closed loops keep four points; the layer's nominal volume is recomputed. Roads elsewhere are proved against these exact roads, so lowering keeps exact every edge near this layer's connectors and separator bond wall segments, under next-layer non-wall Bridges (whole) and row ends (1 mm of each road end of skin, solid and wall Bridge rows), under support up to its contact gap, where a next-layer road runs along its rim (half its width ± budget, within 30°), and every point not deep inside the layer below's model roads. Fixed-dual jobs are not lowered. A verifier refusal after lowering is a lowering bug: add the coupling here, never relax the check. After scheduling, arc runs are lowered in the plan: keep a run only where the dialect's declared firmware segmentation stays within `MAX_FIRMWARE_ARC_DEVIATION_MM` (worst rounding-reachable segment count) and its ends are `MIN_ARC_CHORD_MM` apart; clear all runs when the printer has no arcs. Lowering only removes arcs, never refuses, and the emitter then writes every remaining run.

Only travel meeting the explicit threshold with known current XYZ retracts. Emit decreasing stationary absolute E, optional vertical/XY/landing hop in envelope, then exact recovery to pre-retraction cumulative E. Recovery adds no deposited material. Enforce separate travel/process budgets before sink growth; emitter checks rounded coordinates, feed, E precision and flow. Complete-job prime and final lift/park stay lifecycle-owned.

Fixed-dual paths follow the captured per-layer permutation of both tools, including empty model groups. Both tools retain supported waste on every fine interval. Each group's entry reference is its actual waste endpoint. Actual switches alone barrier/retract/lift/stage before selection/reset/wait/recovery; adjacent same-tool groups retain wait/safe-plane/waste without inventing feeder debt or selecting/resetting the same tool. Every model entry uses the final-model-top clearance plane. Backend and independent byte replay consume stored order rather than running a second scheduler.
Every task carries its plan layer. The scheduler searches each layer in parallel from two starts (the job start, and the first pass's end of the layer below) and keeps per layer the candidate with less travel from the actual previous end; wall seams are then authored in one serial pass from the actual previous end. Distributed wall starts maximize the dot product with a compass direction from the layer index and the loop's least projected vertex; no history crosses layers. Preserve existing previous-position/coordinate ties and all path geometry/widths. This is placement, not contour tracking or guaranteed physical separation. The independent verifier reconstructs the policy without importing realization helpers.

Acceptance includes independent numeric process goldens, byte mutations of fan/feed/flow/recovery/hop, support-only and real gap layers, variable-height properties and seam/direction determinism. Parent runs checks once integrated. All output is software-only and physically unqualified.
