# Pure process realization rules

Canonicalize existing normalized paths in place, then stream typed process events to the bounded emitter. Do not format/parse programs, access native geometry/storage, retain a motion/index stream, or call the independent verifier. Sorting/rotation/reversal must be explicit in the stored normalized plan; streaming borrows it with constant-size event state.

The shared deposition-routing crate owns task order, permitted direction/seam and authored wall seam policy. The adapter borrows path terminals, physical intervals and exact separator wall/skin attachment prerequisites; a barrier retains each actual fine layer. No universal role sort or private row router remains. Apply a checked permutation in place with edge widths and directed wall closure preserved, then release transient decisions before streaming. Nominal bead area uses each path's width and physical interval, with first-layer/bridge flow factors. Feeds follow only the declared speed rule in `contracts::manufacturing::speeds` (role speed or uniform speed with factors, per-edge flow ceiling, per-layer cooling scale, `speed_role` for sparse-region bridges, the path's `exposed` flag for outer walls and exposed top skin); fan PWM follows `path_fan_pwm`. A single-tool flow excess slows, never refuses. Later-layer temperature targets precede the first path above layer 0. Cooling remains queued policy, not a measurement.

Only travel meeting the explicit threshold with known current XYZ retracts. Emit decreasing stationary absolute E, optional vertical/XY/landing hop in envelope, then exact recovery to pre-retraction cumulative E. Recovery adds no deposited material. Enforce separate travel/process budgets before sink growth; emitter checks rounded coordinates, feed, E precision and flow. Complete-job prime and final lift/park stay lifecycle-owned.

Fixed-dual paths follow the captured per-layer permutation of both tools, including empty model groups. Both tools retain supported waste on every fine interval. Each group's entry reference is its actual waste endpoint. Actual switches alone barrier/retract/lift/stage before selection/reset/wait/recovery; adjacent same-tool groups retain wait/safe-plane/waste without inventing feeder debt or selecting/resetting the same tool. Every model entry uses the final-model-top clearance plane. Backend and independent byte replay consume stored order rather than running a second scheduler.
The scheduler's distributed wall starts maximize distance from a fixed eight-start same-tool history across scheduled layers; non-Wall/open paths never enter it. Preserve existing previous-position/coordinate ties and all path geometry/widths. This is bounded job-wide placement, not contour tracking or guaranteed physical separation. The independent verifier reconstructs the policy without importing realization helpers.

Acceptance includes independent numeric process goldens, byte mutations of fan/feed/flow/recovery/hop, support-only and real gap layers, variable-height properties and seam/direction determinism. Parent runs checks once integrated. All output is software-only and physically unqualified.
