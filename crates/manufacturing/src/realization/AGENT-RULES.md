# Pure process realization rules

Canonicalize existing normalized paths in place, then stream typed process events to the bounded emitter. Do not format/parse programs, access native geometry/storage, retain a motion/index vector, or call the independent verifier. Sorting/rotation/reversal must be explicit in the stored normalized plan; streaming borrows it with constant-size event state.

Canonicalization orders supports/interface before object roles with deterministic role/XY/point ties, nearest-entry closed seams/open direction and original vertex ties. The emitter and independent verifier consume stored paths directly, never another route algorithm. Preserve every admitted path/edge, including coincident entry travel. Use true height for nominal bead area; compose first-layer/bridge factors. Cooling is queued ordinary default-fan PWM, not a physical measurement.

Only travel meeting the explicit threshold with known current XYZ retracts. Emit decreasing stationary absolute E, optional vertical/XY/landing hop in envelope, then exact recovery to pre-retraction cumulative E. Recovery adds no deposited material. Enforce separate travel/process budgets before sink growth; emitter checks rounded coordinates, feed, E precision and flow. Complete-job prime and final lift/park stay lifecycle-owned.

Acceptance includes independent numeric process goldens, byte mutations of fan/feed/flow/recovery/hop, support-only and real gap layers, variable-height properties and seam/direction determinism. Parent runs checks once integrated. All output is software-only and physically unqualified.
