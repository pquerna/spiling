# Independent replay vision

Provide bounded independent software evidence that actual emitted bytes realize explicit normalized paths and typed machine-job intent. Diagnostic body-only and complete Marlin single-extruder workflows have separate required semantic sequences. Complete jobs verify modal setup, native homing declaration, thermal waits, bounded priming, deposition and final barrier/clearance-park/shutdown. Coordinate, feed, extrusion and command mutations fail rather than approve a preview.

Optional packed inspection streams actual object, support, stationary process and lifecycle commands, retaining normalized layer/role attribution separately and excluding firmware-owned homing trajectories. Priming, object filament, support filament and stationary recovery are distinct totals. Cooling state is independently decoded for the next queued block, not displayed as invented motion. No matching-emitter comparison, copied motion vector or second program parser.

Software semantics do not establish hardware truth, thermal behavior, firmware/configuration/calibration accuracy, collision clearance, mechanical/material performance or physical printability. Real printer metadata/configuration review and measurements are required before physical qualification; no connector or permission-to-print claim follows from a successful report.
