# Independent replay rules

Decode actual program bytes without importing backend formatting, parser or extrusion helpers. Validate bounded intent and normalized plan; consume expected path points through a borrowed iterator, never rebuild expected program/motion vectors. Persisted verified flags are not authority. Unknown macros/commands, duplicate/malformed fields, extra/missing/reordered modal/lifecycle operations and unsafe/mutated moves fail.

Diagnostic body-only sequence is G21/G90/M82/G92 E0 then G0 path starts/G1 deposition. Complete Marlin jobs additionally require M149 C (Celsius, `TEMPERATURE_UNITS_SUPPORT`), exact ordered volumetric/feed/flow/fan resets, G28 native homing declaration, M420 S0, M190 R/M109 R heating-and-cooling waits, explicit bounded prime, object motions, final M400, vertical clearance lift then XY park, M400 and heater/fan/motor shutdown. See the backend's [reviewed Marlin contract and primary source evidence](../backend/AGENT-RULES.md). Independent lifecycle decoding must not call backend helpers or silently model physical homing trajectories.

All interpolated motions require XYZ/F, deposition requires positive absolute E deltas. XYZ6/F6 comparisons use half-step0.0000005 plus scale-aware arithmetic slack; E8 absolute uses0.000000005, deltas twice that. Thermal specifications are finite integral Celsius degrees matching firmware integer targets, never fractional fictional precision. Plan tolerances do not enlarge replay bounds. Validate actual command-space endpoints, printer feeds and decoded flow. Independently reject actual decoded priming segments touching/intersecting the validated full all-layer XY ownership bounds expanded by half bead width and serialization/roundoff padding; no hole/gap/Z exemption or toolhead collision claim. Obtain those bounds with one allocation-free plan validation traversal, not a second parser or polygon copy. Nominal bead is `(width-height)*height + pi*(height/2)^2`; prime filament is specified separately from object volume/filament totals. Every layer requires actual deposition.

An optional SPLR schema2 sink receives only accepted actual f64 XYZ/E/F and source lines. Body layer/kind attribution is expected-plan metadata, numeric values are actual commands. Kind0 travel,1 perimeter,2 solid,3 bottom skin,4 top skin,5 sparse,6 lifecycle travel,7 prime; lifecycle layer65535 is never an object layer. Homing motion is excluded; first interpolated endpoint has unknown start. Header remains96/record48, lifecycle_count at28, at most200004 events/16MiB. Preserve body deposition/path counts; lifecycle_count is separate (0 or4). Reserve checked bytes once, no per-motion objects and no replay allocation/hash for report-only. Failure/cancellation drops unpublished bytes. Packed contract admission is not another program parser.

Reports distinguish verified software lifecycle/modal/wait/barrier/command-space semantics from excluded thermal sensor truth, actual firmware/configuration/calibration, homing trajectory, physical startup state, collision/fixture clearance, support, mechanics/material and printability. Successful replay is not permission to operate a printer. Adversarial tests mutate real emissions and use independent numeric goldens; parent runs all checks after owners land.
