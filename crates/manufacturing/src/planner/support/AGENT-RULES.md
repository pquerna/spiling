# Deposited-anchor bridge and breakaway support rules

Own actual nominal deposited-footprint bridge classification and bounded vertical breakaway realization inside the native planner. Native object partition/source identity is immutable. Previous full material domains are never support certificates for sparse interiors. Intersect each candidate centerline analytically with the union of previous actual stroke capsules: declared half-bead radius, exact perpendicular strip and endpoint-circle intervals, with no polygonized-circle or overlay tolerance expansion. Interior anchors require positive-length intervals; isolated tangent points do not suffice. Separately certify positive-area overlap of the actual candidate endpoint disk and previous nominal capsule iff exact point-to-segment distance is strictly below the sum of their declared radii. Equal-distance tangency has zero area. This endpoint proof does not dilate interior capsules, add material or shorten uncovered centerline spans. Bound every two-ended free span using the sole `process.max_bridge_span_mm`; only half-bead-sized one-sided nominal overhangs are tolerated without support. Preserve closed contours under whole-contour Bridge role and account actual bridge/first-layer flow separately from support.

Native line sampling must not destroy continuous anchoring. Analyze maximal straight runs across contour seams with roundoff-only collinearity while preserving all original points; curved samples remain separate. Fully unanchored tiny strokes never inherit the half-bead overhang allowance. Capsule intervals and actual endpoint-area certificates separate direct previous-layer anchors from intentionally lower interface contacts. Only direct anchors at both ends certify Bridge; bounded contact-resolved deposition retains its object role.

Before support publication, evaluate both allowed orthogonal hatch axes whenever the preferred axis leaves demand; parity is only a tie-break. Regenerate alternatives from unchanged classified realized domains D (native M union admitted finish A), never native-only replacements. Whole perimeter-owned fill rows can coalesce already-required same-emitted-row pieces only if complete contiguous coverage and a bounded direct-anchor Bridge are proved. Never add a sparse piece/row, change area partition, widen anchor/native/finish tolerances or mutate admitted contour points. After support generation revalidate every realized object stroke, choose a genuinely anchored axis against actual contact paths and recreate composites if their old Bridge proof is stale. Stage only bounded current-layer alternatives and ownership metadata.

Group unbridgeable actual-stroke demand per contact layer. Disabled support refuses with useful layer/Z/limit diagnostics. Enabled support must declare capability and density/XY gap/Z gap/interface thickness. Only after strokes prove demand may final realized D provide a conservative corridor candidate; full material never becomes a deposited anchor. Before publishing a fixed-XY column, clip through every bed-to-contact realized D slab, excluding its declared XY clearance and all protected native holes. Image overlays change the entire lower shaft/corridor dependency, not only a fixed last-N-mm tip window. Both regenerated orthogonal object rasters retain the identical D ownership. No branching, floating column or global-any-overlap bed proof. Erode the combined physical support domain S once by half a bead. Interface subset I partitions centerline roles/densities, not physical material boundaries: preserve every outer/hole wall edge, add no seam outlines, and permit bead overlap across the role seam while keeping all nominal beads inside S. Independently eroding I and S-minus-I is forbidden. Revalidate actual object/support/contact strokes before publishing; declared Z gap is an outward-proved minimum separation between actual XYZ6 full-bead enclosures, not a nominal epsilon or exact attachment. Shared `program_coordinates` helpers own point and segment height enclosures. Output-aware support-stop events reserve representation/arithmetic error, check the projected upper enclosure, retreat one quantum if needed and refuse if still unprovable; never move true native/field events to fit contact. Select the latest provably safe scheduled top and recheck final actual object/interface paths under the existing bounded support-work budget.

Share immutable fixed-XY corridor contours across unchanged layers rather than cloning full point arrays. Reuse unions for identical incoming owners while the immutable candidate column is fixed; weak cache keys retain no old contour arrays. Avoid redundant role-partition Boolean work for empty or shared whole-interface coverage. Retained-budget accounting may conservatively count shared owners repeatedly, but never allocate an unbounded deduplication map. Support raster candidates use preferred then orthogonal axes only after actual prior-support admission; charge every attempted candidate's work and live staging, release rejected candidates before retry, and commit only selected output segments.

Return separate support area/nominal volume; include support paths in combined segment admission. Borrow filtered prior path/point arrays and reuse one bounded interval workspace; retain no polygonized alternate anchor map or copied motion plan. Charge native/corridor/interface/protected/temporary contours and combined interval/gap records against the remaining retained-geometry budget. Bound cumulative Boolean/projection and actual segment-pair intersection work, finite arithmetic and hatch rows; check cancellation during each stage/edge. Owning tests use genuine box/hole occurrences for cantilever, floating, mixed closed bridges, blocked-plus-valid components and clearance/bridge/gap refusal; pure mathematical regressions cover exact circular caps, sparse void, shrinking-wall anchors and positive support-wall entry. Independent emitted replay and software-only qualification remain mandatory upstream.

Raster regeneration receives the live additional support/interface/protected-domain retained-point count, excluding the caller's object and frozen cache pool. The caller must include it with live neighborhood operands and classified scratch; a frozen cache reservation does not cover additional owned query temporaries. Clear anchor workspace before invoking the callback, and never count the object/cache reservation twice.

Anchor queries accept paired world-millimetre endpoints and declared bead width; previous/contact iterators stay borrowed and distinct to preserve direct-anchor provenance. Whole-row admission groups its axis, retained-point accounting and borrowed recipe, while cancellation and cumulative work remain caller-owned. Shared-union cache entries name a weak source owner and strong result; nearest-stroke diagnostics name distance in millimetres, deposition role and endpoints without copying path arrays.
