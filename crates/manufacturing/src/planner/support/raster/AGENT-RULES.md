# Support centerline realization rules

Own the private physical-support centerline and process-role realization consumed by the parent support planner. Inputs are one layer's kept support cells S and interface cells I from the sweep's conservative grid (`../grid.rs`), the recipe and the actual scheduled layer. Never access native M, image parameters, schedule construction, object ownership or support polygons here.

Erode S once on the grid by the declared half-bead width: E keeps only cells whose closed distance to every cell outside S exceeds it, so every nominal bead centred anywhere in E stays inside S. Interface is a centerline ownership/density selector, not an independently cleared solid: hatch ownership is E ∩ I versus E − I. Interface uses full density; ordinary support retains declared density. Beads may overlap a role seam; each emitted path belongs to exactly one role and is accounted once. A sub-bead I strip must not erase the physical support wall or create artificial clearance.

Hatch rows come straight from the grid: each lattice line's road segments are the runs of E (or E ∩ I, E − I) along it, at the line's exact coordinate, with run ends at cell edges clipped inward to cover XYZ6 projection; a line within that clip of a cell boundary uses only cells set on both sides. Support hatches use a common build-frame lattice (line k at k · pitch) and pitch derived from captured resolved nominal layer height and actual bead width; clipping, islands, interface changes and thin layers never move a row. Odd lattice lines run reversed. Rows shorter than one XYZ6 command are omitted.

Walls follow E's own traced boundary, simplified within one cell by chords that stay inside the closed E cells (never the extra-eroded contour: walls must reach E's edge to anchor object strokes beside protected voids), each edge split only where its cells' interface membership changes, judged at each piece's midpoint; same-role pieces continue one path with no seam outline. Fit sub-command pieces within 0.001 mm of every original span inside that contour, retaining endpoints, closure, width, physical interval and role boundaries; where no complete admissible chain exists, keep the admissible chords covering the most length and return the omitted length for `support_omitted_wall_mm`. Never invent a chord to avoid omission.

The parent uses only the layer's preferred axis (`HatchAxis::for_policy(AlternatingXY, hatch_key)`); what it cannot anchor is omitted and reported, never retried on the other axis. Build one lower inventory per layer and reuse it for every anchor query there. Preserve independently rooted straight wall runs across a closed seam; an unrelated failed path cannot erase rooted deposition. Lower/contact sets stay immutable during retention; same-layer paths never supply roots. Only SupportInterface may start on a separated part contact. Preserve capsule, endpoint, bridge and complete-clearance rules, and propagate errors/cancellation.

Byte-admit grids, contours, staged paths and scratch against the remaining geometry allowance; count raster, fitting and anchor work and check cancellation per row/edge. Borrow previous strokes; retain no alternate candidates. Software admission does not establish physical strength or printer readiness.
