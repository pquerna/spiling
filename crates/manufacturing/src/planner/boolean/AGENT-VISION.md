# Boolean work admission vision

Admit genuinely bounded overlay work for native sections, ordinary offsets/skins and support consumers without making highly sampled local capsule neighborhoods look globally quadratic in every disk vertex. Coarse-safe calls need no scratch; a reusable conservative edge index handles tighter locality under the planner's explicit cumulative work policy.

Geometric material, source coordinates, holes and numerical policies remain owned by the existing consumers. The index respects the pinned overlay's integer coordinate conversion and charges its own construction/sort/scans as well as admitted same-/cross-operand boundary candidates. It is not a replacement Boolean implementation, source simplifier, texture-specific fast path or promise of kernel allocator/physical printer safety.

Varying-Z skin horizons use the same conservative candidate accounting cumulatively across their actual intersection sequence, preserving the final material/holes without mistaking repeated remote-edge pairs for executed local work.

Acceptance includes thick bounded disk-neighborhood erosion retaining expected exterior/hole geometry, actual native cylindrical ordinary-wall compile/replay, adversarial resource refusal and cancellation. Dependency-scale or input-frame expansion requires a fresh conservative conversion/work review; resource allowances never establish geometric correctness.
