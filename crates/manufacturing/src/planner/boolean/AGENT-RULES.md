# Boolean work admission rules

Own carrier-independent conservative work admission before the existing geo overlay/buffer consumers. Never alter source vertices, polygon/ring ownership or offset/native/finish error bounds. The planner's declared cumulative planar-work ceiling is 128 million units, independent of native interval and anchor work; no per-source or retry-triggered cap changes. Admission is a resource proof, not a geometry operation or alternative Boolean kernel.

Small coarse-safe inputs remain allocation-free. When a whole-ring Cartesian upper bound is too coarse, use the bounded boundary-edge sweep. Charge input/index construction, every heapsort comparison/swap, every active scan including expired/disjoint/same-operand entries, and every admitted boundary predicate candidate. Cancellation is checked throughout. Keep scratch counts/byte products and conservative construction/sort allowance checked before growth; do not hide an uncharged quadratic broad phase. Unary calls may borrow the same owner once but must count its complete intra-operand candidate work.

Borrowed required-material polygon pieces use the same coarse/sweep admission implementation and combined-coordinate conversion bound as owned MultiPolygon operands. This view copies no coordinates, changes no geometry and introduces no alternate coverage tolerance or texture-specific work limit.
The same bounded cancellable heapsort may order native-M polygon component bounds. Its caller charges each AABB candidate, every filled-polygon narrow-phase edge/containment upper bound and union-find/list scan to this unchanged cumulative counter. Actual-polygon components only partition ordinary Boolean computation; singleton coordinates move unchanged and interacting operands borrow existing ring buffers. Pre-admit all new component/index/output-record scratch bytes alongside live native proofs. Neither planar disjointness nor preserved coordinates certifies native source separation, all-Z coverage or feature correspondence; the completed joint native proof retains that authority.

Skin horizons accumulate admission work through the same edge sweep across the entire intersection sequence. Keep coarse allocation-free bounds only for genuinely small cumulative operands; never sum whole-ring Cartesian products for otherwise local varying-layer neighborhoods or reset the sequence counter per overlay. Execute each overlay only after that shared admission, without a second duplicate admission pass.

Bounds must enclose the consuming pinned geo/i_overlay shared integer conversion. Work-only inflation derives from combined coordinate span and absolute-frame arithmetic, with outward rounding and explicit finite/conditioning refusal. It never authorizes geometry snapping or changes geometric tolerances. Dependency adapter changes require re-review of this bound. Do not abort standard sorting with an invalid comparator or panic interception; the private heapsort returns errors without publishing scratch.
The native-M consumer may propose a cumulative coordinate-error request derived from this reviewed work enclosure for every executed overlay; exact separated appends incur no conversion. This proposal is never a geometric certificate. Geometry's completed joint proof must independently establish each actual source-M input's inclusion in the exact accepted output within an achieved bound, native union feature correspondence and the actual output hash. Input receipt presence, work padding or a Boolean tolerance cannot substitute for output coverage, and a feature lost to grid quantization must refuse even when its metric error is small.

The conservative work estimate may tighten a coarse ring-product estimate without changing geometric sampling or accuracy. General dense/all-overlap and near-grid candidates remain subject to the declared cumulative ceiling, including intra-operand work. Exercise causal boundary-neighborhood ring/hole geometry, refusal/cancellation and actual imported compile/replay under external resource caps; no support/physical-printability claim follows.
