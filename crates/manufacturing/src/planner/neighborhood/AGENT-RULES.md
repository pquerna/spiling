# Realized-D skin neighborhood rules

Own job-local physical-horizon intersections of immutable final `SectionSpan.material` D. First complete the raw actual-distance horizon query, then evaluate its captured fill-bead clearance lazily: erosion by the same fixed structuring disk distributes over intersection, so intersect cleared full-D leaves without offsetting a fragmented raw horizon again. Neighbor wall/fill ownership is never a leaf. Keep actual unequal-height/event endpoints, protected holes and the existing offset/Boolean policy; this is neither native M/C reuse nor an exact directed-floating-set claim.

`SkinNeighborhoods::new(sections, fill_clearance_mm, initial_work)` inherits cumulative planar work. Attribution, raw range overlays, final fill-clearance construction, traversal and eviction share that counter. Admit index/point/byte arithmetic before growth, cancel at every query/traversal and retain typed numerical/resource refusals. Construction allocates only the bounded index; raw leaves borrow admitted D.

Raw and cleared tree slots share one admitted metadata allocation, geometry pool, counter and eviction scan; zero clearance needs only raw slots. Raw leaves borrow D, while cleared leaves and internal ranges may share pinned geometry or own genuine temporaries. Exact ordered full-D identities may alias both policies, never heights or horizon positions. Keep the raw query alive through clearance evaluation: count cached owners once in the pool, and add raw/query/recursive temporaries to offset and intersection scratch. Callers count returned owned temporaries; pinned shared results remain in the pool. Never clone source D merely to derive a leaf.

Reclaim unpinned derived geometry by oldest last-use cumulative work, then node index. Charge cancellable eviction scans; never evict another Arc owner's geometry. Empty and borrowed metadata remain. `freeze_retained_capacity()` freezes both coordinate-point retention and actual retained-owned bytes, including Arc and ring/polygon capacities: support snapshots the complete byte receipt once. The fixed index allocation is already counted separately. Replacements must fit both frozen ceilings after eviction; otherwise return admitted owned temporaries. Recompute evicted leaves/ranges with the same policy/order/counter, never a native shortcut.

`admit_retained` reclaims optional cache ownership before refusing complete live external/scratch staging. Include retained cache in ordinary wall staging too; never pre-bake it into classification's fixed budget. Frozen retention does not fund query/classification temporaries.

Tests compare sliding non-nested curved horizons against independent raw-first offsets and leaf-derived intersections under the existing declared policy, preserving protected holes and policy-independent floors/roofs. Exercise nonzero-clearance shared-byte admission, pins, eviction, frozen/zero pools, failure atomicity and cancellation without requiring a particular storage variant or private traversal count. Native CLI/workbench compile and independent replay remain acceptance; no source-text acceptance.
