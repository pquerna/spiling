# Realized-D skin neighborhood rules

Own only job-local exact intersections of immutable final `SectionSpan.material` D. Leaves borrow source geometry; lazy aligned contiguous internal ranges retain shared intersections. Native M/C invariance, image parameters and geometry approximations never authorize reuse. Query endpoints are inclusive span indices, resolved by the planner's actual-distance schedule; fold aligned disjoint ranges in ascending order through the existing classification Boolean operation.

`SkinNeighborhoods::new(sections, initial_work)` inherits the existing cumulative work. Required-material attribution uses `work_mut()` and all neighborhood overlays use that same unchanged20M counter. Charge index initialization, traversal, point validation and the existing bounded overlay admission. Index/node/point/byte arithmetic is checked before growth. Cancellation precedes every query and interrupts traversal and point validation; construction has no cancellation argument and admits only the bounded layer-count index, never geometry.

`Material` borrows a leaf, shares a cached node, or owns a genuine temporary aggregate. Its lifetime is the source lifetime, not a mutable-cache borrow. Empty values allocate no geometry or Arc. `temporary_points()` counts only owned geometry. Callers pass all externally retained geometry, including other live query temporaries, to `survival`; it adds cache geometry exactly once. Recursive builds and folds include every owned input, the live accumulator and simultaneously live replacement result in staging admission. Include `retained_points()` in ordinary wall/classified-region staging too. Excess work/nonreclaimable retention/invalid indices refuse explicitly; never reset counters or copy every leaf.

On retention pressure, reclaim oldest unpinned cached geometry deterministically by last-use cumulative work, breaking ties by node index. Every scanned node charges work and checks cancellation. Never evict an Arc with another owner: pinned geometry remains charged until callers/builds release it. Leaves and empty metadata remain. `freeze_retained_capacity()` tightens future cache retention to its current count and returns the pool reserved by the parent before support; never exceed it. Computed nodes that cannot enter this pool stay owned temporaries if all simultaneously live geometry fits ordinary admission. Recompute evicted exact ranges with the same geometry/order and cumulative counter, not a native shortcut.

`admit_retained` lets ordinary classification report its complete live external/scratch requirement and reclaim optional cached nodes before refusal. Never bake a pre-reclamation cache count into a fixed classifier budget. The planner combines source/wall geometry, live query temporaries and any support/protected domains; this module adds its current pinned/reclaimable cache exactly once.

Focused tests must independently check varying/growing/shrinking/sliding domains, protected holes, inclusive endpoints, leaf/shared/temporary ownership transitions, deterministic reclamation with pins, frozen and zero-sized pools, true dense-work refusal, aggregate cache-plus-temporary retention refusal and cancellation at the eviction scan and warm-query boundaries. The parent planner owns imported native compile/replay and physical horizon integration evidence; no geometry mocks or source-text acceptance.
