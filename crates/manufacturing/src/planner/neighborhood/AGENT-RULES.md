# Realized-D skin neighborhood rules

Own job-local intersections of immutable final `SectionSpan.material` D inset to the innermost wall center, at one compile-fixed recipe radius `(perimeter_count − 0.5) × bead_width`. Erosion distributes over intersection: derive each leaf once, then intersect aligned contiguous ranges; never offset a bloated horizon aggregate in classification. Keep the existing circumscribed-disk/0.005 mm offset policy and ordinary Boolean arithmetic; this algebra grants no new tolerance or native authority. Native M/C invariance never authorizes reuse. Inclusive span endpoints still come from the actual-distance schedule; fold disjoint nodes in ascending order.

`SkinNeighborhoods::new(sections, inset_mm, initial_work)` inherits cumulative planar work. Attribution, leaf-offset overlays, range overlays, traversal and eviction share that counter. Admit index/point/byte arithmetic before growth, cancel at every query/traversal and retain typed numerical/resource refusals. Construction allocates only the bounded index; leaves are lazy.

Nonzero-inset leaves and internal ranges own geometry in one shared pool. Only the exact zero-radius identity borrows raw D. `Material` shares pinned cache geometry or owns a genuine temporary, independent of the mutable-cache borrow; empty values allocate no geometry/Arc. `temporary_points()` counts only owned temporaries. Callers supply all external source/wall/support geometry and other live query temporaries; the index adds cached ownership exactly once. Offset admission includes disk/capsule construction, existing primitives, tube, source copy and live result; recursive folds include both inputs, accumulator and replacement.

Reclaim unpinned leaves/ranges by oldest last-use cumulative work, then node index. Charge cancellable eviction scans; never evict another Arc owner's geometry. Empty and zero-radius borrowed metadata remain. `freeze_retained_capacity()` fixes the pool reserved before support. Computations that cannot enter it return admitted owned temporaries. Recompute evicted leaf insets/ranges with the same policy/order/counter, never a native shortcut.

`admit_retained` reclaims optional cache ownership before refusing complete live external/scratch staging. Include retained cache in ordinary wall staging too; never pre-bake it into classification's fixed budget. Frozen retention does not fund query/classification temporaries.

Tests compare physical skin ranges and consumer ownership against brute-force independently derived final-D insets, preserving protected holes, actual-anchor properties, frozen/zero pools, pins, failure atomicity and cancellation. Parent acceptance owns unchanged native fitting/housing/image compile and independent replay; no count/wording or source-text acceptance.
