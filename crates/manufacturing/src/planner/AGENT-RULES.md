# Planar planner rules

Consume immutable native definitions and rigid occurrences. Inverse-transform world horizontal planes, then place native millimetre loop points in world XY. Native outer/hole classification remains authoritative; associate holes with their smallest containing outer before union, canonicalize rings and never replace sections with tessellation, source-name geometry, a second kernel or source mutation.

Public `preflight(input,cancel)` captures the input revision and performs the same intent/source/pose/carrier/placement metadata admission as planning. Reports have at most 256 bounded checks with relevant occurrence/source face references. Eligibility is metadata-only: every report explicitly leaves native section/topology/offset/support/bridge work to Compile and denies physical qualification. Only admitted planar/cylindrical analytic native definitions enter this lane; freeform/general STEP remains explicitly refused by native admission. Sloped planar and tilted cylindrical faces require per-layer native sections and all existing native degeneracy/tolerance/topology gates. Placed XYZ limits and bed/top contact use original analytic native projection extrema, never transformed AABB corners as an exact certificate.

The bounded schedule splits the nominal bed grid at every real horizontal native event, the exact analytic top, breakaway support-stop events (horizontal contact elevation minus declared Z gap) and interface-start events (support stop minus declared interface thickness). Each layer records true `height_mm`, increasing deposition Z and an interior native sample. Refuse intervals at or below twice native plane tolerance instead of silently omitting a shelf or rounding away a top. Empty source intervals are retained for genuine floating bodies. Empty deposition intervals are admitted only by the domain's bounded breakaway contact-gap invariant, never by invented object area or bead thickness.

Native event identity at the bed, nominal grid and exact top uses only a four-machine-epsilon world-Z magnitude bound, independently of native plane/thin-feature tolerances. Canonicalize roundoff-identical events before constructing intervals; genuine near-bed/grid/top short intervals still reach the unchanged explicit refusal. Preserve the exact native top rather than snapping it to a nominal grid.

Reuse native XY footprints only in certified open extrusion slabs with exactly invariant transformed planar/cylindrical carriers; otherwise section every layer natively. Retain each footprint once per span. Cache the current immutable wall/fill layout and stable height/physical-neighborhood/parity templates. Physical skin neighborhoods use actual cumulative layer distances, conservatively intersecting every crossed footprint; bottom owns overlapping skins. Wall, bottom, top, solid and sparse domains partition object material; holes/intentional sparse void retain separate accounting. Supports never change object partition or source/occurrence identity.

Prepare native intersection seeds once per used immutable definition, shared by its rigid occurrences, in a job-local borrowed map. Deduct actual retained capacities from the geometry adapter's aggregate source allowance; query clipping scratch remains separately bounded. Release all prepared sources after collecting native footprints and before classification/support work. Never clone source solids, persist native caches or substitute seed meshes for native sections.

Object offsets use the material set minus/union its boundary's disk neighborhood, built from convex segment capsules on exterior and hole rings. The circumscribed disk has at most 0.0025 mm outward radial error within the existing 0.005 mm offset policy. Admit retained primitive points and pair work before one shared-coordinate-frame capsule union; do not incrementally resnap capsule-union results. Never hull/simplify authoritative material or discard tiny resulting islands. Preserve component/hole topology and thin-feature refusal. Complementary skin domains intersect/subtract their original operands, not already rounded masks. Object hatches remain within native perimeter-owned erosion and classified fill domains; bridge coalescing may join only already-required continuous pieces, never extra sparse fill. Actual height determines rounded bead area and solid/sparse spacing. Coverage volume follows emitted role flow factors: first-layer flow for all deposition, bridge flow for Bridge; object and support nominal volumes remain separate.

Bridge admission uses previous actual nominal deposited strokes, not the full native source material. Intersect each candidate centerline analytically with the union of exact segment capsules at declared half-bead radius, using perpendicular strip and endpoint-circle intervals; no polygonized-circle or overlay approximation certifies an anchor. Interior anchors require positive-length intervals, not isolated tangent points. Separately certify the actual candidate endpoint disk's positive-area overlap with a previous nominal capsule by strict point-to-segment distance below the sum of declared radii; equal-distance tangency has zero area and is not an anchor. Endpoint certification never dilates interior capsules or shortens measured centerline gaps. Two-ended spans must be no longer than `process.max_bridge_span_mm`; only bounded half-bead one-sided overhangs are tolerated without support. Contours containing a bridge remain whole closed contours with Bridge process role. Disabled support refuses unanchored/over-limit demand with layer/Z/bridge-limit diagnostics.

Bridge admission traverses maximal straight native sampled strokes, including across closed seams, using only cross-product arithmetic-roundoff collinearity. Never remove/move contour points or flatten curved runs. Tiny fully unanchored strokes still demand support; the half-bead overhang allowance needs an actual positive-length interval or positive-area endpoint anchor. Exact intervals and endpoint certificates retain provenance: lower declared interface contacts can resolve bounded demand, but only two direct previous-layer anchors certify a Bridge role. Contact-resolved deposition retains its object role and remains explicitly distinct from direct support.

If preferred raster orientation has unresolved demand, evaluate both allowed orthogonal axes from the same native ownership domains before publishing demand; event-index parity is only a deterministic tie-break. Whole rows clipped by native perimeter-owned fill may join existing classification pieces only when their emitted-grid intervals cover the complete row without gaps/overlap and actual direct strokes prove a bounded bridge. No new sparse row/material, source-material anchor or relaxed endpoint/radius/native tolerance is permitted. After support generation, revalidate all realized object strokes against actual previous/contact paths, reconsider both axes where necessary and remove stale composite bridge roles. Bound temporary rows, ownership metadata, anchor records and cumulative work; retain no alternate full motion plan.

Breakaway support groups proved actual-stroke demand per contact layer. The genuine current native material footprint supplies a conservative corridor candidate only after demand is proved, never an anchor map. Before publishing any column, clip its fixed-XY corridor against all bed-to-contact native material expanded by declared XY clearance and all protected native holes. Only surviving bed-anchored vertical corridors produce Support/SupportInterface paths; branching or floating support is not claimed. Centers remain half a bead inside clipped domains and support hatches enter at their own wall centers for positive bead overlap instead of tangent-only starts. Nominal support beads remain outside object/protected clearance, the highest support Z stays below object contact by the declared gap, and interface thickness/density are explicit. Validate support raster spans against actual prior support strokes, and revalidate every demanded edge against actually emitted contact strokes so another valid column cannot certify a blocked component. Report separate support area/volume and do not label intentional contact-gap object deposition as a two-ended free bridge.

Check cancellation around native/Boolean/buffer work and during every layer/path/hatch/anchor edge. Bound native+wall+classified retained points, corridor/interface/protected/temporary contours, combined anchor interval/gap records, cumulative support/skin Boolean and actual stroke-pair clipping work, schedule layers, raster rows and combined object/support deposition segments before growth. Borrow prior paths and reuse one bounded interval workspace; do not polygonize anchor circles or copy full path arrays to filter roles. Native calls remain nonpreemptible and do not promise kernel allocator RSS limits.

Exercise parent-owned `cargo test --locked -p spiling-manufacturing`; first construct the genuine operator fixtures with `cargo run --locked -p spiling-geometry --example generate_operator_fixtures`. Tests include exact/non-grid scheduling, inward planar ramp, native tilted cylinder, sparse roof bridges, mixed closed bridge contours, cantilever/floating support, protected holes, blocked components, cancellation and bounded demand. Native compilation and independent replay establish software behavior only, never physical printability.
