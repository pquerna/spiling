# Manufacturing preflight rules

Own public `preflight(&CompilerInput,&AtomicBool)` and the shared planner metadata admission seam. Consume captured revision, inert intent, stored/native identity, rigid occurrences and admitted native face/projection metadata only. No native intersections, offsets, support generation, persistence, printer control or independent eligibility convention in clients.

Check profile/process/support capability, source identity, pose, bounded records/events and placed analytic XYZ extrema. Native line/circle directional projection, not rotated AABB corners, certifies bed/top placement. Preserve real horizontal events and per-occurrence analytic first/last material elevations so a tilted floating body cannot appear mid-layer and acquire false bed anchoring. Include occurrence/face references where relevant. At most 256 checks; truncation cannot turn an erroneous input eligible. Bound iterations by existing native input caps and check cancellation between faces/curves/records.

Capture full ordered surface overlays and the exact immutable canonical image map, validate every native target including disabled/shadowed layers, and resolve enabled definition then occurrence fills. Metadata certifies native full-height rectangle/full-turn exterior cylinder attribution and the constrained upright bed-anchored extrusion/process/sampling bounds; expand conservative placed extents and exclude other occurrences/fixed components/complete-job prime. Admit the bounded nominal/native/support/image-row schedule and local midpoint vertical-error refinement once, charging retained field-sample estimates; Compile reuses that captured schedule without repeated native queries. Private prepared fields share canonical image allocations and expose identity, bounds, local Z invariance/error/events and retained sampling. Metadata admission never claims construction succeeded: original-section correspondence, closed material/hole retention, actual offsets/resolution and deposited-stroke anchors remain Compile obligations.


Every report records `input_revision`, `software_only=true` and explicit informational pending native section/topology/offset/deposited-anchor bridge/support analysis during Compile plus absent physical qualification. Metadata eligibility is not successful slicing, general STEP admission or physical printability. Return actionable report errors for cheap input problems; preserve typed cancellation/native failure instead of fabricated success. Owning native regressions exercise source/occurrence refs, sloped-face pending checks, floating-disabled and out-of-envelope errors, bounded status and cancellation.
