# Manufacturing boundary vision

Turn explicit printer/recipe data and authoritative placed BREP definitions into deterministic bounded planar paths, a software-only absolute Cartesian program, provenance and independent replay measurements. Opt-in inspection additionally supplies bounded packed actual-command motion for the workbench, preserving accepted rounding deviations rather than echoing normalized plan coordinates. This crate isolates native planning and 2D Boolean/offset dependencies from persistence and protocol consumers.

One bounded native geometry/planner pipeline turns admitted trimmed source material into walls, skins, solid/sparse interiors, actual deposited-anchor bridges and vertical breakaway supports. Family labels never authorize operations: complete native height events, actual slab metric/feature certificates and explicit process/resource gates govern manufacturing. One actual-height schedule combines native/field/support events and required native shape-error refinement. Support exclusions use continuous-target outer occupancy; skins initially describe scheduled D distance. Preflight distinguishes admitted/refused/unresolved and pending Compile work, while persisted achieved-policy/coverage summaries remain descriptive. Canonical process realization and fresh independent emitted-byte replay remain software-only, not physical qualification.

Source-backed exact planar/cylindrical ribs and canonical image relief retain source identity, Smooth precedence, protected material/holes, source-local mappings and truthful original/realized/added accounting. Broader base families never broaden those finish certificates. Native M, mandatory C and requested D have independent reuse identities; supports depend on every lower realized occupied corridor and actual deposited contacts, not a fixed tip window. Image nominal-bead resolution remains advisory independently of fresh replay. BREP stays immutable; arbitrary generic texturing, material painting and physical tactile/printability certification are separate gates.

Requested image detail is not a promise of nominal-bead survival. One ordinary first-wall erosion serves both mandatory native-M coverage and attributed resolution diagnostics; unreachable native material and unchanged non-image D remain hard failures while fine image additions may be correctly lost and reported. This distinction changes no source/hole/topology, resource, offset or actual-anchor safety gate.


Diagnostic-body and complete single-extruder Marlin programs retain independent replay of startup, declared homing/thermal policy, priming, process state and shutdown. Declaration hashes are not measurements. Branching supports, color, multi-axis deposition/execution, physical machine/sensor qualification, collision certification and arbitrary infill remain outside this software gate. Native geometry support is query-certified and bounded, never inferred from family membership. Acceptance remains durable compilation and fresh saved-bundle inspection/export, not machine readiness or platform qualification.
