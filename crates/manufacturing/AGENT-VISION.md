# Manufacturing boundary vision

Turn explicit printer/recipe data and authoritative placed BREP definitions into deterministic bounded planar paths, a software-only absolute Cartesian program, provenance and independent replay measurements. Opt-in inspection additionally supplies bounded packed actual-command motion for the workbench, preserving accepted rounding deviations rather than echoing normalized plan coordinates. This crate isolates native planning and 2D Boolean/offset dependencies from persistence and protocol consumers.

Current software support is one extruder and an eligible analytic planar/sloped/tilted cylindrical subset, subject to per-layer topology, offset and resource gates. Bed-anchored variable-thickness schedules resolve horizontal/exact-top/support-stop events; perimeter offsets, physical skin horizons and alternating-axis solid/sparse interiors preserve closed native holes/islands. Disjoint object ownership stays separate from bounded two-ended bridges checked against actual prior deposited footprints and vertical breakaway supports/interfaces clipped to bed-connected clearance corridors. Support-only and bounded genuine contact-gap layers invent no object material. Canonical entry seams/order are stored in the normalized plan; process realization applies first-layer/bridge speed-flow-cooling and conditional stationary retraction/hop/recovery, independently checked from actual emitted bytes. Public metadata preflight gives captured revision/occurrence/face diagnostics, not successful native Compile analysis or physical qualification. Unresolved thin/topology/resource conditions fail explicitly; nominal accounting is not physical geometry, strength or material evidence.

Diagnostic body programs and typed complete single-extruder Marlin jobs are independently replayed, including startup modes, declared homing, thermal waits, priming, process state and shutdown. Firmware/configuration/calibration hashes are provenance declarations, not measurements. General/freeform STEP, branching supports, color, multi-axis deposition, physical execution, machine qualification, sensor truth, collision certification and arbitrary infill remain outside this software gate. Acceptance is durable end-to-end software compilation and fresh saved-bundle inspection/export with independent emitted replay, not physical printability, machine readiness, GPU-visible/pickable or platform qualification.
