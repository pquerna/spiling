# Runtime-independent wire authority vision

Own bounded version-four project/scene/job/manufacturing/artifact control contracts, persistent project/source identity, explicit synthetic diagnostics and independently checked SPLM/SPLS encoders consumed by native clients and generated TypeScript. The crate is not a storage engine, transaction implementation, planner, replay verifier, CAD implementation or transport runtime.

The control ABI is v4; project format is v2; packed SPLT/SPLM/SPLS schemas remain v1. Project/source/occurrence identity and explicit manufacturing intent/artifact references are persistent; native handles and scene publication epochs are disposable. Manufacturing schema describes software-only validated data, not printability or physical printer support. Durability, native/desktop and platform claims require exercised evidence.
