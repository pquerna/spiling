# Engine API authority vision

Own one typed protobuf native API, checked domain/persistence adapters, standard long-running operation types, bounded generated shell views and explicit packed SPLT/SPLM/SPLS/SPLR layouts. Geometry, recoverable project authoring, durable image relief and software-only manufacturing share the same operation observation/cancellation and immutable artifact retrieval surfaces as diagnostics. Inspection provenance is metadata-only; captured bundles retain unique bounded canonical image content. Sampled resolution advisories remain distinct from independently verified emitted motion. This crate is not a decoder, scheduler, storage engine, CAD kernel, planner or program verifier. Profile declarations and schemas confer no physical printer support.
