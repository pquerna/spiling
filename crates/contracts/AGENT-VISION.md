# Engine API authority vision

Own one typed protobuf native API, checked domain/persistence adapters, standard long-running operation types, bounded generated shell views and unchanged packed SPLT/SPLM/SPLS layouts. Geometry, recoverable project authoring and software-only manufacturing share the same operation observation/cancellation and immutable artifact retrieval surfaces as diagnostics. This crate is not a scheduler, storage engine, CAD kernel, planner or verifier. Profile declarations and schemas confer no physical printer support.
