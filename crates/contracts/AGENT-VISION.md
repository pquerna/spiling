# Engine API authority vision

Own one typed protobuf native API, checked domain/persistence adapters, standard long-running operation types, bounded generated shell views and explicit packed SPLT/SPLM/SPLS/SPLR layouts. Geometry, recoverable project authoring and software-only manufacturing share the same operation observation/cancellation and immutable artifact retrieval surfaces as diagnostics. Inspection provenance and opt-in actual-motion display are bounded contracts; this crate is not a scheduler, storage engine, CAD kernel, planner or program verifier. Profile declarations and schemas confer no physical printer support.
