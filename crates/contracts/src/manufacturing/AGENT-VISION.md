# Manufacturing contract vision

Provide one bounded inert Rust-defined language for printer/job data, source-bound requirements, classified physical deposition and independently replayed durable bundles. Core, compiler and native clients consume the same strict schema; checked protobuf adapters and generated DTOs are views of that authority.

Material identity, explicit loaded-tool binding, construction ownership, process role and physical interval remain separate. Native M, requested D and actual commands retain distinct evidence. Single-tool and bounded fixed-dual Marlin routes share checked constant/per-edge widths and actual-height volume semantics without implying general machine support. SPLR7 associates nominal plan ownership with independently decoded XYZ/E/feed and explicit tool epochs; nominal associations are not measured beads.

Independent emitted-byte replay is mandatory on compile and reopen. Software evidence does not establish physical calibration, adhesion, collision safety, firmware truth or machine readiness. Unsupported geometry, process combinations and resource demands remain explicit refusals.
