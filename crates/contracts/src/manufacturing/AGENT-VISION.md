# Manufacturing contract vision

Provide one bounded inert Rust-defined language for printer/job data, explicit planar recipes, classified paths and independently replayed durable bundles. Core/compiler/native clients consume the same strict schema; protobuf adapters and generated shell DTOs do not establish another authority.

The current schema captures native shape-error, seam/axis policies, native-query coverage, complete ordered process and surface documents and unique canonical image content. Regional interior area/fraction/provenance replaces global-density accounting without treating nominal void as actual extrusion. Source-bound sparse intent is independent of face finishes and global recipe permissions. Native M, realized D and actual strokes remain separate authorities. Visible summaries retain requested/achieved native accuracy and skin/support scopes; image-resolution advisories remain sampled nominal-bead evidence, not physical survival. Inspection exposes metadata/advisories, never pixels.

One single-extruder complete Marlin2 job declares named machine/firmware/configuration/calibration provenance and typed native-home, thermal-wait, prime and final-park data. Diagnostic compilation remains explicit. Required process policy realizes first-layer/bridge speed/flow, queued cooling and external stationary retraction/travel-hop/recovery. True scheduled layer height and physical skins preserve variable-height object ownership; bounded bridge and explicit breakaway supports stay separate from object material. Genuine contact gaps have no fake deposition and prove the requested minimum in actual Cartesian XYZ6 bead coordinates; retained native/field events can require a larger gap, never a claim of exact physical attachment. These software semantics are not physical certification.

Opt-in SPLR5 carries actual object/separator/support/process/lifecycle XYZ/E/F, source lines and validated role attribution through one independent parser/sink. Depositing events separately associate nominal expected-plan width, physical-Z interval and regional owner, never physical bead measurements. Nondeposition has an explicit absent association. Object/support reports, prime and recovered E remain separate; homing trajectories remain firmware-owned and excluded.

Independent software decoding remains mandatory on compile and reopen. Command-space/modal/wait/barrier completeness does not certify firmware configuration truth, calibration, thermal sensor behavior, collision clearance or physical printability. Hardware selection, actual metadata/measurements and supervised physical prints remain unresolved external gates; no connector, arbitrary macros, multiple extruders, universal scheduler or physical qualification claim.
