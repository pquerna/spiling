# Software manufacturing contract rules

- Own explicit printer/recipe/intent, normalized plan, provenance, bundle/report/artifact, SPLR packed admission and transport-independent manufacturing DTOs and validators. No geometry kernel, planner, storage, machine-program parser or runtime dependencies.
- Typed Manufacturing gRPC Execute owns Get/SetIntent; Compile/Verify return standard Google Operations with native metadata/results. Domain Inspect maps Verify with explicit captured project base revision and VerificationOutput; protobuf unspecified/unknown output fails. Immutable bundles and optional replay artifacts are read through descriptors and ByteStream, never chunk commands. Short reply failures use canonical Google Status, not success message arms.
- Protobuf adapters explicitly check every domain conversion in both directions, including enum values, finite measurements, profile/component budgets, hashes and descriptor/record correspondence. Bundle/profile authoring and persistence retain their existing bounded inert JSON schema; no JSON payload tunnels through protobuf. Generated TypeScript describes shell authoring data, never engine-executed code. No implicit profile/recipe defaults, old-format decoding, aliases or physical capability claims.
- Frame is explicit right-handed Cartesian XYZ millimetres; bed is envelope minimum Z. One extruder, fixed-height nonempty deposition layers, physical-thickness top/bottom skins (conservative ceil-to-layer interpretation), explicit finite infill fraction in (0,1], no generated supports. Paths distinguish perimeter/bottom skin/top skin/100% solid interior/sparse interior. Layer coverage partitions material section area; protected holes are excluded, intentional sparse void is nominal area\*(1-density), not a physical guarantee.
- Printer workflow is required: DiagnosticBodyOnly pairs only with CartesianAbsoluteGcodeV1; CompleteMarlin pairs only with Marlin2SingleExtruderGcodeV1 and named machine/firmware/configuration/calibration provenance plus bounded native-home/thermal/prime/park data. No macro strings/defaults. Reviewed firmware assumptions live in [backend rules](../../../manufacturing/src/backend/AGENT-RULES.md); declared provenance is not measured qualification. Lifecycle endpoints share command envelope; park clears object and prime Z.
- Complete Marlin thermal declarations must be integral Celsius; the configuration contract requires TEMPERATURE_UNITS_SUPPORT/M149 C before any temperature command. Priming must not intersect the complete all-layer XY deposition bounds expanded by half bead width and coordinate rounding slack, even in holes/gaps or above the part. Check nominal and rounded prime coordinates; this conservative ownership exclusion is not toolhead collision certification. Validation can return only the fixed-size exclusion bounds to independent replay without a polygon copy.
- Validate finite positive process parameters, capabilities, reference integrity, semantic hashes and resource budgets before use. Nested plan deserialization explicitly borrows one owned cumulative segment budget across every layer/path and admits at most 100000 actual segments before point-vector growth; empty/one-point paths are rejected during admission. Preserve strict fields, per-array limits and serialized Rust/TypeScript shape. Semantic input fingerprints sort identities and exclude project revision/allocator/artifacts/timing; include captured source provenance and explicit intent.
- Bundle schema validation never establishes replay success: independent emitted-program replay is mandatory on compile and reopen. See [manufacturing protocol](../../../../docs/protocol/manufacturing.md).
- SPLR schema2 retains96-byte header/48-byte f64 records; lifecycle_count uses header28, at most200004 events/16MiB. Body counts stay plan counts; four complete-job lifecycle events use layer65535, kind6 travel/kind7 prime; kinds0..5 are body travel/perimeter/solid/bottom/top/sparse. Validate exact length/hash/MIME, remaining reserved fields, unknown-start first endpoint, later known/coincident travel, positive deposition/prime, lifecycle ordering, consecutive nonempty body layers and exact counts/bounds without event allocations. Homing trajectories are excluded, never fictional interpolated motions. Bind metadata/provenance to original bundle record. See [packed replay](../../../../docs/protocol/replay.md).
- Exercise negative schema/resource/reference/hash and wire tests with `cargo test -p spiling-contracts`; generate all TypeScript centrally through the existing generator.
