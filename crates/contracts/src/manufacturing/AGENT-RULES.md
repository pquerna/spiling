# Software manufacturing contract rules

- Own explicit printer/recipe/intent, normalized plan, provenance, bundle/report/artifact, SPLR packed admission and transport-independent manufacturing DTOs and validators. No geometry kernel, planner, storage, machine-program parser or runtime dependencies.
- Typed Manufacturing gRPC Execute owns Get/SetIntent; Preflight/Compile/Verify return standard Google Operations with native metadata/results. Preflight carries bounded revision-bound metadata-only software eligibility checks, publishes no bundle and establishes neither native slicing success nor physical printability. Domain Inspect maps Verify with explicit captured project base revision and VerificationOutput; protobuf unspecified/unknown output fails. Immutable bundles and optional replay artifacts are read through descriptors and ByteStream, never chunk commands. Short reply failures use canonical Google Status, not success message arms.
- Protobuf adapters explicitly check every domain conversion in both directions, including enum values, finite measurements, profile/component budgets, hashes and descriptor/record correspondence. Bundle/profile authoring and persistence retain their existing bounded inert JSON schema; no JSON payload tunnels through protobuf. Generated TypeScript describes shell authoring data, never engine-executed code. No implicit profile/recipe defaults, old-format decoding, aliases or physical capability claims.
- Schema4 frame is explicit right-handed Cartesian XYZ millimetres; bed is envelope minimum Z. Required process/retraction/support policies have no defaults; process.max_bridge_span_mm is the sole bridge authority. Increasing scheduled layers carry true height_mm, interior section Z and variable-height physical skin horizons. Realized section area equals source_section_area_mm2 + surface_added_area_mm2 under the ownership tolerance; both source/addition are zero for support-only/contact-gap layers. Source/offset bounds are independent of required surface_tolerance_mm. Support area/nominal volume never enters object partition. Empty layers require breakaway policy, exactly zero ownership, no leading/trailing empties, a contiguous physical gap <=z_gap_mm, preceding SupportInterface, following actual object deposition and useful bed-anchored support.
- Surface approximation admission requires finite `0 < surface_tolerance_mm <= 0.001` millimetres, independently of existing source/offset bounds. Captured normalized plans cannot advertise a weaker arbitrary finish approximation.
- Printer workflow is required: DiagnosticBodyOnly pairs only with CartesianAbsoluteGcodeV1; CompleteMarlin pairs only with Marlin2SingleExtruderGcodeV1 and named machine/firmware/configuration/calibration provenance plus bounded native-home/thermal/prime/park data. No macro strings/defaults. Reviewed firmware assumptions live in [backend rules](../../../manufacturing/src/backend/AGENT-RULES.md); declared provenance is not measured qualification. Lifecycle endpoints share command envelope; park clears object and prime Z.
- Complete Marlin thermal declarations must be integral Celsius; the configuration contract requires TEMPERATURE_UNITS_SUPPORT/M149 C before any temperature command. Priming must not intersect the complete all-layer XY deposition bounds expanded by half bead width and coordinate rounding slack, even in holes/gaps or above the part. Check nominal and rounded prime coordinates; this conservative ownership exclusion is not toolhead collision certification. Validation can return only the fixed-size exclusion bounds to independent replay without a polygon copy.
- Validate finite positive process parameters, capabilities, reference integrity, semantic hashes and resource budgets before use. Nested plan deserialization explicitly borrows one owned cumulative segment budget across every layer/path and admits at most 100000 actual segments before point-vector growth; empty/one-point paths are rejected during admission. Empty layer path arrays are structurally admitted, but only whole-plan validation can authorize the bounded contact-gap invariant above. Preserve strict fields, per-array limits and serialized Rust/TypeScript shape. Semantic input fingerprints sort identities and exclude project revision/allocator/artifacts/timing; include captured source provenance and explicit intent.
- Semantic fingerprints and full manufacturing/inspection provenance include every ordered surface-schema2 layer and exact variant parameters, including disabled layers and explicit Smooth overrides. Allocators/revisions are excluded. Native full-height rectangular-wall/full-cylinder certification and derived additive rib construction belong outside contracts; accounting is not physical grip efficacy or edited BREP. Planner identity5 accompanies unchanged emitter/verifier4 and manufacturing schema4.
- Bundle schema validation never establishes replay success: independent emitted-program replay is mandatory on compile and reopen. See [manufacturing protocol](../../../../docs/protocol/manufacturing.md).
- SPLR schema3 retains96-byte header/48-byte f64 records; lifecycle_count at28, process_count at88, at most300004 events/16MiB. Packed deposition includes object/support; report/summary separate object/support, prime and recovery. Kinds0..7 retain meaning,8 bridge,9 support,10 interface,11 retract,12 unretract. Process events have known stationary XYZ and actual decreasing/increasing absolute E; fan commands are not fake motion. Actual layer IDs can skip verified contact-gap schedule layers; standalone packed admission does not prove native contact geometry. Exact length/hash/MIME, bounded counts/coordinates and remaining reserved fields remain required. See packed replay protocol.
- Exercise negative schema/resource/reference/hash and wire tests with `cargo test -p spiling-contracts`; generate all TypeScript centrally through the existing generator.
