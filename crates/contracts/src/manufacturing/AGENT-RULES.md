# Software manufacturing contract rules

- Own explicit printer/recipe/intent, normalized plan, provenance, bundle/report/artifact, SPLR packed admission and transport-independent manufacturing DTOs and validators. No geometry kernel, planner, storage, machine-program parser or runtime dependencies.
- Typed Manufacturing gRPC Execute owns Get/SetIntent; Preflight/Compile/Verify return standard Google Operations with native metadata/results. Preflight carries bounded revision-bound metadata-only software evidence and admitted/refused/unresolved disposition, publishes no bundle and establishes neither native slicing success nor physical printability. Domain Inspect maps Verify with explicit captured project base revision and VerificationOutput; protobuf unspecified/unknown output fails. Immutable bundles and optional replay artifacts are read through descriptors and ByteStream, never chunk commands. Short reply failures use canonical Google Status, not success message arms.
- Protobuf adapters explicitly check every domain conversion in both directions, including enum values, finite measurements, profile/component budgets, hashes and descriptor/record correspondence. Bundle/profile authoring and persistence retain their existing bounded inert JSON schema; no JSON payload tunnels through protobuf. Generated TypeScript describes shell authoring data, never engine-executed code. No implicit profile/recipe defaults, old-format decoding, aliases or physical capability claims.
- Schema6 frame is explicit right-handed Cartesian XYZ millimetres; bed is envelope minimum Z. Required process/retraction/support policies and finite positive recipe.native_shape_error_mm have no defaults; process.max_bridge_span_mm is the sole bridge authority. Native shape error is explicit semantic intent captured in fingerprints/provenance, independent of source/offset bounds and surface_tolerance_mm. Increasing scheduled layers carry true height_mm, interior section Z and variable-height physical skin horizons. Realized section area equals source_section_area_mm2 + surface_added_area_mm2 under the ownership tolerance; both source/addition are zero for support-only/contact-gap layers. Support area/nominal volume never enters object partition. Empty layers require breakaway policy, exactly zero ownership, no leading/trailing empties, preceding actual SupportInterface, following actual object deposition and useful bed-anchored support. Their contiguous actual XYZ6 physical gap must be at least z_gap_mm, never bounded above by that minimum; native/field partition constraints can require a larger gap. Existing role, true-height, resource and revision obligations remain mandatory.
- Surface approximation admission requires finite `0 < surface_tolerance_mm <= 0.001` millimetres, independently of existing source/offset bounds. Captured normalized plans cannot advertise a weaker arbitrary finish approximation.
- Native kernel, conditioning, indeterminate analysis, singular geometry and exceeded shape-error failures retain distinct ManufacturingErrorCode categories through checked native errors; unsupported geometry is not a catch-all numerical diagnostic.
- Required native_geometry coverage persists in plans and visible summaries: requested/achieved shape error, accepted original-occurrence/slab captures, height analyses, certified layers, events and cumulative query work. source_feature_coverage partitions accepted layers into disjoint_source_layer_count, invariant_source_union_layer_count and native_interface_complex_layer_count; their checked sum equals certified_layer_count, never a global-Z invariance label. Native interface complex coverage requires actual continuing-core/critical-contribution and complete leaf-ledger evidence; naming it grants no capability. slab_count includes every original occurrence in each accepted native span, even inactive sources and owned endpoints, but invariant spans can cover several scheduled layers without additional captures. Therefore height_analysis_count <= slab_count <= height_analysis_count * certified_layer_count; no slab_count >= certified_layer_count assumption or fabricated per-layer capture is valid. owned_critical_slab_count counts unique original-occurrence/slab captures with any owned endpoint stratum or transition collar, not faces, and cannot exceed slab_count. Reused certificates bind each accepted capture. Failed/refined attempts affect only geometry_work. No empty-height bound or unresolved union proof is invented. Skin means scheduled D material distance; support clearance names continuous target outer occupancy. Summaries confer no native certificate or emitted physical union-boundary authority.
- Printer workflow is required: DiagnosticBodyOnly pairs only with CartesianAbsoluteGcodeV1; CompleteMarlin pairs only with Marlin2SingleExtruderGcodeV1 and named machine/firmware/configuration/calibration provenance plus bounded native-home/thermal/prime/park data. No macro strings/defaults. Reviewed firmware assumptions live in [backend rules](../../../manufacturing/src/backend/AGENT-RULES.md); declared provenance is not measured qualification. Lifecycle endpoints share command envelope; park clears object and prime Z.
- `program_coordinates` owns only the explicit current CartesianAbsoluteGcodeV1/Marlin2SingleExtruderGcodeV1 XYZ6 encoding contract: endpoint projection, remaining decimal/f64 enclosure and full nominal-bead vertical interval. Emission, support contact selection/final proof and normalized empty-gap validation share it without backend re-exports or independent rounding formulas. Normalized validation exhaustively binds current output dialects; future dialects must choose their representation, never inherit this as generic plan rounding. Program serialization, planning and independent byte parsing remain outside contracts.
- Current XYZ6 checked projection/enclosure requires absolute coordinates <=2^52/1e6 mm (about4503.6km), preserving exact rounded scaled integers and distinct adjacent parsed lattice points. Outside this certified output range return NativeConditioningFailure, never a guessed coordinate. Only proved exact dyadic XYZ6 coordinates (multiples of1/64) have zero decimal error. Gap subtraction checks all TwoDiff head/virtual/recovered/error/residual intermediates and its outward result for finiteness before returning evidence; nonfinite compensation is typed conditioning, not NaN comparison fallthrough, scale epsilon or a fabricated point interval.
- Complete Marlin thermal declarations must be integral Celsius; the configuration contract requires TEMPERATURE_UNITS_SUPPORT/M149 C before any temperature command. Priming must not intersect the complete all-layer XY deposition bounds expanded by half bead width and coordinate rounding slack, even in holes/gaps or above the part. Check nominal and rounded prime coordinates; this conservative ownership exclusion is not toolhead collision certification. Validation can return only the fixed-size exclusion bounds to independent replay without a polygon copy.
- Validate finite positive process parameters, capabilities, reference integrity, semantic hashes and resource budgets before use. Nested plan deserialization explicitly borrows one owned cumulative segment budget across every layer/path and admits at most 100000 actual segments before point-vector growth; empty/one-point paths are rejected during admission. Empty layer path arrays are structurally admitted, but only whole-plan validation can authorize the bounded contact-gap invariant above. Preserve strict fields, per-array limits and serialized Rust/TypeScript shape. Semantic input fingerprints sort identities and exclude project revision/allocator/artifacts/timing; include captured source provenance and explicit intent.
- Semantic fingerprints and full manufacturing/inspection provenance include every ordered surface-schema3 layer, exact mappings and canonical/source image metadata, including disabled layers and Smooth overrides; revisions/allocators are excluded. Only self-contained full provenance includes the unique bounded canonical image content table; inspection/status never carries pixels. Correspondence/header/dimensions/hash and effective layer/occurrence/face/image diagnostic attribution are checked before replay. Sampled resolution records retain strict counters/finite intervals, coverage, maxima and at most8 representatives; summary totals are advisory, never a weakened field/geometry/vertical-fidelity/replay gate. Planner identity7 accompanies unchanged emitter/verifier4 and manufacturing schema6.
- Full provenance content shares Arc<Vec<u8>> canonical captures; serde retains the same bounded byte-array shape. Clone ownership, never raster bytes, per capture/section. All image/resolution allocations remain charged to existing bundle/retained budgets.
- Bundle schema validation never establishes replay success: independent emitted-program replay is mandatory on compile and reopen. See [manufacturing protocol](../../../../docs/protocol/manufacturing.md).
- SPLR schema3 retains96-byte header/48-byte f64 records; lifecycle_count at28, process_count at88, at most300004 events/16MiB. Packed deposition includes object/support; report/summary separate object/support, prime and recovery. Kinds0..7 retain meaning,8 bridge,9 support,10 interface,11 retract,12 unretract. Process events have known stationary XYZ and actual decreasing/increasing absolute E; fan commands are not fake motion. Actual layer IDs can skip verified contact-gap schedule layers; standalone packed admission does not prove native contact geometry. Exact length/hash/MIME, bounded counts/coordinates and remaining reserved fields remain required. See packed replay protocol.
- Exercise negative schema/resource/reference/hash and wire tests with `cargo test -p spiling-contracts`; generate all TypeScript centrally through the existing generator.
