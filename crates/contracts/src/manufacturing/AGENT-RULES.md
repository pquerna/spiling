# Software manufacturing contract rules

- Own explicit printer/recipe/intent, normalized plan, provenance, bundle/report/artifact, SPLR packed admission and transport-independent manufacturing DTOs and validators. No geometry kernel, planner, storage, machine-program parser or runtime dependencies.
- Typed Manufacturing gRPC Execute owns Get/SetIntent; Preflight/Compile/Verify return standard Google Operations with native metadata/results. Preflight carries bounded revision-bound metadata-only software evidence and admitted/refused/unresolved disposition, publishes no bundle and establishes neither native slicing success nor physical printability. Domain Inspect maps Verify with explicit captured project base revision and VerificationOutput; protobuf unspecified/unknown output fails. Immutable bundles and optional replay artifacts are read through descriptors and ByteStream, never chunk commands. Short reply failures use canonical Google Status, not success message arms.
- Protobuf adapters explicitly check every domain conversion in both directions, including enum values, finite measurements, profile/component budgets, hashes and descriptor/record correspondence. Bundle/profile authoring and persistence retain their existing bounded inert JSON schema; no JSON payload tunnels through protobuf. Generated TypeScript describes shell authoring data, never engine-executed code. No implicit profile/recipe defaults, old-format decoding, aliases or physical capability claims.
- The printer frame is explicit right-handed Cartesian XYZ millimetres; bed is envelope minimum Z. Required seam/axis/process/retraction/support/sparse policies and deposition limits have no defaults. `PrintLayer.lower_z_mm` is the true schedule boundary; `height_mm` is nominal reporting. Every path records `WidthProfile::Constant` or `PerEdge` and a physical-Z interval. Per-edge width count is exactly `points.len()-1`, including an explicit closing edge; constant profiles allocate no width vector. Borrowed checked-edge consumption supplies actual edge width, and reversal/closed rotation preserve edge-width correspondence. Ordinary paths span `[lower_z_mm,z_mm]`; only validated combined SparseFill/genuine regional Bridge spans consecutive actual intervals under one effective source/profile and explicit band decision. Actual process limits/flow use each edge's width and the path's physical height, never a first-width, mean-width or recipe fallback. Native shape error is independent of approximation budgets. Source/addition/support ownership stay separate; empty layers require actual bed-anchored SupportInterface and following object deposition. Outward-proved XYZ6 full-bead gaps meet the requested minimum, not physical attachment qualification.
- Interior accounting uses positive-area process regions with finite fractions in [0,1]. Global recipe zero retains intentional-void/source coverage and emits no interior hatch; mandatory walls/skins and actual-anchor/replay admission remain independent. Authored sparse overrides retain their positive-only ProcessValue contract. Distinguish authored solid/sparse/void from explicitly owned plate construction and reserved separator domains; construction contributes to the partition once. separator_area_mm2 sums bounded ProcessInterfaceCoverage separately. Each interface binds exact source/provenance, XY axis/coordinate, bead-width thickness, half-width bonding overlap and finite centered strokes. Actual SeparatorWall segments biject to those centerlines. Box permission is explicit, never inferred from overlap. Bundle validation checks source/operation/value bindings; native geometry and independent replay own partition/contact proof.
- Typed ProcessDiaphragmCoverage owns exact solid-construction regional indices, source/permission/winning neighbors, centered source thickness, pose-mapped world slab and full eligible extent with holes. Validate complete slab/layer/owner bijection once per plate, partition and separate once-only area; no ordinary region may masquerade as a plate. Bundle binding reuses resolve_at, not an alternate precedence rule. Strong full-height material/bead proof and actual lower/upper/wall attachment remain planner/verifier responsibilities.
- Surface-color intent binds immutable source/face/occurrence identity and physical skin/backing depths through the existing route. Required bounded material domains and nullable path/process-region material references are separate from geometric roles; white backing is solid construction, not a sparse-density override or purge sink.
- Every path requires nullable `owner`: immutable Wall construction, matching MandatorySkin or Regional(index into the stable layer process_regions), otherwise unknown/null. Perimeter requires Wall; a Wall lowered to Bridge retains Wall ownership and wall traversal/seam policy while Bridge still controls its process role. The explicit RegionalSkinBridge variant owns exactly three straight points: the sole actual middle transition and skin_first bind Regional/mandatory portions; reversal toggles that flag. Its bounded skin_bridge_domains retain classified regional/mandatory and source-owner operands. No generalized mixed merge authority follows. Fresh decoded-byte verification proves both projected portions, complete direct lower anchors, role/order/flow and no duplicate commanded segment. SPLR5 projects the two actual RegionalSkinBridge events to existing Regional/Mandatory associations, never an unknown fallback.
- Plans and summaries carry the same required bounded process_resolution table. Source/provenance-bound Applied records require actual regional/interface attribution; NoEligibleInterior records require its absence. Missing/duplicate identities and unknown wire statuses fail. Empty effective selectors remain visible authored intent, not silent uniform-density success.
- Surface approximation admission requires finite `0 < surface_tolerance_mm <= 0.001` millimetres, independently of existing source/offset bounds. Captured normalized plans cannot advertise a weaker arbitrary finish approximation.
- Native kernel, conditioning, indeterminate analysis, singular geometry and exceeded shape-error failures retain distinct ManufacturingErrorCode categories through checked native errors; unsupported geometry is not a catch-all numerical diagnostic.
- Required native_geometry coverage persists in plans and visible summaries: requested/achieved shape error, accepted original-occurrence/slab captures, height analyses, certified layers, events and cumulative query work. source_feature_coverage partitions accepted layers into disjoint_source_layer_count, invariant_source_union_layer_count and native_interface_complex_layer_count; their checked sum equals certified_layer_count, never a global-Z invariance label. Native interface complex coverage requires actual continuing-core/critical-contribution and complete leaf-ledger evidence; naming it grants no capability. slab_count includes every original occurrence in each accepted native span, even inactive sources and owned endpoints, but invariant spans can cover several scheduled layers without additional captures. Therefore height_analysis_count <= slab_count <= height_analysis_count * certified_layer_count; no slab_count >= certified_layer_count assumption or fabricated per-layer capture is valid. owned_critical_slab_count counts unique original-occurrence/slab captures with any owned endpoint stratum or transition collar, not faces, and cannot exceed slab_count. Reused certificates bind each accepted capture. Failed/refined attempts affect only geometry_work. No empty-height bound or unresolved union proof is invented. Skin means scheduled D material distance; support clearance names continuous target outer occupancy. Summaries confer no native certificate or emitted physical union-boundary authority.
- Printer workflow/dialect pairing is strict. DiagnosticBodyOnly and CompleteMarlin retain their explicit single-tool meanings. FixedDualMarlin pairs only with Marlin2FixedDualGcodeV1 and the bounded source/material/tool/reservation contract in routing.rs. No macro strings/defaults. Firmware assumptions and lifecycle belong to backend rules; declarations are not measured qualification. Lifecycle endpoints share the command envelope.
- Occurrence materials are required Uniform or LayerCycle values with explicit immutable loaded-material bindings. Reuse optical LayerCycle, but initial routing admits equal positive slot heights and indices0/1 only. Signed physical origin/phase, fused boundaries and exact ordinal conditioning govern complete intervals; never resolve by mutable layer index, infer a tool from a palette index or accept a real slot crossing. Existing arithmetic endpoint identity is not geometry tolerance.
- `program_coordinates` owns the current Cartesian XYZ6 projection/enclosures, not serialization or parsing. The existing normalized point pass independently requires every ordinary bottom/top/solid/sparse projected segment to follow required policy at actual scheduled index; Bridge/support/perimeter roles are excluded. Emission, contact/final proof and empty-gap validation share the coordinate contract without backend re-exports or independent rounding formulas. Future dialects must choose their representation explicitly.
- Required `recipe.top_skin_axis` independently controls ordinary TopSkin at its actual scheduled index; other ordinary roles follow `rectilinear_axis`. Bridge is excluded from ordinary axis checks only because its actual lower-anchor/span construction is verified separately, never to authorize rotated supported rows.
- Current XYZ6 checked projection/enclosure requires absolute coordinates <=2^52/1e6 mm (about4503.6km), preserving exact rounded scaled integers and distinct adjacent parsed lattice points. Outside this certified output range return ProgramCoordinateConditioningFailure, never a guessed coordinate. Only proved exact dyadic XYZ6 coordinates (multiples of1/64) have zero decimal error. Gap subtraction checks all TwoDiff head/virtual/recovered/error/residual intermediates and its outward result for finiteness before returning evidence; nonfinite compensation is typed conditioning, not NaN comparison fallthrough, scale epsilon or a fabricated point interval.
- Complete Marlin thermal declarations must be integral Celsius; the configuration contract requires TEMPERATURE_UNITS_SUPPORT/M149 C before any temperature command. Priming must not intersect the complete all-layer XY deposition bounds expanded by half bead width and coordinate rounding slack, even in holes/gaps or above the part. Check nominal and rounded prime coordinates; this conservative ownership exclusion is not toolhead collision certification. Validation can return only the fixed-size exclusion bounds to independent replay without a polygon copy.
- Validate finite positive process parameters, capabilities, reference integrity, semantic hashes and resource budgets before use. Nested plan deserialization explicitly borrows one owned cumulative segment budget across every layer/path and admits at most 100000 actual segments before point-vector growth; empty/one-point paths are rejected during admission. Empty layer path arrays are structurally admitted, but only whole-plan validation can authorize the bounded contact-gap invariant above. Preserve strict fields, per-array limits and serialized Rust/TypeScript shape. Semantic input fingerprints sort identities and exclude project revision/allocator/artifacts/timing; include captured source provenance and explicit intent.
- Semantic fingerprints and full manufacturing/inspection provenance include the ordered process document and every ordered surface-schema3 layer, exact mappings and canonical/source image metadata, including disabled layers and Smooth overrides; revisions/allocators are excluded. Only self-contained full provenance includes the unique bounded canonical image content table; inspection/status never carries pixels. Correspondence/header/dimensions/hash and effective layer/occurrence/face/image diagnostic attribution are checked before replay. Sampled resolution records retain strict counters/finite intervals, coverage, maxima and at most8 representatives; summary totals are advisory, never a weakened field/geometry/vertical-fidelity/replay gate.
- Full provenance content shares Arc<Vec<u8>> canonical captures; serde retains the same bounded byte-array shape. Clone ownership, never raster bytes, per capture/section. All image/resolution allocations remain charged to existing bundle/retained budgets.
- Bundle schema validation never establishes replay success: independent emitted-program replay is mandatory on compile and reopen. See [manufacturing protocol](../../../../docs/protocol/manufacturing.md).
- SPLR schema6 uses a96-byte header/80-byte f64 record, active tool at record76 and epoch count at header92. Kinds0..13 retain meanings;14 is a nonmotion G92 E0 tool epoch with F0 sentinel,15 supported waste with nominal bead dimensions and unknown model owner. Object/support/waste share the100000 deposition budget; epochs cap50000, total300004/32MiB. Wall sentinel remains distinct. Actual XYZ/E/F and exact E8 feeder debt are independent of nominal associations. No frame-jump line or compatibility reader; packed admission is not native contact, physical deposition or machine-program verification.
- Exercise negative schema/resource/reference/hash and wire tests with `cargo test -p spiling-contracts`; generate all TypeScript centrally through the existing generator.
