# Process policy contract vision

Make first-layer, cooling, bridge and travel/recovery behavior explicit inert operator intent rather than emitter defaults. Keep support material separate from object ownership and preserve one authoritative bridge bound. Give inexpensive eligibility checks captured revision and actionable bounded diagnostics, without claiming native analysis or physical printer support.

Required schema3 fields are shared by planning, realization, independent actual-byte verification, protobuf and generated clients. Declared machine capability is a software contract, not measured hardware truth.
