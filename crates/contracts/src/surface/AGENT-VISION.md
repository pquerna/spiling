# Source-face surface contract vision

Provide one durable generated authoring language for selected-source-face directional finishes. Planar vertical ribs are bounded source-backed manufacturing additions on certified full-height rectangular exterior vertical native walls; cylindrical ribs use complete exterior vertical native cylinders with integer circumference closure and source-local phase. Smooth is an explicit override. Authoring may preserve a valid source face even when compilation rejects unsupported geometry/process/pose combinations truthfully.

The document is not BREP editing, mesh jitter, a global recipe flag, generic brush infrastructure or physical grip certification. Exact native face identity, construction admission and independently replayed emitted coordinates remain engine/geometry/manufacturing responsibilities, not schema claims.
