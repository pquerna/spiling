# Source-face surface contract vision

Provide one durable generated authoring language for selected-source-face directional finishes. Planar/cylindrical ribs and image-driven periodic U/physical-source-Z relief are bounded source-backed additions on certified upright native carriers. Smooth is an explicit override. Immutable canonical image identity includes dimensions and pixels; first-admission source metadata remains provenance rather than a retained original-file promise. Authoring may preserve a valid source face even when compilation rejects unsupported geometry/process/pose combinations truthfully.

The document is not BREP editing, mesh jitter, a global recipe flag, generic brush infrastructure or physical grip certification. Exact native face identity, construction admission and independently replayed emitted coordinates remain engine/geometry/manufacturing responsibilities, not schema claims.
