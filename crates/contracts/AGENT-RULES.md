# Engine API authority rules

- Protobuf schemas own the native gRPC API. Vendored Google Operations, Status and ByteStream schemas retain their Apache license and upstream bytes. No Tauri, renderer or kernel dependencies.
- Build generated native types with pinned vendored protoc and tonic/prost. Rust adapters derive the shell view; TypeScript is generated by `cargo run -p spiling-contracts --bin generate`, with `--check` for drift. Never hand-maintain another wire model.
- Packed SPLT layout remains explicitly versioned and independently validated; never serialize Rust memory layouts. Engine/shell ship together; no cross-version control negotiation.
- Test the binary golden fixture and view mappings; see [protocol](../../docs/protocol/control.md).
