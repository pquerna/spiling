# Protobuf schema vision

Describe one authoritative native engine API for diagnostics, geometry, recoverable authoring and software-only manufacturing using established Google operation/artifact patterns. Typed messages carry checked domain values; binary display schemas and persisted JSON remain separate. RPC streaming and schema presence do not themselves establish native accuracy, durable publication, UI consumption or physical manufacturing support.
