# Immutable image field vision

Give engine import and native manufacturing one small deterministic image implementation without coupling storage to a codec or geometry to an importer. Canonical bytes remain durable authority; borrowed bilinear fields expose local bounds, row invariance and explicit lattice events for certified native carrier lifting and varying-Z scheduling. This is not an image editor, generic procedural plugin system or independent geometry verifier.
