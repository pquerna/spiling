# Assumed printed macro mechanics

The engine's sole native worker consumes this crate from saved source-bound
Analyze cases. It isolates the CPU numerical dependencies; it is not another
application, geometry kernel, writer, job runtime or research solver.

`native::capture` requires complete native closed-slab/source-leaf and bounded
native graph/span ownership. `run::execute` constructs disjoint wall/skin/core
regions, assembles full-integration Hex27, retains one immutable original factor
for eligible warm load edits, independently assesses original coefficients, and
produces checked SPLA fields. Missing native/model/resource premises refuse.

Laws are explicit assumptions, particularly the **assumed effective core law**.
Exact recipe compatibility is not a calculated density/pattern law or a qualified
RVE receipt. Global print-axis tensors and tied macro interfaces do not resolve
individual roads or establish weld quality. Macro field/model accuracy, IL2 N1,
calibration and physical/machine qualification remain separate. Detailed Enhanced
construction and reference qualification do not fall back to this operator.

The [public contract](../../docs/protocol/analysis.md) owns coverage, frames,
source-origin moment transfer, evidence, budgets, packed fields, retention limits
and bounded reproduction. Test through the engine feature graph (including
`-p spiling-engine`), with jobs ≤2 and external memory/task/wall limits; a minimal
standalone feature graph can unnecessarily rebuild the pinned native kernel.
