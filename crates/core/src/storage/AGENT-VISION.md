# Recoverable storage vision

Store exact source bytes, canonical content-addressed PGM assets, separately retained original/canonical palette JSON, manufacturing bundle JSON with captured content and complete project10 manifests with bounded ordered surface/process documents and independent appearance studies, retaining one independently validated previous checkpoint. Readers retain complete snapshots while the single writer advances. Immutable assets synchronize before publication; failed first saves remain retryable without deleting foreign paths. External source/image/palette paths are unnecessary for read-only open/recovery. No eager asset GC, session data, persisted undo, image processing, appearance evaluation, program replay or printer execution. OS durability remains platform/evidence-gated.
