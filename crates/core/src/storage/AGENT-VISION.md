# Recoverable storage vision

Bind exact source bytes, canonical PGM assets, original/canonical palettes, complete manufacturing bundles and strict project10 roots to one self-contained PTAC .spil. Core retains one independently validated previous save, immutable captured readers and monotonic recovery floors while session history stays in memory. Publication receipts preserve uncertainty instead of inventing successful saves. Explicit bounded collection and compact-to-new reclaim storage without changing project meaning or replacing a live attachment. External inputs, legacy directories, persisted undo, image processing, appearance evaluation, native admission and program replay are not storage authority. OS durability remains platform/evidence-gated.
