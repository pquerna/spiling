# Durable project authority vision

Provide runtime-independent source-backed authoring, explicit manufacturing intent, immutable content-addressed bundle assets and bounded checkpoint recovery to the engine. Persistent identity, original source bytes and complete software-only artifacts survive session replacement; native caches and display state remain derived engine concerns. Undo is session-only, not a persisted journal. No planning, emitted-program replay, printer execution, external-source references, geometry kernel objects or alternate consumer-side project implementation. Platform durability claims require independent filesystem/power-loss evidence.
