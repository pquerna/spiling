# Durable project authority vision

Provide runtime-independent source-backed authoring, ordered durable whole-face finishes, explicit manufacturing intent, immutable canonical image and content-addressed bundle assets and bounded checkpoint recovery to the engine. Persistent identity, original STEP bytes, source-image provenance, canonical image bytes, surface layers and complete software-only artifacts survive session replacement without external image files; native caches and display state remain derived engine concerns. History shares bounded raster allocations and restores the exact input/artifact pair; undo is session-only, not a persisted journal. No planning, image decoding, emitted-program replay, printer execution, external-source references, geometry kernel objects or alternate consumer-side project implementation. Platform durability claims require independent filesystem/power-loss evidence.
