# Original controlled AST recipe rules

Own original inch/unit templates and one-property adversarial mutations for the corpus generator. `ast.rs` contains shared controlled record/serialization helpers reused by native importer regressions; `mod.rs` owns generation-only dimensional conversion and adversary recipes. Do not compile unused generation recipes into library tests, suppress warnings or establish a second STEP serializer convention.

These helpers construct original fixture bytes, not production admission or healing. Preserve fixed source identities, actual dimensional scaling, grammar-valid mutations and canonical licensing. Frozen source changes require a new name/version. Exercise generator `--check` and `cargo test --locked -p spiling-geometry`; the [corpus rules](../../../../fixtures/geometry/AGENT-RULES.md) govern frozen evidence.
