# Native geometry examples: vision

Provide auditable original inputs, a real headless geometry facade surface and reproducible native-derived cross-language goldens. Generation preserves native lines, circles, planes and cylinders; diagnostics report mm bounds, canonical source faces, strict mesh errors and native section areas. Facade/golden commands do not establish engine transfer, desktop rendering, STEP assembly import or general CAD support; those use separate real-surface evidence. Freeze measured support in the corpus manifest and evidence, not successful compilation.
