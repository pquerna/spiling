# Native geometry examples: vision

Provide a real headless geometry facade surface and reproducible native-derived cross-language goldens. Diagnostics report original source/native faces, support brackets, separate interpolation/trim/packing errors and native section numerics. Frozen original sources retain historical producer identity; immutable hash/license verification is separate from current facade qualification.

Independent OCCT inputs and selected historical regression sources preserve useful consumer invariants without maintaining a synthetic CAD writer. Source topology, units, transforms and material-side orientation must survive inspection unchanged. Malformed historical closed-spline topology is not a positive source oracle. Facade/golden commands do not establish engine transfer, desktop rendering, general STEP support or physical manufacturing.
