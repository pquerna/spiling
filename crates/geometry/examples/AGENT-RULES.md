# Native geometry examples: rules

- `generate_corpus` owns reproducible original STEP construction through the pinned public kernel writer, with genuine analytic carriers and bounded polynomial/rational/sweep recipes in `parity/mod.rs`. The parity helper is also the library's test-only source recipe; no replacement entity label or import-only widening establishes support. Newly generated parity sources must pass facade import, certified display, tight directional bounds and native sections before staging. Denominator-zero and eighth-grid polynomial aliasing recipes exercise whole-domain conditioning/refusal. Generation is not an import repair path; frozen source changes require new names.
- Positive recipes must bound outward material, not merely close topologically. Preserve original profile gauges and verify oriented caps/walls through source construction and STEP roundtrip. Reverse construction winding explicitly; never compensate through a hidden geometry-conversion inversion.
- `generate_operator_fixtures` constructs original closed planar prisms for exact nonintegral top, off-grid shrinking shelf and inward native ramp regressions. Output lives in `fixtures/manufacturing/native`; print exact generated hashes and preserve frozen corpus files. `--check` compares exact bytes. Parent-owned generation must precede native manufacturing tests; construction/fixture presence is not numerical acceptance.
- `inspect_corpus` exercises the public geometry facade and reports observed admission, packed mesh audits, tight directional support brackets and native section numerics. Face inspection uses `FaceInfo.geometry`, retaining original source-face and source-surface entity kinds. It must not access private kernel storage or invent engine/session behavior.
- `generate_native_goldens` encodes actual native box/through-hole output through contracts' builders with fixed fixture-only identities. Keep these separate from kernel-independent algebraic vectors; generator `--check` detects byte drift. It does not simulate engine/session lifecycle.
- Keep deterministic fixture recipes and licensing with [the corpus](../../../fixtures/geometry/AGENT-RULES.md); acceptance evidence belongs in [geometry evidence](../../../docs/quality/geometry-evidence.md).
- Exercise these binaries with `cargo run --locked -p spiling-geometry --example <name> -- <arguments>`; compilation or unit tests alone are not facade evidence.
