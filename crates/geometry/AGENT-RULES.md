# Native geometry boundary rules

Own immutable STEP admission, native queries, source-mapped display and the private kernel facade. [ADR005](../../docs/adr/ADR005-native-first-development-geometry.md) adopts the imported SolidCore BREP as the single DEVELOPMENT material authority, with original STEP identity/provenance and original finish inputs preserved. The native route is active with source7; executable producer identities and the manufacturing contract own current planner semantics. Native material reliance does not confer independent original-STEP topology/embedding proof. Preserve independent material, void, incidence, metric, conditioning and resource obligations. Descriptive metadata, nearest points and display meshes never grant operations; keep finish certificates narrow.

Native admission and display publication are independent. Preserve admitted geometry, source identity, metadata and conservative bounds on display failure; report the typed failure, not an empty successful mesh or invalid-source diagnosis.

Use one bounded native pipeline. Taylor bounds require qualified smooth spans, including nested or uncertain knots. Denominator exclusion, trim coverage, actual curve continuation, regularity and critical incidence are distinct proofs; samples and Boolean leaders are search data. Posed queries enclose actual quaternion polynomials: near-unit does not mean orthogonal. Translate closed support endpoints with the shared directed sum used by bed placement: preserve exact endpoint cancellation without discarding bracket width or pose-coefficient residuals.

Keep material, occupied projection and deposition separate. Per-source shape proofs do not certify composed-source features. Joint whole-slab proofs bind original sources, actual union candidates and used leaf dependencies. Incoming original cap incidence closes a regular core only at a coefficient-proved exact posed endpoint; it never authorizes cross-height critical glue. Other endpoint/critical collars require native incidence and resolved coverage, never false empty-prism or reverse-directed-leaf claims. Deferred protected-void queries retain opaque original product, regular, critical or collar authority and its owned storage; missing sample Hole loops never prove all-height absence. Protected voids and emitted support-capsule clearance are separate obligations; Boolean work padding is not geometric error.

Regular interface pairs borrow both actual material buffers and seal source/pose/leaf/candidate/exact-cut identity without retaining contours. Their whole embedded material-and-void collar discharges only actual overlap topology; native branch confinement, complete closed-cut incidence and critical/collar gates remain independent. Charge pending receipt capacity together with temporary proof storage; false grants no authority.

An original `EndpointUncertainty` joint is not pole authority. Independent Native pole qualification must retain the same original vertex and complete oriented coedge endpoints, prove the actual analytic pole/axis and whole connection image under the existing physical chart-error limit, and preserve original joint labels and cap/port heights separately from the critical band. Complete source C1/height-jet/normal, nonincident-trim, original-owner and degree-one projected-star checks remain mandatory; nearness, a joint label or a sample cannot replace incidence.

Explicit parameter identity does not prove selected PCURVE master equivalence: validate the selected original association over its own active domain, including nonincident carriers. Bare LINE coefficients do not supply an active unit interval; finite restrictions require original edge authority and whole-span forward correspondence. Implicit edges retain one whole-range continuation per original definition edge. Consumers borrow that branch rather than reselect roots or substitute guides. Preserve oriented source genealogy.

An undeclared source-associated sweep may propose an affine profile chart from complete borrowed harmonic operands and their actual reflection anchors; numerical Gram/phase collection is search only. Keep explicit original bounded domains separate from nominal native conic windows. An original unbounded harmonic profile may propose an equivalent phase branch inside the actual native evaluable interval, but only the unchanged complete coefficient/position/relative-tangent certificate can prove the numeric phase shift. Missing LINE generators can then use a certified original rim endpoint at the identical original topology vertex (or a genuine bounded original profile endpoint); native endpoint enclosures only propose coordinates. Original active spatial ranges, whole forward bounds, original-wire incidence, periodic-branch/domain binding and native face coverage remain mandatory. A derived chart is never an invented original PCURVE.

Charge completed work and owned capacities cumulatively, including failures and cancellation. Caller limits only narrow frozen caps. Count shared preparation once and account query/output coexistence. Native allocations and bounded stacks retain separate kernel/host limits; adapter accounting is not an RSS guarantee. Preserve specific unresolved, conditioning, singularity, resource and cancellation failures.

Prepared section analyses and deferred protected-void projections borrow their already-certified original trim domains and selected source-only recipes by immutable definition instance and original face/vertex identity. Domain/recipe reuse never reuses height-dependent classification, roots, continuation, critical incidence, wall/floor clearance or slab certificates. Charge retained metadata once at the source owner and admit each native classification's current scratch separately; standalone consumers use the identical query algorithm with locally owned preparation.

Directional source-cone extrema use the literal affine radial law `V+s(B(t)-V)`: bound the complete selected boundary `B` in one parameter and retain feasible apex/boundary witnesses. Query refinement must preserve the immutable BASE/comparison/displacement inventory and source cost; tight scalar extrema are not a new physical OriginalF/G correspondence or material admission.

Canonical authority and qualification: [native-first decision](../../docs/adr/ADR005-native-first-development-geometry.md), [geometry evidence](../../docs/quality/geometry-evidence.md). Native-first queries must not invisibly mutate authoritative BREP through private state or derived trims. Unsupported/indeterminate operations refuse explicitly; independent command replay does not certify original-STEP topology/embedding or physical readiness.
