# Native geometry boundary rules

Own byte-based declared-profile STEP admission, immutable native definitions, face-mapped display artifacts, native analytic directional extrema and native planar sections. No filesystem capture, sessions, occurrences, project persistence, scheduling, Tauri or rendering. Keep Monstertruck types inside private library modules; original corpus/operator fixture generators may construct genuine kernel objects directly, but facade diagnostics use only the public facade. Engine composition attaches session/artifact identity after encoding; the facade never invents those IDs. Cancellation is cooperative, checked before/after nonpreemptible upstream calls and between native faces/analytic curves. Errors remain typed; unsupported input is never repaired or replaced by meshes.

`Definition::vertical_wall_face` returns only an immutable source-local rectangular wall certificate; cancellable consumers use `vertical_wall_face_with_cancel`. Resolve the exact admitted FaceId to its positional native face use, require one four-line closed rectangular trim without holes, native outward orientation, full analytic source-Z span and a unique global supporting material plane. Use 1e-7 mm native residual and 1e-10 angular tolerances, not section/manufacturing approximation budgets. Unknown identities are `unknown_handle`; cylinders, sloped/top/partial-height faces, recessed or ambiguous coplanar trims are `unsupported_geometry`. Do not infer from meshes, section proximity or AABB corners, mutate source BREP, or claim invariant extrusion/overlap/manufacturing eligibility from this face-only certificate.

Standalone queries use frozen per-artifact caps. Engine callers narrow native face admission, mesh vertex/triangle/byte packing and sampled section bytes through explicit remaining-capacity entry points; budgets cannot raise frozen caps. Check faces before kernel conversion, mesh counts during audit/packing and sampled loops before retained growth. The facade does not own aggregate scene accounting or promise allocator-level kernel RSS limits.

Exercise `cargo test --locked -p spiling-geometry` and the real native corpus smoke; see [geometry evidence](../../docs/quality/geometry-evidence.md).
