# Native geometry boundary rules

Own byte-based declared-profile STEP admission, immutable native definitions, face-mapped display artifacts and native planar sections. No filesystem capture, sessions, occurrences, project persistence, scheduling, Tauri or rendering. Keep Monstertruck types inside private library modules; the original corpus generator may construct kernel objects directly, but facade diagnostics use only the public facade. Engine composition attaches session/artifact identity after encoding; the facade never invents those IDs. Cancellation is cooperative, checked before/after nonpreemptible upstream calls and between faces. Errors remain typed; unsupported input is never repaired or replaced by meshes.

Standalone queries use frozen per-artifact caps. Engine callers narrow native face admission, mesh vertex/triangle/byte packing and sampled section bytes through explicit remaining-capacity entry points; budgets cannot raise frozen caps. Check faces before kernel conversion, mesh counts during audit/packing and sampled loops before retained growth. The facade does not own aggregate scene accounting or promise allocator-level kernel RSS limits.

Exercise `cargo test --locked -p spiling-geometry` and the real native corpus smoke; see [geometry evidence](../../docs/quality/geometry-evidence.md).
