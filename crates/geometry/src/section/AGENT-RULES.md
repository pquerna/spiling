# Native planar section rules

Own direct definition-local SolidCore BREP sections and their immutable certificates. Do not construct a clipping solid or use a 3D Boolean, display mesh, sampled intersection, analytic family label or source tolerance as authority. Borrow the one millimetre-scaled BREP; source unit scale is provenance, not a second spatial conversion.

Every original native knot rectangle must be excluded by complete coefficient bounds or retained in the root proof. A transverse chart requires a uniform nonzero dependent partial derivative around every possible root. A small candidate cell, subdivision depth, missing boundary roots or native search result never proves existence, uniqueness, completeness or emptiness. Unresolved critical, tangent, coplanar, periodic-interior and vertex incidences refuse explicitly, never return an empty or partial section.

Evaluate the literal stored surface/curve chart. Native NURBS UV is not the original STEP angular chart. UV trims are the actual original edgeuse associations in the native edge direction; map only the explicitly declared normalized edge fraction to each native natural interval. Prove spatial-edge/chart-curve correspondence over the whole interval with coefficient/derivative bounds. Intersect an overestimated UV interval with the active chart only after a homogeneous coefficient containment proof. No fitted chart, seam borrowing or period guess is allowed.

Exhaust complete edge and trim root inventories with C0, strict endpoint existence and nonzero derivative proofs. Directed trim crossings determine material entry/exit without sampled fill. Assemble only at native `(EdgeId, root ordinal)` identities (or separately certified actual vertices), never by epsilon clustering. Use actual shell Faceuse orientation for material-left direction. Preserve sorted source-face ordinals and exact native chart spans beside the polygons through canonical ordering. Exact span limits are root expressions, not rounded parameter midpoints.

Bound every output chord over its entire native graph interval. Second-order interpolation needs closed-span C1 or one original open knot cell with proved C0 endpoint limits; otherwise a proved C0 piecewise derivative bound supplies the weaker Lipschitz bound. Account for original trim endpoint uncertainty and the actual common native endpoint coordinates. Plane error is a whole-segment linear bound, independent of chord error. Certify local tangent monotonicity and separation of nonadjacent complete curve error tubes; never repair crossings. A sampled polygon is not manufacturing/slab authority.

Placed raw sections qualify the complete affine covector hull, not just the nominal plane residual. Exhaust source vertex, actual chart-trim and carrier strata; require C1, nonzero edge derivatives and nonsingular transverse carrier gradients throughout every possible root cell. Unresolved homotopies refuse without borrowing material admission. Preserve each exact span's immutable definition-plane expression and explicit section pose when the returned polygon is placed.

Preparation borrows the immutable definition and creates no second geometry owner. Charge live root/span/output capacities and interval scratch before growth; prepared callers subtract every coexisting retained source/output from the shared 64 MiB allowance. Direct public output limits remain independent of query scratch. Keep the 16 MiB output cap and cumulative work/cancellation across isolation, correspondence, sampling and canonicalization. Move point buffers when joining cycles; no unadmitted native traversal allocation.

Tests belong to the integration owner. Source edits and unexecuted tests are not capability evidence; retain the unchanged box/cylinder, oblique/hole, rounded-housing, fitting and original-bracket gates.
