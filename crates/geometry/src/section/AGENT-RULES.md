# Native planar section rules

Own definition-local native section extraction and its immutable certificates. Placement belongs to the shared geometry adapter, not consumers. Preserve original source identity; generated query caps never acquire original FaceIds.

Only a conservative whole-solid bound establishes emptiness. Use the common bounded support and regularity pipeline, including interior critical sets, original trims and singularities. Family labels, sampled extrema and source boundary endpoints cannot replace it. Keep proven critical contacts distinct from area-bearing sections; unresolved coverage fails specifically.

Prepared native Boolean search meshes are seeds, not geometry authority. Select caps by exact clipping-face genealogy and bind every retained branch to its paired original source faces through native coedge lineage. Preserve all branches and owners. Retain each native loop's sorted unique original source-face ordinals from every validated actual curve use; nearest geometry, sampled-point matching and generated cap identity cannot recover this lineage. Keep owner lists paired with loops through source and placed canonicalization, including winding and first-vertex changes. Derived occupied envelopes carry no native slice owners. Carrier resemblance, guide proximity and a guessed seam owner do not establish identity. Even explicit cap guides require proof against the actual source-face/exact-plane intersection.

Source, clipping and intermediate candidate meshes use the explicit frozen section sampling resolution (0.005 mm), not display admission or the native geometric tolerance (unchanged at 0.00001 mm). Coarse seeds only locate candidate intersections. Every successful crossing query must prove actual curve enclosures and whole-source-face plane-root coverage; absent holes or disconnected candidates are refusals, never successful partial sections.

Preserve every actual oriented original coedge in the height and plane-root census. Opposite uses of one shared edge ID do not themselves prove a periodic quotient seam or authorize cancellation. Closed candidate front/back bindings follow the actual directed Boolean wire use and shared cut vertex, not undirected vertex coincidence.

Prepare a generated face/plane branch from its actual original front trim-root chart when genealogy provides one; otherwise use its actual original back root and traverse the unchanged coordinate backward. Isolate independent original-native and stored-UV root inventories; never identify their raw gauges or guess a period lift. A chart midpoint only proposes the numerical anchor: whole-range continuation and final complete coverage still decide acceptance, and retained original master branches remain unchanged. Capture this proposal before any carrier or edge-curve mutex callback.

For interior generated junctions, derive one coordinate proposal from the actual adjacent directed cut uses and shared native vertex, after original trim genealogy is known. Supply identical coefficients to both incident ends; original trim ends keep their independent closure receipts. Only fresh common-original-root uniqueness and complete joined continuation authorize coverage; coordinate equality or overlapping tubes alone do not.

Sample actual native curves with whole-interval chord and plane bounds. Implicit branches additionally require existence, uniqueness, transversality and complete coverage. Original trim-root endpoint closure requires exact Boolean cut genealogy, oriented original coedges and shared output vertices, never proximity or a guessed parameter map. Borrow pinned original implicit receipts; certify complete plane coverage before sampling, then charge every sealed continuation's extension and Green-area bound under the unchanged chord/plane caps. Prove native wire area and polygon orientation independently; return exactly closed, canonical winding, first vertices and loop ordering in the actual returned frame. Placed queries must preserve these guarantees under the actual accepted pose, not an assumed orthogonal matrix.

Sampling may carry immutable endpoint receipts only at the exact native parameter on the same prepared binding and unit view. Pass receipts through bounded recursion and adjoining spans; never reuse a nearby point or another capture. Chord and Green integration may share one fresh jet over the identical smooth interval. C0 intervals retain complete-image bounds and independent piecewise Green evaluation. Charge live proof scratch, retained stack capacity, reuse work and cancellation under the existing shared limits.

Keep typed native failures attributable to their operation: directional support, height-event census, source-curve capture, wire sampling and full-plane coverage are separate stages. Height/coverage diagnostics retain the original source-face ordinal and failing parameter cell when available; context must not change error codes, discard work or turn unresolved coverage into acceptance.

`Face::with_surface` holds the shared carrier mutex for the callback. Compare owners with the same native face ID using the already borrowed carrier on both sides, retaining coefficient validation and work accounting. Distinct carriers lock in immutable definition shell/face order, regardless of logical source-owner order. Prepare native face trim domains outside carrier callbacks.

Borrow immutable definitions. Charge native seeds plus pinned query proofs once per distinct prepared source. Source admission is at most 60 MiB; source/query/output coexistence shares 64 MiB. Direct section byte limits narrow packed output only; prepared query limits are the caller's remaining shared allowance after every live retained source/output. The independent packed cap stays 16 MiB. Share cumulative work across capture, coverage, sampling, integration and canonicalization; bound allocations before growth, release temporary proofs promptly and move point buffers rather than cloning them. Native Boolean intermediate admissions bound each object separately, not aggregate BREP/search allocations or transient RSS; external host memory limits remain required. Preserve cancellation.

Canonical algorithms and acceptance gates: [native parity ADR](../../../../docs/adr/004-native-geometry-parity.md) and [geometry evidence](../../../../docs/quality/geometry-evidence.md). Source changes and unexecuted tests are not capability evidence.
