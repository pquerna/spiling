# Native planar section queries vision

Provide deterministic owned native sections for bounded valid trimmed geometry while preserving immutable BREP authority. Queries return definition-local f64 boundaries with explicit sampling/Boolean tolerances; downstream engine composition places and packs them without source-face identity claims. Whole-domain support and critical-set analysis distinguish empty, regular and unresolved queries, including sections wholly inside a curved face's trim.

Keep native planar/cylindrical analytic extrema as narrow optimizations behind the shared analysis substrate. Descriptive family/analytic metadata never authorizes a generic operation. Actual native intersection curves require whole-interval approximation and, for implicit curves, validated continuation; search leaders and display meshes remain nonauthoritative.

Repeated layer queries reuse bounded native search preparation across immutable shared definitions without changing intersection geometry or tolerances. Borrowed lifetime, explicit source/query/intermediate budgets and prompt release keep acceleration separate from persistent authority and manufacturing ownership.


Box, cylinder, through-hole and bounded curved-family sections in multiple directions must pass original and frozen independent numerical/topology evidence before native section support is claimed. The periodic-edge gate invokes the public native Boolean on unchanged imported solids, checks every result shell's manifold closure, and retains original source face slots. A genuine native conditioning/completeness failure receives a typed refusal with its source witness rather than sampled-extrema repair, display-derived sections or omitted curved geometry. Occurrence union and manufacturing planning remain outside this module.
