# Strict native display conversion vision

Produce disposable bounded face-mapped display approximations of authoritative native definitions, with exact source-face ordinals and analytic oriented normals including inward hole walls. The identity-free encoded result can be published by an engine without re-encoding or pretending native geometry owns sessions.

The enforced carrier-plus-quantization limit is 0.05 mm for mesh-mm-0.05-v1; this is not source accuracy or arbitrary trim-region Hausdorff certification. Original and frozen independent OCCT periodic-edge regressions exercise all native face slots, circular cap trims, inward hole normals, every emitted triangle and deterministic packing; cancellation and chunk caps remain enforced. Native numerical support requires the frozen corpus evidence at the tested kernel pin, not merely these implementation contracts.
