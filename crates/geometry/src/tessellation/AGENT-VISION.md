# Strict native display conversion vision

Produce disposable bounded face-mapped display approximations of authoritative native definitions, with exact source-face ordinals and analytic oriented normals including inward hole walls. The identity-free encoded result can be published by an engine without re-encoding or pretending native geometry owns sessions.

The enforced carrier-plus-quantization limit is 0.05 mm for mesh-mm-0.05-v1; this is not source accuracy or arbitrary trim-region Hausdorff certification. Original corpus tests separately exercise all native face slots, circular trims, every emitted triangle, deterministic packing, cancellation and chunk caps. Native numerical support requires the frozen corpus evidence, not merely these implementation contracts.
