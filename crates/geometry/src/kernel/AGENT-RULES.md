# Private kernel ownership rules

Own the immutable opaque Definition, native solid, canonical source-face metadata, certified bounds and analytic boundary-curve witnesses. Do not export kernel types, pointers, locks or handles. Preserve positional face identity at every conversion boundary. Downstream modules borrow definitions; topology and certified bounds are release-active admission invariants.

Exercise `cargo test --locked -p spiling-geometry` and the real native corpus smoke; see [geometry evidence](../../../../docs/quality/geometry-evidence.md).
