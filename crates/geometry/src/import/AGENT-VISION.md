# Declared STEP admission vision

Admit bounded valid native trimmed families without guessed units, healing, partial-success assembly import or mesh fallback. Preserve source hash, canonical shell face-use IDs, source surface encoding and exact conversion provenance independently of display tessellation and modeled lowering.

Preserve reusable source/native chart and oriented coedge association through exact analytic, rational and sweep conversion. The retained bounded reference table shares curve maps and borrows unchanged native identities; UV witnesses stay native without duplicated carrier surfaces. Analytic witnesses remain narrow optimizations for existing wall/cylinder finish proofs, not permissions for arbitrary new families.

Admission retains declared length-unit/radian-angle and uncertainty provenance separately from normalized geometry. Whole-domain native enclosures establish conservative boxes and actual rational denominator conditioning, including sign-equivalent negative and nonzero mixed-weight representations. Regularity, trim coverage, approximation and section evidence belong to their captured operations. Support requires exercised import/section/display evidence at the same tested kernel pin; schema acceptance or unexecuted regressions are not universal CAD qualification.
