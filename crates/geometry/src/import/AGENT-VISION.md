# Declared STEP admission vision

Admit original planar/cylindrical parts without guessed units, healing, partial-success assembly import or mesh fallback. Preserve source hash, canonical shell face-use IDs and resolved surface-face IDs independently of display tessellation.

Admission preserves declared length-unit and uncertainty provenance separately from normalized geometry. Cached analytic carriers and canonical source-face order serve independent strict mesh/section consumers. Numerical support remains gated by generated original corpus admission and native evidence; accepting a schema is not a universal CAD claim.
