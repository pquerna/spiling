# Declared STEP admission vision

Admit original planar/cylindrical parts without guessed units, healing, partial-success assembly import or mesh fallback. Preserve source hash, canonical shell face-use IDs and resolved surface-face IDs independently of display tessellation.

Preserve reusable exact source-face/wire/coedge association through analytic-to-modeled conversion. The retained bounded reference table points into one analytic witness store and is bound to unchanged native identities/endpoints; it supports immutable full-cylinder trim proof without NURBS fitting, global-witness attribution, fixture-specific shape flags or another import authority.

Admission preserves declared length-unit and uncertainty provenance separately from normalized geometry. Cached analytic carriers and canonical source-face order serve independent strict mesh/section consumers. The periodic-edge gate includes unchanged frozen independent OCCT cylinder/through-hole bytes and a producer-independent minimal STEP topology reproducer, with native closed-solid and face-slot assertions plus malformed-topology refusal. Numerical support requires import, section and tessellation evidence at the same tested kernel pin; accepting a schema or adding an unexecuted test is not a universal CAD claim.
