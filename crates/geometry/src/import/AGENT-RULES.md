# Declared STEP admission rules

Parse UTF-8 once through maintained step-p21 after source/entity lexical caps; require one DATA section and declared AP203/AP214 profile. Qualified schema OIDs must match the named ISO/AP family and contain positive edition/conformance arcs; do not assume a fixed three-arc suffix. Corresponding pcurve representation contexts are metadata, not additional carrier support. Resolve referenced length/radian units and uncertainty in that AST. Refuse assemblies, unsupported reachable geometry, duplicate/missing canonical face uses and reachable conversion loss. Check remaining native-face capacity before conversion, then normalize through public modeling transforms and require valid closed solid plus certified bounds.

`mod.rs` owns native admission and positional source/native face assertions; `ast.rs` owns bounded lexical/AST traversal; `units.rs` resolves only solid-referenced representation contexts. Keep declared mm/metre/inch length units, radian angles and uncertainty provenance. Face family/optional analytic metadata is inspection data, never operation permission. Admit bounded native plane/cylinder/cone/sphere/regular-ring torus, polynomial/rational splines and exact sweeps through kernel-reported conversion maps; reachable unimplemented wrappers still identify their source entity in the refusal.

Retain shared curve source/native intervals and exact conversion maps before rationalization; immutable public source-unit provenance owns the common mm scale, and source topology owns original selectors, wrapper genealogy and use orientations. Bind the retained maps' restricted decoded-source ranges to that lineage and their native IDs/senses to the final normalized coedges; incidental BREP convenience ranges never supply source trim authority. Source UV and rational native UV are not interchangeable: never certify conversion by evaluating both at the same sampled parameters. Keep exact native chart curves and their full selected branches without copied carrier surfaces or BREP per coedge; no separate periodic-lift metadata substitutes for the expression. Bound retained wires/coedges at `2 * MAX_STEP_ENTITIES`, poll cancellation, and bind each oriented source occurrence to native edge/vertex identity and endpoints. Wrapper removal requires whole-curve analytic carrier membership; unsupported implicit correspondence refuses explicitly.

Preserve the bounded native extraction cause in rejection diagnostics. Admission failures identify stage, original source face/edge or native slot, periodic candidate shift and cumulative work. Retain only fixed-size last/largest periodic interval-fallback receipts across admission, including successful fallbacks and their preceding harmonic numerical declines; a later entry-budget failure must not lose its actual prior work consumer. Charge receipt coexistence to proof scratch, format only on failure and never log every declined candidate. A kernel representation failure is not independent proof that the source solid is invalid; do not hide it with healing, source rewriting or guessed face remapping.

Selected-master checks may reuse only a completed whole-original-range forward position and relative-tangent receipt for the same retained chart with no greater UV uncertainty. Exact coefficient projections, inverse tubes and another face's association are not those receipts. Collect correlated sweep coefficients before interval separation for position and derivative enclosures; retain native smooth-span and denominator qualifications. Explicit native harmonic comparisons must enclose both original expressions, complete affine phase/domain transport, numerical evaluation error and relative tangent agreement against a positive source-speed bound; unsupported expressions retain the bounded interval proof. Native parameter-curve operands already contain the public converter's composed original input chart.

Harmonic numerical reserves retain independent spatial-evaluation and phase-evaluation terms with the same operation-count bound. Phase error is amplified only by the outward sum of absolute trigonometric coefficients after the actual spatial map, never by world translation. Affine UV evaluation retains separate constant/slope majorants `B0+B1*|t|`: reflection adds only `B1*(|a|+|b|)` to the constant, spatial translation affects only that constant, and the complete target range scales only `B1`. Relative-tangent reserves also retain the phase-slope evaluation error when the target interval is small. Retain the spatial reserve even for equal or cancelling coefficients.

Analytic inverse-phase tubes may use a candidate reference only after validated sine/cosine rotates the complete XY enclosure into a strictly positive-X half-plane. Bound the angular residual outwardly by `|Y/X|`; otherwise retain native corner isolation. This is a whole-expression enclosure, never a sampled phase or permission to change an original interval, branch or forward-correspondence obligation.

The authoritative public STEP converter may represent a one-period closed edge by two shared exact native subedges; the same subdivision must appear in every oriented use, without changing source bytes, face count/order, carriers or face direction. Paired seam uses may explain repeated boundary vertices; arbitrary touching loops, seam spikes, open boundaries, nonperiodic/collapsed self-loops and geometrically inconsistent periods remain refusals. Do not implement that representation by an adapter-side healer or second extraction path.

Import boxes and rational-denominator admission share a cumulative bounded interval pass over complete native curve/surface domains, seeded at original source knots before requesting strict jets. Mixed or all-negative weights are not automatic failures; subdivide until the actual denominator excludes zero, or report bounded conditioning failure. Bare sweep profiles' convenience ranges are not STEP trim authority: use the complete retained original UV boundary to bound the chart, then enclose the whole surface image; exact extrusions use the native ruling-boundary theorem. Display/section/normal regularity remains operation-specific; no finite sample or display mesh proves import bounds or chart coverage.
