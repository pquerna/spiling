# Supervised native gRPC client vision

Provide one authenticated, bounded native gRPC lifecycle and checked domain adapter to the CLI and desktop shell: durable diagnostics, source-backed geometry inspection, recoverable project authoring and software-only manufacturing. All long work uses standard Google Operations names; immutable outputs use ByteStream. Child ownership remains separate from individual observations, cancellations and transfers, including reconnects and explicit admission-ID retries.

Recoverable typed domain failures and fully received corrupt manufacturing bundles leave the owner available. Native packed geometry and manufacturing pulls establish checked content/schema/provenance identity; stored verification is not independent emitted-program replay and establishes no physical printer support. The client owns no geometry kernel, project storage, scheduler, source cache, compiler, replay implementation or competing watchdog. Actual-child tests exercise scene preservation, stable geometry IDs, bounded transfer, non-UTF8 sources, writer locking/read-only behavior, observed termination, admission dedupe and save/restart/bundle retrieval after source removal.
