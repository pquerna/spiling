# Shared immutable export vision

Provide the CLI and native desktop shell with one boring, handle-owned exclusive export transaction for checked geometry, fresh manufacturing bundles and actual-program replay bytes. Export preserves operator-owned filesystem content on every failure and leaves completion authority with the consumer; it is not a manufacturing planner, persistence store, retry mechanism or renderer filesystem bridge. Fresh software verification and exported motion never establish physical printer support or machine readiness.
