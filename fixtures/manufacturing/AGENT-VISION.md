# Software manufacturing inputs vision

Provide reproducible TypeScript-authored printer data and explicit planar intent for native-section compilation, emitted-program replay, durable artifact and fresh-process inspection evidence. Separate printer specification from material/process recipe so another ordinary profile can be authored as data without changing the native planner.

The reference is deliberately a software Cartesian envelope, not a commercial machine or calibrated material. Physical printing, firmware lifecycle, thermal behavior, collision avoidance and supported-machine qualification require separate evidence; component-shape presence and successful replay do not establish them.
