# Software manufacturing inputs vision

Provide reproducible TypeScript-authored schema8 printer data and explicit planar intent for native compilation, emitted-program replay, durable artifacts and fresh inspection. Native shape error, seam and axis policies remain captured separately from geometric construction tolerances. Source-bound process and finish documents remain project intent, not profile-global flags. Profile revisions identify the strict consumed cutover; original STEP and configuration/calibration bytes remain unchanged.

References are software-only unqualified declarations, not commercial machines or calibrated materials. Required process/support policies drive actual retraction/cooling/first-layer/bridge/support software semantics. Complete sparse intent is available as trusted TS and inert JSON with unchanged empty calibration provenance; revised configuration explicitly declares ordinary default cooling fan, no laser synchronization and external E-only retraction. Physical firmware/calibration/printing remain external gates; record hashes, shapes and replay establish no machine qualification.
