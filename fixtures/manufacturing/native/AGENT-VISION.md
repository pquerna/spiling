# Native operator fixture vision

Provide genuine native inputs that isolate exact top scheduling, off-grid horizontal events and inward sloped planar section consumption. A frozen native tilted-cylinder cap also isolates offset support disappearance without modifying source BREP or erasing islands. Real shared rigid box occurrences expose cantilever and floating-body breakaway demand without mutating source BREP. Sparse roofs and protected through-holes exercise actual nominal deposited-anchor classification rather than full source-material assumptions.

Acceptance requires parent-owned native construction, public compilation and independently decoded emitted object/support material. Declared XY/Z contact clearance, bounded interface thickness/density, resource/cancellation admission and unsupported/blocked demand diagnostics are software gates. Neither these fixtures nor decoded G-code establish general STEP support, physical printability, collisions or printer qualification.
