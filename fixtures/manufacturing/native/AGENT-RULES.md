# Native operator fixture rules

Own original STEP regression inputs constructed by the pinned public Monstertruck builder in `crates/geometry/examples/generate_operator_fixtures.rs`, reusing the shared original parity recipes for analytic bores. Generation is source construction before writing, never import repair. The initial planar wire normal must point along the positive extrusion direction (+Y for the XZ prisms); native manifold closure alone does not certify material-side orientation. The generator normalizes exact straight-line extrusion carriers to planes, checks closed native manifolds and prints each generated asset SHA-256. Native section material must be the genuine prism, not the clipping rectangle minus a hole-shaped complement. Preserve frozen geometry sources elsewhere unchanged.

Run `cargo run --locked -p spiling-geometry --example generate_operator_fixtures` before the native manufacturing regressions, then use the same command with `-- --check` to detect byte drift. Commit the generated STEP assets with the source recipe after parent-owned execution. Nonintegral top is 7.85 mm; shrinking shelf is at 3.15 mm; inward ramp width shrinks from 20 to 16 mm across 7.85 mm. All depths are 10 mm. Geometry is original Spiling work under OSL-3.0, not customer CAD or independent-exporter evidence.

`off-grid-circular-tunnel` retains the 20 × 10 × 7.85 mm outer prism and adds a through-Y cylindrical void centered at X/Z (10, 1.37) mm, radius 0.24 mm. Exact coordinate permutation of the shared analytic extrusion recipe preserves its original carriers. Sections at Z=1 and 2 mm match `nonintegral-top`, but the actual section splits at 1.13 mm and merges at 1.61 mm; its missing width is `2*sqrt(0.24^2-(z-1.37)^2)`. Preserve both original sources. The manufacturing property `off_grid_native_tunnel_split_merge_and_near_tangency_preserve_replayed_material` requires the actual changed schedule, two near-tangent components and fresh emitted-byte material on both sides of the void. Exact tangent raw sections remain typed `DegenerateSection` refusals, not empty successful sections. The separate `equivalent_analytic_and_rational_sources_preserve_sections_material_and_fresh_replay` property compares existing matched box/cylinder/pocket sources within their chord-error bounds without demanding identical tessellation or G-code.

Native regressions must import these exact files and compile/replay through the public manufacturing facade. Frozen box/through-hole sources plus immutable rigid occurrences provide real cantilever/floating/hole cases. No fabricated section service, meshes, repaired geometry or substituted kernel. A native defect retains the original fixture and typed reproducer; fixture presence does not establish a passed capability gate.

`tilted-cap-offset.points.json` retains the exact closed world-XY material ring from original `fixtures/geometry/cylinder.step` (SHA-256 `95df1da444dc9c49529054f1825c9013c135301df677e30269c3a789ee2b464b`), kernel `5a4ddb7582c3d7f75a39e800a9fef345cdfe435e`, sample Z `8.086652812811982` mm, translation `[40,40,0.08726203218641757]` and quaternion `[0.006170592427165337,0.006170592427165337,0,0.9999619230641713]`. Point-file SHA-256 is `90bd58b1029fdc4ccf147de154c68a85993964dfb1c56260a2d2621ffdfa9428`. It isolates disappearing finite-edge offset supports and bead-center clearance; it is not a replacement native section service or generated STEP asset. Retain the public native compile/replay gate as end-to-end evidence.

`tilted-cylinder-complete.intent.ts` derives the schema7 complete software printer from the owning profile and freezes the 0.4 mm / 0.6 mm / one-wall solid recipe used by the native deadline gate, with explicit 0.1 mm native_shape_error_mm, nearest seam and alternating_xy rectilinear-axis policies. Its inert JSON carries the same full recipe policy; source geometry and process values are unchanged. Trusted source generation uses `pnpm manufacturing:intent`. These process/point fixtures are separate from the generated STEP manifest and declare no physical qualification.
