# Original protocol interoperability fixtures rules

- triangle.json stores the canonical 64-byte B0 diagnostic. mesh.json, section.json and section-multichunk.json store small original algebraic SPLM/SPLS diagnostics with exact hex chunks, descriptors and face/loop metadata. The existing Rust contract generator owns the geometry recipes and bytes; `--check` detects fixture drift.
- native-mesh.json, native-section.json and native-section-multichunk.json are generated by `cargo run --locked -p spiling-geometry --example generate_native_goldens`; `-- --check` checks exact bytes and sidecars through actual native STEP import/tessellation/section. They preserve original source hashes and fixed fixture-only identities, not engine-session evidence.
- Replay goldens are SPLR6 from actual backend emission and independent replay, not native geometry or hardware evidence. replay.json preserves rounding/coincident travel and process/bridge/support/lifecycle attribution; replay-sparse.json retains physical combined-band associations; replay-fixed-dual.json retains real tool-frame epochs, supported waste and exact E8 feeder debt. Regenerate only through the owning manufacturing tests with SPILING_UPDATE_REPLAY_FIXTURE=1: actual_motion_inspection_rounding_coincident_travel_and_fixture, coarse_sparse_dimensions_are_verified_and_packed and fixed_dual_actual_epochs_repay_feeders_and_separate_waste_from_model. Ordinary tests check drift without writes. Keep fixed fixture identities, both language consumers and all license sidecars together.
- surface-image.json is the original asymmetric 3×2 Gray8 canonical PGM image, exact SHA-256 and immutable preview descriptor. Rust content validation/normalization and TypeScript decoding must independently preserve its bytes, pixel order and descriptor bindings; this standard image format is not another SPLR layout or an image-manufacturing certificate.
- Rust compares encoder output with algebraic fixtures; TypeScript independently decodes both families and checks physical native extents, area, residual, winding and chunk-order rejection. Update schema authority and both consumers together. No customer or imported third-party CAD source. Native process/GPU acceptance remains separate from golden decoding.
- Preserve sidecar attribution in distributions. See [control protocol](../../docs/protocol/control.md).
