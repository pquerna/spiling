# Redistributable evaluation inputs rules

Own original redistributable evaluation data, not project persistence or production geometry services. Each corpus has its own rules, vision, generator/provenance, hashes and licensing. Preserve frozen sources; changed geometry requires a new name/version. Do not import customer CAD or third-party fixtures without established redistribution rights. Independent exporters may produce original inputs for admission diagnostics; they never become alternate runtime kernels or successful fallbacks.

Protocol goldens exercise independent byte admission; native corpus/evaluation recipes exercise actual geometry and runtime behavior. Distinguish those evidence boundaries and retain failed/unsupported outcomes explicitly. Canonical measured outcomes belong in [quality evidence](../docs/quality/geometry-evidence.md).
