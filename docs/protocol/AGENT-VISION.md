# Wire specifications vision

Describe authenticated gRPC diagnostics, native geometry/project/manufacturing services, standard Operations/ByteStream and packed synthetic/mesh/section/actual-replay payloads precisely enough for independent decoding. Keep native session identity, persistent project revisions, immutable artifact provenance, explicit inspection output selection and bounded failure behavior explicit. Implemented software semantics do not establish physical GPU, printer or arbitrary-import support.

Surface authoring keeps persistent face intent and canonical content-addressed images separate from native geometry and derived manufacturing. Spatial fields must remain source-frame bound through scheduling, support planning, durable replay and revision-aware read-only inspection.
