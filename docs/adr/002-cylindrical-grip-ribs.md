# 002 — Source-backed cylindrical vertical grip ribs

Status: accepted for implementation after independent geometry and data-flow review; software/physical acceptance is recorded separately.

## Value and scope

Extend the durable face-overlay workflow to cylindrical handles/knobs. Deliver constant-Z additive vertical ribs on a complete, exterior, full-height circular cylindrical source face of an upright, bed-anchored invariant extrusion. Preserve planar ribs. This is not helical/crossed knurling, arbitrary trimmed-cylinder painting, source-BREP editing, fuzzy skin, image mapping or calibrated grip/printability. Unsupported geometry fails explicitly; authoring alone does not certify manufacturing eligibility.

## Macro interfaces and authority

1. Contracts own a new `SurfaceFinish::CylindricalRibs { depth_mm, rib_count, phase_fraction }`. Depth is positive finite mm; count is an integer in `2..=256`; phase is finite in `[0,1)` of one rib cycle. The author stores neither a guessed radius nor a kernel UV/seam. Existing bounded ordered layers, definition inheritance, occurrence overrides, Smooth, disable/remove and monotonic IDs remain authoritative in Core. Native protobuf carries explicit checked scalar fields in the existing finish oneof, not a JSON tunnel.
2. Geometry owns an immutable `VerticalCylinderFace` certificate, resolved from the exact admitted positional native FaceId. It returns source-local XY axis center, radius and full local-Z range. Because modeled circular edges become NURBS, admission retains oriented exact line/circle trim references per positional face/wire into the existing analytic witness store; native coedge incidence/endpoints remain checked against that association. Never fit modeled curves or use the flattened global witness set as face attribution. Require top and bottom continuous oriented circular chains at analytic full-source Z extrema, each exactly one turn without gaps/overlap/backtracking; permit subdivisions. Every remaining incidence is a full-height axial seam whose native edge ID has opposite paired uses; no extra trim/hole remains. Verify canonical material-outward radial orientation and reject another co-carrier face use. Residual/angular admission limits remain 1e-7 mm / 1e-10 with cooperative per-edge/face checks. Native periodic seams are topology, not a user phase origin; no kernel objects cross the facade.
3. Manufacturing owns eligibility and a private tagged prepared finish (`Planar` / `Cylindrical`), with shared face identity, conservative bounds and retained-point accounting. Realization and first-wall certification dispatch both tags; existing planar chain construction remains private to its branch. Cylindrical construction gets a private owning module; no generic mapper trait/plugin framework or second planner/crate. `SectionSpan.material` contains the same realized D consumed by span/wall/skin caches, ordinary paths, alternate-axis raster regeneration, actual deposited anchors and protected-hole support clearance.
4. Existing typed project edits, ProjectRevision/FaceRef checks, history, immutable compiler capture and provenance carry the variant without a second metadata route. CLI accepts the same tagged finish JSON. Workbench adds explicit count/depth/phase controls and uses real native face inspection, not mesh attribution.
5. Effective finish document → native face certificate → posed/process admission and expanded exclusions → authoritative native section M → additive realization D → ordinary walls/infill/skins/anchor/support → emitted G-code → independent decode/replay → durable bundle. Source, realized and added areas remain separate. No finish-specific G-code emitter or verifier bypass.

## General-purpose foundations, bounded acceptance

The acceptance geometry is not the architecture. Overlay ownership, source targeting, scopes and data flow remain carrier-independent; current numeric finish parameters explicitly describe their supported coordinate mapping rather than pretending to be a generic shader language. There are no fixture hashes, entity numbers, known radii, fixed exporter face counts or seam layouts in production admission. Exact per-face analytic trim references cover every admitted line/circle face and remain useful beyond the cylindrical certificate.

Separate the periodic scalar profile (value and conservative derivative bounds) from carrier coordinates and from boundary-domain construction. Planar and cylindrical ribs are two actual consumers, so share this allocation-free profile logic now; protected planar end tapers are a domain envelope, not a different ripple algorithm. Keep planar-supporting-chain versus cylindrical-radial correspondence proofs shape-aware rather than pretending their mathematics is interchangeable.

Share genuinely carrier-independent robust closed-ring simplicity/material-retention predicates, proof-work charging and cancellation. Avoid a copied safety subsystem for every mapper. Prepared carrier-specific values feed one realized material-domain boundary and the existing planner; do not introduce geometry-specific path planners or verifier exceptions. These are concrete reusable modules, not a speculative plugin/mapper trait hierarchy.

Generality evidence must vary source-local frame/pose/phase and native ring subdivision/seam placement where applicable, rather than just rerunning the leading fixture. Negative cases establish current capability limits; they must not encode exporter recognition. Broader trimmed/partial-cylinder or varying-Z support requires a real correspondence/retention/anchor proof, not guessed support from the reusable API. Expanding that envelope must not require replacing durable overlay ownership or the downstream planning interfaces.

## Periodic field and native preservation

Source-local angle `theta = atan2(y-center_y, x-center_x)` uses source +X and right-handed +Z, independent of native carrier parameterization, BREP seam and occurrence pose. Displacement is `depth/2 * (1-cos(rib_count*theta - TAU*phase_fraction))`; its value/derivatives are periodic at the seam. Integral count closes the circumference without rounded pitch or a partial final rib. Effective circumferential pitch `TAU*radius/rib_count` must meet the existing four-bead-width lower limit; depth retains existing process/resolvability bounds. There are no protected angular endpoint margins on a closed full cylinder.

Construction is relative to the certified source's actual native polygon, not a resampled analytic circle that could remove source material. Match exactly one exterior ring by full-turn angular progression, robust convexity, strictly interior axis and radial envelope within the unchanged 0.005 mm native bound; the face certificate, not proximity alone, establishes ownership. Preserve every interior/hole ring's coordinates and order. Every output chord belongs to one original native-edge parameter interval; rounded images of native vertices must remain on/outside both adjacent source edges. Require a simple positively oriented derived exterior, closed inclusion of every source vertex, no proper source/derived crossing or vertex-on-edge crossing entering M, and no ring contacts, including at the seam. Use robust predicates and the existing retention proof pattern; no missing-material epsilon or floating re-quantizing union. Charge every comparison/scratch allocation and cancellation to unchanged aggregate budgets before growth.

Approximation budget remains 0.001 mm for finish construction, separately from the unchanged 0.005 mm native/offset bounds. Reserve 0.00001 mm for source/pose/rounding. Bound chord error for `q(t)=p_native_edge(t)+f(theta(t))*u(theta(t))`, where the native edge is linear. Let `L` bound actual edge length above and `d` bound its supporting-line distance from the axis below, conservatively including frame arithmetic; require `d>0` and angular span below `PI/2`. For `S=L/d`, `|theta'|<=S` and `|theta''|<=2*S*S`; the displaced-term second derivative is bounded by `S*S*depth*(n*n/2 + 2*n + 3)`. Divide an edge into at least `ceil(sqrt(bound/(8*0.00099)))` intervals. This does not assume exactly equal endpoint radii. Merge native endpoints and exact waveform-peak parameters, including periodic seam closure; apply the bound per original edge, never across a native corner. Charge samples, proof comparisons, retained arrays and cancellation to existing aggregate budgets; no increased 20-million Boolean-pair cap. Refuse ill-conditioned/large-coordinate cases rather than hiding error.

Endpoint evaluation must fit the reserved 0.00001 mm: conservatively account source-center subtraction/positive minimum radius, trigonometric phase sensitivity `depth*(n/2+1)*E_theta + PI*depth*E_phase`, arithmetic, pose and directed-rounding error. Reject uncertainty exceeding the reserve. Copy the first stored output vertex for exact cyclic closure; do not reevaluate the seam.

## Admission and unchanged downstream safety

The selected face must be a full exterior cylinder, not an internal bore, partial arc, recessed/partial-height face or a split co-carrier guessed into a whole face. Whole-body invariant-extrusion checks, source-local Z mapping to positive/negative build Z, bed contact, finite frame arithmetic, disjoint finished-occurrence exclusion, printer/component/prime bounds and first-wall rib resolvability remain mandatory. Conservatively expand XY by depth plus construction reserve. Internal native holes, if admitted by the certificate/section proof, remain unchanged; native source ownership cannot be replaced by mesh proximity.

Constant-Z geometry permits existing actual-anchor/support/cache reuse. The first-wall check measures radial extrema of the attributed cylinder exterior only, against the same certified source frame. With `E=native0.005+finish0.001+offset0.005` mm, require requested peak `depth>2*E` and realized first-wall maximum radius within `radius+depth-bead/2 +/- E`, separately reserving floating measurement rounding. This establishes a resolvable peak surviving ordinary erosion, not swept-bead physics, grip, collision freedom or the printed texture.

Keep the 20-million conservative Boolean-work bound, not an accidental whole-ring Cartesian-product acceptance envelope. Ordinary coarse-safe calls remain allocation-free. When overlapping polygon boxes make that estimate inconclusive, shared boundary-edge admission may tighten it, charging input/index construction, checked temporary storage, cancellable sorting comparisons/swaps, every active scan and all intra-/cross-operand candidates before overlay. Comparison boxes conservatively include the pinned overlay's shared integer-coordinate conversion uncertainty; source coordinates and geometric tolerances do not change. Dense/adversarial arrangements still refuse within the same work bound. Material-retention proofs retain their independent bounded robust-predicate accounting.

## Acceptance and bounded OODA loop

- Native proof: unchanged independent OCCT full-cylinder positive; original `cylinder.step` has two lateral faces and is a split/partial refusal, not a fabricated positive. Reject bore/partial/co-carrier/short/sloped/unknown identity; exercise cancellation and source immutability. Keep only deterministic consumer-visible regressions.
- Realization: seam/phase continuity, native M inclusion, exact protected holes, waveform chord bound, integer closure, posed source-local phase and finite/resource refusal. Prove changed closed first walls and real independently verified G-code, not just extra points or a mock echo.
- Operator flow: extend CLI and actual CEF scenarios to select/inspect a real full cylindrical source face, not the planar box. Finish receipt and captured provenance must retain exact identity/tag/parameters; Preflight/Compile → fresh independent ReportAndMotion inspection/actual replay/export → Undo/Redo without restoring fresh verification authority → checkpoint restored finished artifact → delete only owned source copy → fresh read-only reopen/inspection/export. Read-only rejects edits, Compile and Save without advancing revisions. Existing confined native token admission is reused, not a hidden source substitution or mesh route. Existing planar lane remains exercised with one focused regression.
- Resource policy: one warm target, one native Cargo/Rayon/test worker; native build/test cgroup 3 GiB RAM / 128 MiB swap / 64 tasks; CEF separate 1.5 GiB / 128 MiB / 256 tasks. Stage matching fresh engine and frontend before one debug shell build. Enforce an 11 GiB target ceiling and maintain disk headroom; remove only obsolete owned build artifacts if required. No release/package/full-workspace sweep.
- Observe one narrow failing scenario; orient using exact native/proof output; change the owning algorithm/interface; rerun that scenario, then only the affected integration gates. Record failures, limits and observed resource peaks in quality evidence. Do not weaken safety gates to obtain a pass.

## Alternatives and review decisions

- Helical/crossed knurling was deferred because varying-Z additions change support/anchor reasoning; it is not equivalent to a constant-Z periodic profile.
- Analytic-circle reconstruction was rejected because native sampled boundaries and protected holes must not be silently replaced.
- A generic texture mapper/asset subsystem was rejected until a second genuinely different mapping consumer needs it.
- Independent review closed four geometric gaps before implementation: per-face periodic trim ownership rather than global circle sums; actual-edge `L/d` derivative bounds rather than equal-radius assumptions; explicit global no-missing-material/crossing checks; and the separate native radial first-wall error budget. Data-flow review confirmed the tagged prepared seam and independently versioned embedded surface document, and tightened real cylinder token admission, fresh inspection/history authority and resource enforcement. None of those review conclusions is an executed acceptance claim.
