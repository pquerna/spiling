# Spatial image relief and realized support dependencies

Status: accepted after independent field/support and asset/API review; implementation and measured acceptance are separate gates.

## Value ranking and acceptance boundary

1. Image-driven relief: personal labels, grips, artwork and wrapped patterns. This project must validate durable image assets, spatial mapping, genuine varying-Z material, ordinary planning/support and actual G-code together.
2. Region/brush material and color painting: reuse persistent source-face coordinates/asset identity, but keep material/process assignment a distinct semantic channel from geometry displacement.
3. Procedural helical/crossed knurling and deterministic fuzzy skin: scalar-field consumers, not alternative planners. Diagonal/crosshatch/noise images already exercise those spatial pattern shapes; dedicated procedural controls require their own evaluated field contract, not unimplemented enum variants.
4. Broader support/fin strategies: consume the final realized object and actual deposition, not pre-texture source surfaces. Candidate placement intent is distinct from validated support geometry.

Deliver imported PNG relief on both certified planar rectangular and complete outward cylindrical native faces, with content varying in U and source Z. Base BREP stays authoritative and immutable; derived material D retains original section M and exact holes. Use the existing upright base-carrier certificates, not geometry/exporter/face-ID recognition. This is deliberately a hard derived varying-Z consumer, not an arbitrary-freeform carrier claim or a constant-section image shortcut.

## Invariants and dependencies

Native M(z) + captured image/mapping -> realized D(z) -> walls/skin/fill -> actual deposited-anchor demand -> support/contact geometry -> revalidated object/support paths -> emitted program -> independent decoding/replay.

A shape overlay invalidates the whole active manufacturing artifact atomically. Native source slab reuse does not imply D reuse. Realized material identities, skin horizons, wall/classification templates and both support-regenerated hatch alternatives must use the same D(z). Never regenerate source-only contours downstream. Original/realized/added accounting remains separate.

Supports are finalized after shape realization. A future fin path/location may survive as placement intent, never as an attachment/height certificate. Existing support candidates must be clipped/revalidated against all lower realized D with declared XY clearance and protected holes; contacts use actual deposited strokes. Tip/interface effects may be local, but no fixed last-N-mm invalidation rule is sound for shaft/corridor/bed dependencies. This implementation rebuilds support on compile; it does not invent an unproven incremental support cache. Existing Z gap semantics are a conservative minimum, using the last scheduled top at/below the required contact stop; actual gap can be larger and must not be described as exact.

## Immutable image ownership

Add a small `surface-fields` crate because engine import and manufacturing evaluation are separate real consumers. It owns bounded image normalization and borrowed scalar-grid evaluation, depends on contracts, and has no BREP, renderer, Tauri, persistence or planner dependencies. PNG decoding is an optional `png` feature enabled by engine only. Contracts own public metadata/canonical content validation; Core remains dependent only on contracts/storage and owns immutable bytes and transactions; manufacturing owns carrier lifting and planning. `SurfaceImageRecord::validate_content(&[u8])` returns a checked borrowed canonical pixel view. `surface-fields::HeightImage::from_canonical(record,Arc<Vec<u8>>)` shares owned content and exposes borrowed image slices; no contracts-to-fields or Core-to-fields dependency.

Canonical payloads remain shared `Arc<Vec<u8>>` through Core capture, HeightImage and self-contained manufacturing provenance; serialization retains the byte-array wire shape. Reusing/remapping an already admitted image is ordinary AddSurfaceFinish metadata, not a second import. Mapping edits remain available after original-file deletion.

Canonical content is standard binary PGM: exact ASCII `P5\n{width} {height}\n255\n` followed by width*height Gray8 bytes in source image row order, no trailing bytes/comments. SHA-256 of complete canonical bytes identifies the immutable image (dimensions included). Record fields: `image_hash`, `width`, `height`, `byte_count`, `source_hash`, `source_name`. Original encoded PNG hash/name are provenance, not a promise to retain the original compressed file. Black=0 and white=255 are height codes. Static PNG normalization first expands palette/tRNS and reduces each 16-bit channel to its high byte; absent alpha is255. Gray is used directly; RGB luma is `(299R+587G+114B+500)/1000`; height code is `(luma*alpha+127)/255` using wide integer arithmetic, compositing against zero-height black. Gamma/ICC metadata is explicitly ignored. Reject all APNG animation metadata, malformed or oversized input; no resampling or procedural replacement. PGM import preserves exact canonical samples. Native normalization golden bytes/hashes bind these rules; browser preview never defines manufacturing input.

Limits: encoded input <=1 MiB; dimensions 2..=256 and <=65536 pixels; checked PNG output <=262144 bytes and decoder allowance 8 MiB (best-effort decoder limit, not a total allocator proof); <=16 live images /1 MiB canonical payload, <=4 MiB unique retained canonical allocations across active/history/staged state. Keep the 32 KiB/64-layer overlay metadata limits, existing Core history/source budgets, 16 MiB bundle and 20M proof/Boolean work limits. Preflight admits retained sample/geometry estimates; execution checks cumulative per-layer D and path growth before allocation. No pixels in ProjectInfo, repeated finish records or history documents.

`SurfaceOverlays` becomes `{schema_version:3, images:SurfaceImageRecord[], layers}`. This is the sole metadata table; no duplicate manifest image-record authority. Records are unique canonical-hash sorted metadata and exactly equal assets referenced by every saved enabled/disabled image layer. `ImageRelief {image_hash, parameters:ImageReliefParameters}` references that table. Core Snapshot owns `BTreeMap<SourceHash,Arc<SurfaceImageAsset>>`; asset contains checked record plus immutable canonical bytes. Add/remove/target cascade prunes only unreferenced current assets; undo retains shared bytes and coherent artifact. Reimport of existing content searches current and retained history, reuses the owned Arc and complete first-admission record, and returns that authoritative record even if the newly selected PNG hash/name differ. This normalizes incoming import, never rewrites saved metadata. Scope deduplication to retained ownership in this project, not unrelated projects or historical disk files. Saved asset/overlay/provenance disagreements are corruption, not deduplication. No implicit disk GC.

Project format4 saves `images/<hash>.pgm` before manifest/checkpoint publication with the existing whitelist, handle-identity, atomic publication, recovery and storage directory budgets. Missing/corrupt content, header/dimension/hash disagreement and orphan/dangling references fail open including disabled layers. Incoming/staged/history ownership is charged before dropping old state. Core stores no source path. Save/open/read-only/recovery never need the original PNG.

## Mapping and scalar field contract

`ImageReliefParameters` fields: `depth_mm`, `u_repeats:u32`, `u_phase_fraction`, `z_period_mm`, `z_phase_mm`, `edge_margin_mm`, `vertical_error_mm`. All finite; positive depth/period/vertical error, repeats1..=256, phaseU in [0,1), phaseZ in [0,period); margin nonnegative, and positive/process-admitted for planar protected edges (unused cylinder margin must be zero). Depth is not restricted to the old half-bead rib bound: genuine overhangs proceed to ordinary support demand/clearance. Placed extents, conditioning, first-wall/feature realization and existing work/segment limits still apply.

Cylinder U uses source +X/right-handed +Z angle, normalized by2pi, independent of native UV/chart/ring seam. Planar U uses the certificate tangent from its canonical lower endpoint; protected end bands retain source vertices and use the existing smooth taper. Active planar width is face width minus twice the margin. U mapping is periodic with integer repeats and explicit phase. V is periodic physical source Z relative to certified minZ with captured period/phase; image top points toward +sourceZ (image row coordinate decreases as source Z increases). Bilinear wrapping includes last-to-first cells in U and V, so unequal border pixels make a real continuous transition rather than an unbounded seam jump. Documentation/controls expose these semantics; no world-placement texture swimming.

Freeze a periodic pixel-node lattice, with no half-pixel shift: for planar tangent coordinate s, A=width-2*margin and u=(s-margin)/A; for cylinder u=theta/(2*pi) modulo one. U=fract(repeats*u+phaseU), V=fract((sourceZ-minZ+phaseZ)/period), x=W*U, y=-H*V. Let i=floor(x), j=floor(y), alpha=x-i, beta=y-j; reduce i/i+1 and j/j+1 by Euclidean modulo and bilinearly interpolate four Gray8 nodes /255. Positive phase advances the sampled coordinate; increasing source Z traverses image rows in reverse. Last-to-first interpolation occupies a complete cell, not width-1/height-1 scaling.

Planar image end taper is explicitly separate from image tiling: let e=min(s-margin,width-margin-s); taper=0 for e<=0, taper=1 for e>=margin, otherwise `(1-cos(pi*e/margin))/2`. Require width>4*margin and margin>=2*bead; image fields use this fixed protected-band/ramp convention without altering existing periodic-rib taper semantics. U events solve W*(repeats*u+phaseU)=k; Z events solve sourceZ=minZ-phaseZ+k*period/H. Capture worldZ=tZ+sigma*sourceZ, sigma in {-1,+1}, and the complete source XY frame; inverse sourceZ=sigma*(worldZ-tZ) and transformed source atan2 apply even when flipped. Admit event counts before growth: ceil(W*repeats*abs(delta_u))+2 and ceil(H*abs(delta_sourceZ)/period)+2; retain required native/field events and reject unresolved minimum thickness, never merge to hide a feature. Skip certified redundant events in invariant intervals.

Scalar evaluation borrows one immutable decoded raster per image, not one per face/layer. Expose value, nonnegative interval range, local first/second U derivative and first Z derivative bounds, U cell-break/extremum iteration, Z row-break events and invariance over a source-Z interval. No generic plugin/mapper trait framework. Existing periodic ribs remain consumers of the same private field seam where truly shared. Capture immutable source-Z pose/sign once, including flipped source Z.

At fixed source Z, bilinear height is linear in U within each interpolation cell. Partition every native edge at every crossed image column/seam and existing taper break. Preserve original native parameters and exact source coordinates wherever displacement is zero. Planar lifting uses actual native segments, outward normal and taper product derivative bounds. Cylindrical lifting retains actual native chords: for edge length upper L, supporting-line distance lower d, S=L/d, use `|q''| <= S^2*(|h_theta_theta|+4|h_theta|+3*h_max)`. Piecewise derivative jumps are explicit partition boundaries, not smoothed away. Chord allowance remains0.00099 mm plus0.00001 mm source/pose/evaluation/rounding reserve, independent of native/offset0.005 mm. Copy the stored first cyclic vertex for closure. Shared robust retention/simplicity proofs include original M and all exact holes; blank image rows return unchanged M without invented positive displacement.

## Vertical fidelity, scheduling and local realization

The image defines continuous intended height, not merely 'whatever midpoint samples happen to see'. `vertical_error_mm` is an explicit separate radial/normal displacement bound for the layer approximation; it is not the0.001 mm XY chord certificate and not physical accuracy. Within each scheduled slab, conservatively bound deviation from its midpoint field using interval extrema and local `|h_z|*height/2`, including pose arithmetic. Insert bounded mapped image row/cell/seam events and adaptively refine existing deposition intervals when required. Never let a bright band between original layer samples disappear silently. Preserve exact native events, minimum resolvable thickness, max4096 layers and cumulative point/path caps; unresolvable features get a specific diagnostic. Reuse native invariant M separately from realized D, so refinement does not cause avoidable repeated native intersections.

Mandatory native/image/support events define exact interval boundaries. Subdivide each event interval evenly into the minimum admitted number of layers no taller than the nominal recipe height, then apply the vertical-error refinement above. Do not union an independent fixed global nominal grid with image events: nearby unrelated grid tops create avoidable sliver layers and zero serialized extrusion. Only arithmetic identity may coalesce mandatory boundaries; genuinely unresolved event spacing still fails. Keep command precision and the independent positive-extrusion checks unchanged.

Construct certified R/D once, then admitted first-wall erosion E once; ordinary paths derive from E. Do not duplicate the production evaluator/erosion as a supposed independent verifier. Global extrema are not sufficient evidence: independent asymmetric field and actual-first-wall tests must catch phase/row/lost-band and identical-extrema displaced/missing-lobe errors. Independent emitted replay validates bytes against the captured plan, not image geometry.

Wall admission separates requested D from required reachable material C. On an attributed image-owned island, C includes native M **and every non-image finish addition**, including ribs on another face of that same island; only image-added sub-bead lobes remain requested intent with explicit nominal-resolution diagnostics. Every non-image-owned island retains its full-D reachability gate, and strict rib peak certificates remain additional checks. Realize/cache C once per native M slab under the current invariant rib envelope; image-only occurrences share M without another coordinate copy. Attribute C and D by original native witnesses rather than polygon ordering. Reuse the same D-derived E and conservative dilation for the unchanged reachability threshold; do not produce another erosion, suppress a thin-region exception, relax tolerances or silently drop intended geometry. Retain/charge M and any distinct C through this proof and witness attribution, then release them.

Physical-skin neighborhoods intersect consecutive immutable realized-D spans. A bounded lazy aligned-range cache shares these intersections across overlapping lower/upper horizons and support regeneration, with deterministic ascending-range combination. Leaves borrow final D, never native M; cached nodes share geometry rather than copying it per query. Admission charges actual padded boundary candidates, sorting and scans cumulatively with surface/attribution work under the unchanged20M ceiling. Count cached and simultaneously live temporary geometry in staging/retention limits; a cache hit cannot authorize a stale D identity or unbounded retention.

Cache retention is optional derived work, not a reason to pin every historical neighborhood. Reclaim least-recently-used unpinned geometry under combined retention pressure; live shared query operands remain counted and cannot be evicted. Charge eviction scans and recomputation to the same work ceiling. Before support planning, freeze the cache's retained capacity to its reserved pool; regeneration may reclaim/rebuild within that reservation or use admitted temporary aggregates, never grow an unaccounted cache behind the support stage.

Classification reports its complete currently live scratch requirement to the planner's retention authority; optional cached geometry is reclaimed before a hard combined-budget refusal. Regenerated raster requests also carry the live additional support/interface/protected-domain count. A frozen cache pool covers cached nodes, not newly owned query/classification temporaries; include those and all mandatory object/support geometry exactly once.

Production resolution diagnostics stream bounded `FeatureWitness` values at mapped cell/native-edge/taper boundaries, strict extrema, plateau representatives and one interior midpoint per nonconstant smooth piece. Witness identity includes effective surface layer, image, occurrence/face, source Z, normalized source U/cell/repeat and native edge parameter; XY is lifted from the captured field with certified uncertainty. Query distance to the entire attributed owning first-wall exterior, not only same-U segments (erosion moves features laterally), excluding unrelated islands/holes. For distance d, bead radius r and certified lift/offset/distance/rounding uncertainty e, report residual interval `[max(0,d-r-e), max(0,d-r+e)]`, not just an uncertainty-subtracted scalar.

Capture bounded `SurfaceResolution` records in the normalized plan, grouped by image/face/layer: witness counts classified resolved, ambiguous, below nominal bead resolution or unavailable; explicit coverage completeness; maximum residual interval and at most8 representative witness records with truncation indication. Summary/UI expose advisory totals independently of fresh emitted verification. Diagnostic distance work is charged; exhaustion marks incomplete coverage rather than falsely claiming resolution. Missing attributed exterior is unavailable, not a fabricated distance. These are sampled nominal-bead resolution diagnostics, not universal Hausdorff coverage, physical error or guaranteed feature survival. Correct erosion can remove small details; report that without rejecting an otherwise useful image. Blank rows are valid. Field/retention/chord/vertical-error/cache/safety failures remain hard errors.

## Physical support domain and interface roles

Let S be the complete bed-anchored, clearance-clipped support domain and I its requested interface subset. Realize the shared physical center domain E(S) once. Interface is a deposition role/density boundary, not a second object boundary: independently eroding I and S-minus-I can erase a sub-bead interface strip and remove the anchors beneath the next layer despite unchanged S.

Preserve every physical exterior/hole wall edge from E(S), and partition wall/hatch centerline ownership by I without duplicate seam outlines or a fictitious half-bead clearance at that seam. Nominal beads must stay within S; beads may overlap the internal role seam. Paths retain a single explicit role and volume attribution; interface hatches retain full density and ordinary hatches the requested support density. Any splitting must preserve the same physical strokes and admit finite positive representable segments.

Admit a candidate against actual preceding support/interface strokes using the existing capsule/bridge proof. Try the other permitted hatch axis when needed, with unchanged anchor/bridge/clearance refusals and deterministic preference; no density declaration substitutes for deposited coverage. Charge all attempted geometry and anchor work, bound simultaneously live candidate paths/domains, and commit only the selected output segments. A changed lower D still clips the complete bed-to-contact corridor before this realization.

## Complete acceptance and operating gates

- Genuine native planar and independent full-cylinder imports; images vary in both coordinates, include unequal wrap borders, blank rows and a non-grid narrow vertical feature. Leading source identities never appear in production algorithms.
- Local field/chord/source-retention/holes/pose/seam proofs, vertical error/refinement including an aliasing trap, and spatial first-wall fidelity (an identical-global-extrema phase/region mutation must not pass).
- Realized skin/fill changes and both regenerated hatch alternatives consume D; sparse/native-only anchors are not fabricated. A steep image creates real support demand: disabled support refuses; enabled support succeeds with a genuine bed corridor/contact; another image blocks a previously usable lower support corridor and forces rebuild/refusal. No fixed last-N-mm support invalidation.
- Actual CLI and production CEF: choose image, author mapping, atomically Import and apply, inspect canonical preview, Compile, fresh ReportAndMotion and actual G-code/replay varying by Z. Exercise history/checkpoint, delete owned STEP+PNG copies, remap stored image without another file, and fresh readonly reopen/image preview/replay/export. Original BREP and source face identities stay unchanged. Cancellation/error/readonly/stale and corrupt stored image are explicit failures without fallback or state mutation.
- One warm target; one native Cargo/Rayon/test worker. Native3 GiB RAM/128 MiB swap/64 tasks; separate CEF1536 MiB/128 MiB/256 tasks. Target11 GiB stage ceiling with headroom; remove only obsolete owned artifacts if needed. No concurrent builds, release/package/full-workspace sweeps. Focus checks on field/material/asset/interface invariants and actual surface; record real failures and measured resources.
